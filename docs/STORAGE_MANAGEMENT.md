# 本机存储与主动管理

## 分层

- React / 内存：当前交互状态；点击无需等待磁盘。
- localStorage：明确允许的小配置。应用软预算 512 KiB、单项 8 KiB；超预算配置进入异步存储。不是提高浏览器实际配额。
- IndexedDB：文章 JSON、书架、生词、答题、文章练习、学习历史。内存接收后异步事务保存，保存失败必须显示告警。
- OPFS：保留现有 reading-local-data.json 文件副本兼容旧安装；新存储主记录优先，不能让旧文件覆盖新记录。
- 云端：已有用户登录和同步流程，不因本次存储迁移更改协议。

## 迁移与删除

启动等待异步存储初始化，之后才挂载页面，防止空状态覆盖历史。迁移读取原字符串并写入 IndexedDB；仅在事务完成且源值没有改变时删除原 localStorage/sessionStorage 项。失败保留原件。未知来源键不自动清除。

已保存的用户答案、历史、词库、个人导入不设自动删除 TTL。没有“近期不用即删除”的隐含规则。预置教材可更新，但不得为腾空间删除个人内容。已有历史缓存归档到 IndexedDB即释放 localStorage，而不是删除历史。

## 主动管理

启动、每 5 分钟、页面再次可见时检查并迁移可管理的遗留项。写入时也执行小配置预算约束，不等资源耗尽才处理。状态区显示占用估算、待保存量及保存失败情况，可手动立即检查。

localStorage 字符串占用以 UTF-16 键和值长度估算，非浏览器提供的精确物理字节数。浏览器站点配额估算也不是 localStorage 剩余量。共享同源其他项目的数据仅统计，不擅自删除。

## 清空范围

“清空本机记录”删除受管理的学习数据与 OPFS 学习文件内容，保留 AI/语音等小设置，不删除云端数据。不使用 localStorage.clear()，避免影响同源其他应用。

## 边界

异步写入存在提交前窗口；保存中或存储失败不应显示已可靠保存。浏览器可能清除整站数据，长期备份仍依赖导出或云端同步。未获可靠落盘确认时不清理原副本。

同源 localStorage 估算达到 4 MiB 时提前转移本应用小设置，不清除其他项目占用。这是保守预警线，不是宣称浏览器的精确限额。

兼容例外：VocabMaster 的共享收件箱由另一个应用直接读取，保留其原 localStorage 交换协议，限制为 64 KiB，并计入本应用 512 KiB 预算；超过预算时明确提示改用导出/云同步，不把写入失败伪装成成功。它不是书架或历史的存储位置。

数据库读取失败与写入失败分开处理：已有数据库无法读取时禁止随后以空默认值覆盖它；页面提示降级，重新打开页面恢复读取。迁移写事务失败保留源副本并允许维护重试。跨标签页仅通知变化的键，不因每次答题重新加载整本书架。

## 发布验证（2026-11-14）

版本：2026.11.14.2。

- 开发目录 Node 测试 43/43 通过；生产独立存储测试 10/10 通过。
- 实际 Chromium：大记录迁移、localStorage 写入强制失败下答题落盘、刷新恢复、所有存储不可用仍可操作并告警，均通过，无未捕获异常。
- 实际 IndexedDB：事务失败保留源数据、主动维护重试、跨标签页删除同步、超大设置转存、数据库读取失败不覆盖原数据，均通过。
- 自定义云端连接配置必须在异步存储就绪后初始化，避免默认配置抢先生效；不修改云端权限或数据协议。
- 自动化检查覆盖入口不可绕过管理层、两个入口一致、主记录优先于旧文件副本、周期检查与清理范围。

保留限制：浏览器可整体回收站点数据；异步提交前关闭页面仍存在丢失窗口（保存中会尝试阻止意外关闭）；Safari/iPad 真机尚未覆盖。数据库读取失败需重新打开页面恢复，不允许写空默认状态覆盖历史。
