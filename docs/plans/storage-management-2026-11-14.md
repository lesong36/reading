# 存储治理实施计划

范围：阅读器入口、独立存储模块、同步脚本、回归测试和运行说明；不修改现有教材、云端协议或其他未提交功能。

1. 先运行现有回归并增加持久化迁移/故障测试，保护答案及用户导入。
2. 使用内存作为交互状态；IndexedDB 异步保存学习记录与历史数据；保留 OPFS 的现有大文件副本。
3. localStorage 仅用于明确允许的小设置，预算 512 KiB、单项 8 KiB；超限设置转入异步存储。迁移旧数据后，仅在事务提交且源值未改变时删除源副本。
4. 启动、周期和回到页面时主动检查；提供占用及失败状态。用户答案、导入文章不按时间自动删除；可重新获取的缓存与用户数据分开治理。
5. 清理本机学习数据覆盖受管理学习键与 OPFS，保留设置；确保迁移失败时原数据不被删除。
6. 故障注入验证存储满、不可用、刷新、迁移和恢复；同步入口，独立生产发布，防止带入其他开发变更。

主动管理的目标是预防配额耗尽，不通过默默删除用户历史换空间。浏览器最终持久化不可用时必须报告，不能把内存接收冒充磁盘保存。
