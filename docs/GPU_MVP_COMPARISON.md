## 代表性语法差异

1. **s1 — 同位语边界**
   - Mac 将 `(1862–1928)` 单独标为 modifier；P920 将其收进主语。
   - 两种边界都能重建原文，教学展示上 Mac 更明确，P920 更紧凑。

2. **s3 — 定语从句与非谓语**
   - Mac 把 `that` 设为 conjunction，并保留较大的 `focused on` 谓语块。
   - P920 把 `that` 设为 clause-subject，并将后续短语细拆；这更接近关系代词的主语功能，但其 `which` 与 `she` 同时出现 clause-subject 的处理仍需语义审核。

3. **s11 / s16 — 长句过拆风险**
   - Mac 分别为 5 与 11 段；P920 为 20 与 20 段。
   - P920 对修饰链、介词短语与非谓语提供更细颗粒度，但过多切片可能增加错标和界面负担；不能仅因更多段而视为质量更高。

4. **s14 — 定语从句显式程度**
   - Mac 将 `who depicted it in a lithograph` 收为一个 modifier。
   - P920 显式给出 `who / depicted / it / in a lithograph` 的从句主语、谓语、宾语与状语，教学可解释性更强。

5. **s25 — 缩写边界回归**
   - 两端都将 `St. Denis` 保持在同一句、作为主语，证实缩写切句问题已被修复。

## 决策建议

1. **P920 可作为主生产跑道**：本次同类协议的平均吞吐更高，并在显式从句结构上通常更细。
2. **Mac 可作为独立复核跑道**：它提供不同的切片视角，适合对 P920 的高风险长句做第二意见，而不是混合覆盖正式结果。
3. 在全量之前增加“语义裁决样本集”：至少 30 句，覆盖冒号、缩写、定语从句、并列句、非谓语、长修饰链。每句人工确认 gold 结构；两端须达到预设一致率/正确率后再扩展到 104 篇。
4. 不修改原文。后续仅允许：不可变句界合同、分块传输、模型级重试、结果隔离、机械校验与语义抽检。
