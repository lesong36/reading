# 点与间隔图

适用于连续编号的起点和终点，以及相邻两位置之间有相同数量的题目。例如楼层之间的台阶、相邻编号站点之间的等量路程。可以与植树问题等主解法配合；容易把位置数当成间隔数时，即使算式简单也应画出点和间隔。

先从原题图片确认起点编号、终点编号和每段数量。只用原题给定值；OCR 可能只剩题号。终点编号减起点编号得到间隔数，再乘每段数量得到总量。编号是无单位的整数，位置名称写在标签中，不能把“楼”与“级”直接作加减比较。

用原生 interval 图解画实际的点和线段，标出起点、终点、总间隔数、每段数量和总量。factIDs 按起点、终点、间隔数、每段数量、总量的顺序引用五个事实；起点、终点和每段数量为 given，间隔数和总量为 derived。所有编号和间隔数的 unit 为空字符串，每段数量与总量使用一致的实际单位。关系包括终点减起点的 difference，以及间隔数乘每段数量的 product；引用必须对应已声明的事实 id。渲染器会自动绘制所有能清楚显示的间隔，多时明确省略部分，不要手工逐点生成事实。

不要只说“把楼层画成点”而省略图解数据。图中给定值与推得值应区分，逆向检查总量除以每段数量是否还原间隔数。

不适用于闭合环路、非连续编号、各段数量不同或无法确认起终点的题目。仅有长度和间距的植树题应先采用对应主解法，不能把长度当作编号。本模板支持正的 1 至 1000 个间隔；超出范围或必要条件不清楚时说明限制，不编造条件。
