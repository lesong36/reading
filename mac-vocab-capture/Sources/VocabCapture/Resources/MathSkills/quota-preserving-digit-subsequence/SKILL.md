# 受删位配额的字典序子序列

## 适用条件
将数字串删除指定个数的数字、保留其余数字原有先后顺序，并求固定长度结果的最大或最小值。先区分删除单个数字与删除整个原数；核算原串总长度、实际保留位数，以及首位是否允许为0。若结果允许改变长度、存在额外数码库存或相邻约束，普通窗口贪心不保证适用。

## 保留足够后续数字的窗口
设还需保留r位，当前位置之后共有m个数码，下一位只能从前m−r+1个位置中选择，否则余下不足r−1位。最大数在此窗口选最大数码；最小数首位如果要求非零则只选允许的非零数码，之后选最小数码；没有合法选择应报告不可行。同值取最早位置，因为这保留了至少同样多的后续选择。移到所选位置之后，重复直至取满r位。

固定长度数字按从左到右的首个不同位决定大小：窗口外的位置无法留下足够后缀；窗口内选择更优首位优于任何较差首位；相同首位选更早不会减少后续可行性。对每个后缀重复这一交换论证，得到全局最优。该证明依赖约束仅为顺序、保留数量和首位非零；其他约束必须重新验证后缀可行性。

## 原题及核对
将1至30依次连接，1至9共9位、10至30共42位，总51位；删除45个数字，保留6位。最大结果998930（原串位置9、29、47、49、50、51）；最小且首位非零结果100120（位置1、11、31、33、34、51）。两问是独立选择，逐位核查原位置递增、保留6位与首位限制；原题问的数不是删去的数。

## 边界
若仅余的窗口没有非零首位，不能拿0冒充合法首位，也不能将多删的数字补回。若要求所选数字互不相同或结果可变长度，应额外验证限制，不能直接沿用无约束贪心。
