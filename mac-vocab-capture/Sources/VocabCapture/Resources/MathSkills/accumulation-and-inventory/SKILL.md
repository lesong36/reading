# 累计与进销存

加减法应用题先分清是在累加已经完成的部分，还是从原有数量里减去离开的、加上新来的。来源是分类体系里的基础数量关系。

# 累计

只加已经发生的部分。要剪 $96$ 张窗花，第一天剪 $14$ 张，第二天剪 $15$ 张。两天一共剪了 $14+15=29$ 张。$96$ 是任务总量，这一问没有用到它。

# 剩余

从原有数量里依次切掉运走的部分。摘了 $105$ 个西瓜，运走 $40$ 个和 $27$ 个，剩下 $105-40-27=38$ 个。

# 进销存

原有的，减去离开的，加上新来的。

$$\text{现有} = \text{原有} - \text{减少} + \text{增加}$$

车上原来 $24$ 人，下去 $13$ 人，上来 $18$ 人。现在有 $24-13+18=29$ 人。

画的时候用箭头记下每一步：$[24] \xrightarrow{-13} [11] \xrightarrow{+18} [29]$。倒回去求原来有多少，就是 [[还原问题]]。

# 先合再分

两篮桃子 $25$ 个和 $15$ 个，每 $8$ 个装一盒。先求总数，再求份数：$(25+15)\div 8 = 5$ 盒。这是 [[归一与归总]] 里归总的最简形式。

# 分段计费

不同区间单价不同，先切开，再分别算，最后相加。停车 $3$ 小时内 $15$ 元，超过的每小时 $6$ 元，停了 $6$ 小时。前 $3$ 小时 $15$ 元，超出 $6-3=3$ 小时，$3\times 6=18$ 元，一共 $15+18=33$ 元。
