# 状态图

同一个事物按时间变化时，每个时刻画一个方框，方框之间用箭头写上这次加了多少或减了多少。数量在方框之间流动。`Gemini_A` 的数形工具把它用作多步加减和还原。课堂上的 [[进销存图]] 是同一种画法。

# 怎么画

1. 左边画起点，写上原来的数量。
2. 每发生一次变化，向右画一个箭头，箭头上写 $+n$ 或 $-n$。
3. 箭头指向下一个方框，方框里写变化后的数量。
4. 最右边是现在的数量。

车上原来 $24$ 人，下去 $13$ 人，上来 $18$ 人。

$$[24] \xrightarrow{-13} [11] \xrightarrow{+18} [29]$$

现在有 $29$ 人。

# 从结果倒推

知道最后一格，不知道第一格，就从右往左读。箭头上的加变成减，减变成加，乘变成除，除变成乘。方框仍按原来的顺序画，数字从终点填回起点。做法和 [[还原问题]] 相同，只是每一步都留在图上。

# 什么时候不用线段

变化发生在同一个对象身上，例如同一辆车、同一笔钱、同一堆货物。画成两条线段，会被看成两个人在比较多少。比较多少时改用 [[线段图]]。
