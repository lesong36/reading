# 空瓶换水

$n$ 个空瓶换 $1$ 瓶饮料。喝完以后又得到 $1$ 个空瓶，所以真正被消耗掉的是 $n-1$ 个空瓶。讲义 Q2-09。

# 为什么除以 $n-1$

规则是：$n$ 个空瓶 $=$ $1$ 份水 $+$ $1$ 个空瓶。两边同时去掉 $1$ 个空瓶：

$$(n-1)\text{ 个空瓶} = 1\text{ 份水}$$

所以

$$\text{能喝的瓶数} = \text{空瓶数} \div (n - 1)$$

$3$ 个空瓶换 $1$ 瓶，手里有 $10$ 个空瓶：$10 \div (3-1) = 5$，能喝 $5$ 瓶。

$2$ 个空瓶换 $1$ 瓶，手里有 $5$ 个：$5 \div (2-1) = 5$，能喝 $5$ 瓶。

# 手里的瓶子刚好差一个时

规则是 $3$ 换 $1$，手里只有 $2$ 个空瓶。先向店主借 $1$ 个，凑成 $3$ 个换 $1$ 瓶，喝完还回这 $1$ 个空瓶。公式仍然成立：$2 \div (3-1) = 1$。

# 做题时

1. 看清几个空瓶换 $1$ 瓶，这个数是 $n$。
2. 用空瓶数除以 $n-1$。
3. 除不尽时，余下的空瓶留在手里，不够再换。
