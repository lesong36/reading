# 面积图

两个量相乘，画成矩形的面积，或者画成一条被等分的线段。总价、路程、工作总量都是这块“面积”。课堂里的单价模型和速度模型用等分线段来读这三个量。

# 三条边怎么读

单价模型里，每份的长短是单价，份数是数量，整条线段的长度是总价。

$$\text{总价} = \text{单价} \times \text{数量}$$

$$\text{数量} = \text{总价} \div \text{单价}$$

$$\text{单价} = \text{总价} \div \text{数量}$$

牛奶每盒 $18$ 元，买 $3$ 盒。画 $3$ 段，每段长 $18$，总长 $18\times 3 = 54$ 元。

已知总长和每段的长，看能切成几段，就是求数量。已知总长和段数，把总长平均切开，每一段的长就是单价。

速度模型是同一张图：每段是速度，段数是时间，总长是路程。小丽 $6$ 分钟走 $480$ 米，每分钟 $480\div 6 = 80$ 米。时间相同比路程，路程相同比时间；两个都不同，就先把每分钟的路程算出来再比。

# 面积不变时改边

每小时栽 $15$ 棵，$4$ 小时完成。矩形面积是 $15\times 4 = 60$ 棵。改成 $3$ 小时栽完，面积仍是 $60$，另一边变成 $60\div 3 = 20$ 棵。这就是 [[归一与归总]]。

大货车 $8$ 小时走完，小轿车速度是货车的 $2$ 倍，路程相同。速度变成 $2$ 份，时间就变成原来的一半，$8\div 2 = 4$ 小时。

去程每小时 $40$ 千米、走 $3$ 小时，路程 $40\times 3 = 120$ 千米。返回走同一条路，用 $2$ 小时，速度是 $120\div 2 = 60$ 千米/时。

# 先算差，再乘

原价每千克 $12$ 元，现价 $9$ 元，买 $4$ 千克。可以画两个矩形再相减：$12\times 4 - 9\times 4 = 12$。也可以先把单价差画成一条短边：$(12-9)\times 4 = 12$。两条算法是同一块面积。

# 矩形上直接求一条边

`Gemini_A` 把乘法画成矩形：一条边是数量，另一条边是单价，面积是总价。买 $4$ 支钢笔花 $32$ 元，矩形面积是 $32$，一条边是 $4$，另一条边是 $32\div 4 = 8$ 元。行程里两条边是速度和时间，面积是路程。工程里两条边是效率和时间，面积是工作量。

已知面积和一条边，未知边等于面积除以已知边。这就是归一：先把矩形切成一格一格，每格是 $1$ 份。

# 鸡兔的面积置换

$35$ 个头、$94$ 只脚。先画一个面积为 $35\times 4 = 140$ 的矩形，表示全是兔。实际只有 $94$ 只脚，多出来的面积是 $140-94=46$。每把一只兔换成鸡，面积减少 $2$，所以鸡有 $46\div 2 = 23$ 只，兔有 $12$ 只。头数小时也可以先用 [[列表法]] 一行一行试。

口诀：乘出来的量是整段或整块面积；求其中一个边，就用面积除以另一边。面积不变时，一条边变成几倍，另一条边就变成几分之一。
