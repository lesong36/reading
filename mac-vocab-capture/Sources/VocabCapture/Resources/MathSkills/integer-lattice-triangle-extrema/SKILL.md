# 格点三角形面积分类与最小值

## 适用、计数对象和限制
适用于清楚的有限正方格或钉阵：允许点都是整数格点，格距与单位面积明确，求三角形的不同面积种类，或固定一条格点底边的最小非零面积。先辨清“面积种类”“形状”“位置方案”三个不同对象。三个点必须互不相同且不共线。允许范围、是否可选边界点、是否只选某些点必须保留；不能以无界格点的存在性替代题内可行构造。
这里只用长方形和三角形面积、整数乘除及完整有限分类。不要求皮克公式、行列式、鞋带公式或贝祖定理；本技能也不赋予其他格点公式的使用许可。三角格、非整数点、任意连续点或格距不均匀不套下述整数倍下界。截图模糊时先保留待定点，不能将交点四舍五入成格点。

## 每个候选用外框补差，推导半格整数性
给三点围出最小水平竖直外接长方形。正宽高时，四条外框边各须接触至少一个顶点；只有三个顶点，所以至少一个点在外框角上。平移、翻转读格方向，使该角点在左下；这些操作不改面积。以下字母只标记数格所得长度，不用它们列方程求未知数。
- 若另一个顶点在对角，则目标在外框的一半三角形内。用这一半面积减去另两块三角形；两块的底各在外框边上，高由到对应边的横、纵格距读出。每项都是整数底×整数高÷2。若剩余第三点在另一侧，选另一半外框，不能减出负面积再说面积为负。
- 若没有顶点在对角，另两点分别接触右边和上边。令外框宽W、高H，右边点离底b格，上边点离左c格。外框减去底右角、左上角、右上角三块直角三角形：W×H−W×b÷2−H×c÷2−(W−c)×(H−b)÷2。三块完整覆盖外部，只能共边，不能重复扣。
因此每个格点三角形的面积都是半个单位正方格的整数倍。最大也不超过其外框面积的一半：对角构型是半外框减非负块；后一构型用乘法分配律合并两倍面积，得到W×H减b×c，故也至多半个外框。这个结论从具体割补推出，不引用格点面积定理。
共线、同一行或同一列的三点面积为0，按题意排除。物理单位在数格面积后乘；格距为2厘米时小格面积4平方厘米，不能仍乘2。

## 不同面积的完整分类
将允许的点按逐行顺序编号。只取编号i<j<k的三个点，防止顶点换序重复；逐个排除共线，按上述外框补差计算面积。同形平移仍是不同点组，须在随后按面积去重时合并。表中保留“面积—一个合法三点代表”，相同面积的多个形状只占一类。候选数小可完整列举；候选多时先用半格整数性和全图最大外框给可能值，再为每个可能值给合法代表。必须同时证明无其他值和每个所列值均能达到。
例如4行4列、相邻间距1厘米的钉阵，取横纵读格0至3。面积只能是0.5的倍数，至多3×3÷2=4.5；下面九个代表覆盖0.5至4.5全部可能值，故有9种，而不是9个三角形：

| 面积（平方厘米） | 三个读格点 |
|---|---|
| 0.5 | (0,0)、(0,1)、(1,0) |
| 1 | (0,0)、(0,1)、(2,0) |
| 1.5 | (0,0)、(0,1)、(3,0) |
| 2 | (0,0)、(0,2)、(2,0) |
| 2.5 | (0,0)、(1,2)、(3,1) |
| 3 | (0,0)、(0,2)、(3,0) |
| 3.5 | (0,0)、(1,3)、(3,2) |
| 4 | (0,0)、(1,3)、(3,1) |
| 4.5 | (0,0)、(0,3)、(3,0) |

非直角代表也按前节外框减三角形核算，不能只画一个“看起来差不多”的形状。后台可再枚举16点的全部560个无序三点组校对；完整有限检查是复核，不作为要求学生学习组合符号的前提。

## 固定长方形对角线的最小非零面积
只对固定底边是长方形对角线AC的构型使用这一段。以A为读格起点，向右、向下数格，C到A横W、纵H；P的格距是x、y。连接另一个外角，把包含P的半长方形拆成目标PAC与两块底高可读的白三角。两边分别做补差，合并后得到两倍面积为W×y与H×x的差的绝对值。这是当前图的面积加减推导，不能省略推导后要求孩子背通用坐标公式。
若W、H有公因数g，两个乘积和它们的差都是g的倍数，非零面积至少g÷2个单位格。最大公因数给最强的这种整数下界，但还要在允许点集中找到达到点；找不到时只能叫下界，不能直接报最小值。可按允许行列完整列举，逐项算非零差，不调用无界整数解定理。
例如100×80的原图，差必为20的倍数，所以面积至少10。取从A向右1格、向下1格的内部点P，包含P的一半ADC面积4000；两块白三角面积分别80×1÷2=40、100×79÷2=3950，目标4000−40−3950=10。它满足允许范围并达到下界，才可结论最小10。另如12×8全格点，取内部P(1,1)，补差面积2，等于公因数4的一半。

## 边界反例与输出
若6×4矩形只允许P=(1,2)，虽整数下界为1，唯一允许点的面积却为4，不能说最小1。允许P任意移动或含非整数坐标时，整数倍下界失效，通常可逼近底线；固定有限点集则应逐个核查。不要把“不能等于0”漏掉，也不要把半格面积按四舍五入变成整数。
输出面积表或下界与达到点，并附点序、单位和关键补差。图只能展示真实格点、所选代表和辅助外框；无法渲染时保留原图参照与读格表，不编造移动动画或暗中放宽允许范围。
