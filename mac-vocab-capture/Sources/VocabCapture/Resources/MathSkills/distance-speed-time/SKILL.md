# 行程问题

路程、速度、时间是同一套关系的三种问法。相遇看路程和，追及看路程差。讲义 Q4-05 到 Q4-13，火车在 Q5-02、Q5-03。


## 往返行程的图解选择

普通往返或流水往返，先从本题原图确认去程与回程是否走同一段路。路程相同且速度不同时，优先配合 [[列表法]]：去程、回程各一行，路程、速度、时间各一列，两个路程格对应同一个已知或算出的路程。先算去程路程，再用该路程除以回程速度得到回程时间，不能把速度和时间互换。

问题问能否按时返回时，再用 [[线段图]] 表达时间：把去程、回程两个时长首尾相接，下面对齐限时，标出超过或剩余的时间；也可增加总用时与限时的比较表。图上只比较同单位的时长，不把米和分钟画成可直接相加的长度。不因出现“速度×时间”就配面积图；单个面积矩形不能解释上述时间比较。


# 三个基本量

速度是单位时间走的路程。

$$\text{路程} = \text{速度} \times \text{时间}$$

$$\text{速度} = \text{路程} \div \text{时间}$$

$$\text{时间} = \text{路程} \div \text{速度}$$

每分钟 $20$ 米，走 $4$ 分钟，路程是 $20\times 4 = 80$ 米。$100$ 米走 $5$ 分钟，速度是 $100\div 5 = 20$ 米/分。

分段走时，各段路程相加。总路程 $40\times 12 = 480$ 米，前 $2$ 分钟每分钟 $30$ 米走了 $60$ 米，剩下 $420$ 米用 $7$ 分钟，后一段速度是 $420\div 7 = 60$ 米/分。

同一段路、两种走法，时间差乘速度等于路程差。早到和迟到相差 $30$ 分钟，对应的路程差是 $1700-500=1200$ 米，速度是 $1200\div 30 = 40$ 米/分。

# 相遇

两人同时出发，所研究的是两人路程之和，时间相同。相向走到见面，和背向走远，都用这一个公式。

甲每分钟 $71$ 米，乙每分钟 $29$ 米，走了 $4$ 分钟。

$$\text{路程和} = (71+29)\times 4 = 400\text{米}$$

$$\text{相遇时间} = \text{路程和} \div \text{速度和}$$

两人从相距 $100$ 米的 $A$、$B$ 同时相向出发，速度分别为每分钟 $40$ 米与 $60$ 米。第一次相遇用 $100\div(40+60)=1$ 分钟，两人合走了 $1$ 个全程；这个第一次相遇发生在任何一人到对端之前。

**往返第几次不能无条件套公式。** 只有两人等速、异端同时相向出发、到端立即原速返回、没有停留，且只数离散迎面相遇时，第 $n$ 次合走 $2n-1$ 个全程。例如两端距 $100$ 米、两人各每分钟 $50$ 米，迎面相遇为第 $1$、$3$、$5$ 分钟。速度不等、同端出发、可能同到端点、题目把追上也算相遇时，先用 [[行程事件线与周期发车]] 逐次核对方向与时刻。即使某个“奇数全程”时刻位置相同，也可能是端点同到而非迎面，不能直接把代入公式的 $n$ 当成实际计数序号。

# 追及

同向走，快的比慢的每单位时间多走一段，这段就是速度差。追上所用的时间，等于一开始拉开的路程除以速度差。

快的每秒 $8$ 米，慢的每秒 $5$ 米，速度差 $3$ 米。开头拉开 $9$ 米，$9\div 3 = 3$ 秒追上。拉开 $90$ 米，$90\div 3 = 30$ 秒追上。

$$\text{追及时间} = \text{路程差} \div \text{速度差}$$

哥哥 $7$ 点出发，每分钟 $60$ 米。弟弟 $7$ 点 $10$ 分出发，每分钟 $100$ 米。哥哥先走 $60\times 10 = 600$ 米，速度差 $40$ 米/分，弟弟再走 $600\div 40 = 15$ 分钟追上，弟弟走了 $100\times 15 = 1500$ 米。

# 环形

一圈长 $400$ 米，速度 $6$ 米/秒和 $4$ 米/秒，从同一点出发。

同向是追及，路程差是 $1$ 圈：$400\div(6-4)=200$ 秒第一次追上。第 $2$ 次追上，路程差是 $2$ 圈，时间 $800\div 2 = 400$ 秒。

反向是相遇，路程和是 $1$ 圈：$400\div(6+4)=40$ 秒第一次相遇。第 $2$ 次是 $2$ 圈，$80$ 秒。

已知同向 $200$ 秒追上、反向 $50$ 秒相遇：速度差 $400\div 200 = 2$，速度和 $400\div 50 = 8$。再用 [[和差问题]]：$(8+2)\div 2 = 5$，$(8-2)\div 2 = 3$，单位是米/秒。

# 流水行船

顺水速度等于船在静水中的速度加上水速，逆水速度等于静水速度减去水速。

$$v_{\text{顺}} = v_{\text{静}} + v_{\text{水}},\qquad v_{\text{逆}} = v_{\text{静}} - v_{\text{水}}$$

$$v_{\text{静}} = (v_{\text{顺}} + v_{\text{逆}}) \div 2$$

$$v_{\text{水}} = (v_{\text{顺}} - v_{\text{逆}}) \div 2$$

静水 $8$ 千米/时，水速 $2$ 千米/时：顺水 $10$，逆水 $6$。顺水 $20$、逆水 $12$：静水 $(20+12)\div 2 = 16$，水速 $(20-12)\div 2 = 4$。

同一条河上，水速对两船相同。求出一船的水速，可以移到另一船的顺水和逆水上。

# 火车

火车自身有长度。从车头碰到目标，到车尾离开目标，这段时间里火车走过的路程要把车长算进去。

停着的人没有长度：路程等于车长。车长 $300$ 米、速度 $20$ 米/秒，经过这个人用 $300\div 20 = 15$ 秒。

过桥：路程等于桥长加车长。桥 $6000$ 米、车 $300$ 米，$(6000+300)\div 20 = 315$ 秒。车身完全在桥上的那一段时间，路程等于桥长减车长：$(6000-300)\div 20 = 285$ 秒。

两列火车相向错车，从车头相遇到车尾分开：

$$t = (L_1+L_2)\div(v_1+v_2)$$

$300$ 米和 $200$ 米的两车，速度 $20$ 与 $30$ 米/秒：$500\div 50 = 10$ 秒。

同向超车，快车从追上慢车车尾到自己的车尾超过慢车车头：

$$t = (L_1+L_2)\div(v_1-v_2)$$

同样两车、速度 $30$ 与 $20$：$500\div 10 = 50$ 秒。

人迎面或同向被火车经过，把人看成另一段在动的长度。相向时路程和等于车长，同向时路程差等于车长。
