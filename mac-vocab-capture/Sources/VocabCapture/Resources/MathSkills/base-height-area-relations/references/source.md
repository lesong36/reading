# 底高与等积关系

## 何时使用与先决条件
题目涉及平行四边形、三角形、梯形的面积，或通过共底、等高、中点、对角线比较面积时使用。已知小学乘除、分数和面积单位；新公式先用下述拼合解释，再计算。题号、示意图外观和线段倾斜程度都不是长度、垂直、平行或中点的证据。只用原题给定或经证明的关系；无法看清图形时说明缺失信息，不估量求值。未知交点比例、相似三角形平方比、正多边形细分、三角格计量、风车方形剪拼和任意曲线不由本技能自动覆盖。

## 第一步：登记真实区域、底和高
给所求区域及每个补充区域编号，列出顶点、边界、已知共线/平行/垂直及点的先后顺序。选一边作底，高是对面顶点到这条底所在直线的垂直距离；垂足可以落在底的延长线上。梯形的两底必须互相平行，高是两底所在平行线之间的距离。不要将腰长当高，或将原图的横向长度用作另一个方向的高。同一次底高配对要写明理由，单位统一后才能乘。

## 第二步：可执行的面积变换
- 平行四边形：沿垂线剪下边角，平移到另一侧拼成长方形；拼接必须无重叠、无缺口，底和垂直高不变，所以面积＝底×高。钝角且垂足在外时可用两块拼补，不能因图像倾斜改用斜腰。
- 三角形：取两份全等三角形，一份旋转半周，沿对应边拼成同底同高的平行四边形；故一份面积＝底×高÷2。逆求高＝面积×2÷底，逆求底同理；底、高必须为正。
- 梯形：取两份全等梯形，一份旋转半周拼成底为上底加下底、同高的平行四边形；面积＝（上底＋下底）×高÷2。反求底和＝面积×2÷高。不能把不平行的两条边相加当两底。
这些是保面积的拼合说明。作图时标出复制件和移动，不能声称原图多出一块面积。若输出图形工具不能表达切补，保留上述文字证明或清楚的关系表；不以虚构图或无法运行的图代码代替证明。

## 第三步：从等高、共底转移面积
1. 两个三角形的底都在同一直线上，顶点在与底平行的另一条直线上，才可确认等高。它们的面积按底的份数分配：底是3份和5份，面积也是3份和5份。共底时，面积按垂直高的份数分配。顶点在同一条斜线上不保证等高。
2. 顶点P相同，A、B、C依次在同一底线上，B在线段AC内，则三角形PAB与PBC内部不重叠，完整组成PAC，故面积相加，底也相加。若B在线段AC外，应先登记点序再用大三角减小三角，不能一律相加。多个不同顶点若都在同一条平行线上，也可先把各面积写成各底×共同高÷2，再合并底；它们不一定拼成一个大三角形。
3. 已知两块等面积，可从两边同时扣除同一块，剩余仍等面积；或补入同一块。必须指明同一块及两边的完整覆盖，不能凭阴影外形断定等积。求阴影的大减小时逐块登记，重叠只计一次。
4. 平行四边形内，底取完整一边、顶点位于对边上的三角形，面积是整个平行四边形的一半。若底被分成数段、各三角形顶点都在对边直线上，各面积之和也是底段总长×高÷2；顶点无需相同。

## 第四步：中点和对角线
边AB的中点M满足AM＝MB，因此同顶点C的三角形CAM和CMB等面积；“中点”须题给或证明。三角形三边中点D、E、F连成小三角形时，可不用相似：先用AC中点E说明ABE占ABC一半，再用AB中点D说明ADE占ABE一半，所以角部ADE占全形四分之一。同理另外两个角部各四分之一；三块无重叠，加上中间DEF完整覆盖ABC，中间也占四分之一。
平行四边形一条对角线分成两块等面积三角形，各半；可直接用同高同底公式，也可用旋转半周后的全等。两条对角线交点O为中心：以一条对角线的中点旋转半周，因对边平行且等长，另两顶点互换，故另一条对角线也过该中点。于是各半三角形再被中点分半，四个小三角形各占四分之一。一般四边形不具备此结论；不能只看画了两条对角线就四等分。

## 第五步：检验、取舍和输出
先给所求量，再给关键底高理由、面积算式和单位。反求长度后检查它是否落在题目限定线段内；面积不得为负，局部不得超过包含它的全形。有面积和与差时可先求两块的两个候选大小，再结合图形包含关系排除不可能分配。对多小题逐项回答。原图已说明关系时无需另画装饰图；若画辅助线，只添加解释所需的垂线、共底延长线、中点连线，并明确哪些是辅助线。坐标图仅在原题几何约束能被坐标实现且已逐项核验时生成，不编造长度。图和文字的区域、数值与单位必须一致；不支持某种图表不会阻止完成可验证的文字证明。

## 独立正例与可检验算式
平行四边形底18厘米、高7厘米，底分成5厘米、13厘米，各取对边上一点作两个三角形。两顶点可以不同，仍距底线7厘米。面积分别5×7÷2＝17.5、13×7÷2＝45.5平方厘米；和63，等于18×7÷2，是全形126的一半。不能据此说两块必拼成一个三角形。
另一题两个共顶点、同底线的三角形，底分别13厘米和5厘米，第一块面积39平方厘米。共同高39×2÷13＝6厘米，第二块5×6÷2＝15平方厘米；相加54与合底18×6÷2一致。
梯形两底6、14厘米，高5厘米，面积（6＋14）×5÷2＝50平方厘米；复制两份拼得底20、高5的平行四边形，面积100，核对一半50。三角形面积80平方厘米，连三边中点后，三个角部及中间各20，四块和80。

## 反例与拒绝错误套用
平行四边形底10厘米、腰8厘米、对应高6厘米，面积为60而不是80平方厘米；腰不等于高。共底10厘米的两个三角形，高分别3和5厘米，面积15和25，不能仅凭共底判等积。梯形腰8厘米但未给垂直高且不能推出时，不能将8代入梯形公式。
一般梯形取A(0,2)、B(0,0)、C(6,0)、D(2,2)，上底2、下底6、高2，面积8。对角线交点O(1.5,1.5)，靠上底的AOD面积0.5，靠下底的BOC面积4.5，另两块各1.5；合计8但不四等分。坐标只供独立核验此反例，不作为要求学生使用坐标或相似的方法。
