# 有限博弈与必胜策略

## 适用与先决核对
题目给出有限状态、双方轮流且都追求获胜、每步合法动作、终局及谁赢谁输。每次操作让某个非负整数减少，或能列出有限无循环状态时，可从终局逐步倒推。先读清“拿最后一个赢”还是“拿最后一个输”、能否一次拿完、允许跳过吗、是否必须拿相同数。规则缺失不猜；存在重复局面、平局、随机抽取或不完全信息时，不宣称本方法必胜。

## 倒推法
1. 写出局面描述与轮到谁。把终局直接标为胜或负，注意“轮到的人无步可走输”和“刚拿走最后一个的人输”是不同规则。
2. 当前玩家若至少有一步可把对手送入必败局面，则当前必胜，记录这一步。若每个合法后继都让对手必胜，当前必败。不能仅因存在一条赢的走法就忽略对手可以不配合。
3. 从小规模列胜负表，发现规律后还需证明两个方向：每个称为败的位置，所有合法步都会离开败集合；每个称为胜的位置，至少有一步回到败集合。列表几项只供猜测，不是无限外推证明。
4. 给策略时用“对方拿k，我拿……”说明所有合法k，并检查剩余数量是否足够。策略可能只有在自己先走某一步后成立。不能在最后一步要求拿0个或超出允许上限。
5. 题目问必胜者时，可以给策略并指出先后手；题目问可保证的最多得分，还需分别讨论对手最不利的选择，不能按友好配合来算。

## 可复核例题
桌上有17枚棋子，轮流拿1、2或3枚，拿最后一枚者赢。0枚时轮到的人已无步可走，属败；1、2、3可一次拿完属胜；4无论拿几枚都给对方1至3，属败。每个4的倍数拿1至3后都不再是4的倍数；非4倍数可拿其除以4的余数，余数是合法的1至3，留下4的倍数。因此先手拿1留下16，以后对手拿k就拿4−k，始终合法，最后自己取完。检查第二手若拿3，自己拿1；若拿1，自己拿3，不能只写一种回应。

## 反例与终局敏感性
同样17枚和每次1至3，改为拿最后一枚者输，则1枚是败，2至4是胜，5是败，败局是1、5、9、13、17。因此此时先手必败，旧策略不适用。两堆棋子允许从任意一堆拿任意数量也不是单堆模4，不用异或或背诵规则；状态少可列完整后继，状态大且无已证规律则说明边界。

## 输出
用小表或状态图展示倒推依据，给可执行应对与终局验算。完整策略必须覆盖对手所有合法分支。儿童版解释以分组、配对和算术为主，不因出现“游戏”就硬匹配成每次凑固定数。

## 补充校验

验证配对策略时，还要证明它不会在对手行动之前已无棋可取而轮到自己。正向构造与反向胜负表应一致；若某个小状态不吻合，先检查终局定义和动作上限，不把异常当作可忽略的特例。多个玩家、允许联盟或目标是平局的游戏不使用两人零和胜负标记。
