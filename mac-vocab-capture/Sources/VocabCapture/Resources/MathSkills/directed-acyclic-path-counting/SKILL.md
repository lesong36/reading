# 有向网络与单调路径计数

## 范围与先核问题
用于有限有向无环图、只向右和上走的等距方格、逐层向下读字，以及只向右、上、右上任意正步长的皇后路径。必须从实际图面列节点和有向边，不把所有交叉线自动接成路口，也不把真实可换向交点漏掉；箭头、桥跨、实心点、题中约定优先。当前网络的交叉处是否可转弯无法判明时保留两种解释，不能以某种答案反推原图。
先说明计的是路线、落点序列、不同词串还是最短路线。两条路线读出同一串文字，若题问读法/走法，通常仍按不同位置路线计；若明确问不同字符串，必须将字符串集合去重，不能用路径数冒充。不同颜色道路或平行道路是否区分要按题意；确实不同的平行边须保留边编号和重数。

## 1. 实际节点、边与顺序
为节点记录标签及行列坐标；每一条允许移动记为起点→终点，附方向和是否平行边。图中箭头限定向右时，一条从左上到右下的斜线仍向右但向下，不能因为“通常向上”将它删掉。把每节点所有前驱反查完整，尤其终点的最后几条入边。
找到一个顺序，使每条边的起点都排在终点前：可按严格增加的层号或坐标量排序，也可反复取当前没有未处理前驱的节点。若节点尚未处理却找不到这样的点，说明有环或抄错边。本技能不将有环图按普通格网标数。一般图禁止重复节点的简单路径需要状态包含已访问节点集合；此扩展未在这里实施，不声称覆盖。允许绕环的路线还可能无穷多。

## 2. 前驱贡献相加
起点标1，表示尚未走任何边的唯一出发状态；其他点先标0。按上一步顺序处理，将每条到达当前节点的边的起点路线数分别加来，得到当前点路线数。若同一前驱有两条确实不同道路，各贡献一次，也可乘边重数。所有节点完成后取终点数；若到终点即结束，则不再沿其出边继续走。不可到达点保留0。
理由：到达非起点的一条路线有唯一最后一条边，按这条边分类互不重叠，删去最后边后恰对应前驱的一条路线。因此相加不漏也不重。起点等于终点时是否允许零步须按题目，默认上述1仅表示允许原地不动的空路线；要求至少走一步则另处理。

## 3. 方格最短路与禁点
等长水平、竖直格边从左下到右上，最短路线必须恰好向右指定列数、向上指定行数；任何反向都会多走，所以可只保留这两种有向单位边。每格点的数是左邻和下邻数之和；两条轴上可达点标1。原图有缺边就删对应边，不能把矩形中没画出的路补上。
禁点必须不可到达及不可通过，先删点及所有相关边或始终标0再传播；不能先算整表仅在最后把禁点数减1。可用“总路线−经过一个禁点路线”复核，其中经过该点的路线数＝起点到禁点数×禁点到终点数；多个禁点有重叠经过，不能不加处理地逐个相减。含障碍时全局最短路线未必仍单调；若题问允许绕行的真正最短路，须另外先求距离和最短路边，不将这里的单调数当答案。

## 4. 逐层读字
每个字所在位置为独立节点，只连题目允许的下一层相邻位置；不可因文字相同而合并节点。每次恰下一层时层号严格增加，故按层相加。要读指定词时，节点还须匹配该层应读的字；可选起点有多个则各起点标1。最后层所有允许终点的数相加。核对最后一字的所有位置；题只允许到某一指定位置时不能把整层都加进来。

## 5. 皇后长步必须重建边
棋盘格内落子时，状态是每格中心，不是棋盘线交点；4×4棋盘只有16个落点，左下(0,0)，右上(3,3)。每次可向右、上或右上移动任意正整数格，则从(x,y)分别连到(x+k,y)、(x,y+k)、(x+k,y+k)，直到边界，k从1开始；不许零步，也不许右下。每步x+y都增加，按该和排序可保证先处理全部前驱。
在落点(x,y)处，需累加同一行左侧全部落点、同一列下侧全部落点、左下同斜线全部落点的路线数；不是仅左、下、左下三个近邻。一次跳两格与分两次走各一格是不同落点序列，题计走法时都要算。一次跳过的中间格不是新落点，不能再为未停留的位置产生多份路线。
有禁点或挡子时先澄清：只禁落地可以跨越；禁通过或实体挡子则任何穿越它的长边也删去，不能只删落点。原题没有障碍就不擅加棋子。此技能不处理可左下移动的普通皇后全盘任意路线。

## 独立例与反例
等距2×1格网从(0,0)到(2,1)仅右上单位步：底行1、1、1，上行1、2、3，共3条。若禁(1,0)，则只能先上再右右，共1条，可用3−1×2＝1核对。
皇后在2×2棋盘从左下到右上有3条：右上一步、先右后上、先上后右。把它当只右上格网会得到2而漏直达；只许单位对角则在更大棋盘会漏长步。另一网络S→A、S→B、A→T、B→T有2条，即使A和B都标字“京”且S/T标“北/奥”，两路线的词串同为“北京奥”；路径数2、不同字符串数1。
若A→B、B→A形成环且还能到T，不能依任意节点顺序相加。若额外禁止重复节点，状态必须记录已访问集合；本技能明确排除此分支，不能删除一条回边来凑DAG。

## 输出与复核
先给真实节点/边及方向约定，再给按顺序的标数表、终点值和一条合法路线。说明是否包含交叉转弯、长跳、禁通过和空路线。小图可用逐条枚举与标数独立核对；两个实现共用同一个误抄图仍可能同时错，所以必须另与原图对照。方法输出可用Markdown表或边列表，不声称新增自动识图或通用执行工具。
