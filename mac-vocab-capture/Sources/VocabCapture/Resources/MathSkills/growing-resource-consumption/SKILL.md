# 牛吃草问题

草每天都在长，牛每天都在吃。两次不同的吃法，可以求出草每天长多少、原来有多少。讲义 Q5-01。

# 两次吃法求草速

把一头牛一天吃的草记作 $1$ 份。$7$ 头牛 $5$ 天吃完，一共吃了 $7\times 5 = 35$ 份。$9$ 头牛 $3$ 天吃完，一共吃了 $9\times 3 = 27$ 份。

多出来的 $2$ 天，草又长出了 $35-27=8$ 份，草每天长 $8\div(5-3)=4$ 份。

原来的草等于某一组总消耗减去这段时间新长的草：$35-5\times 4 = 15$ 份。

$$\text{草每天长的} = (\text{总消耗}_1 - \text{总消耗}_2) \div (\text{天数}_1 - \text{天数}_2)$$

$$\text{原有草} = \text{总消耗} - \text{天数} \times \text{草每天长的}$$

天数长的那一次，总消耗更大，因为它把后长出来的草也吃了。

# 再问还能吃几天

$5$ 头牛去吃。每天长 $4$ 份，$5$ 头牛每天净吃 $5-4=1$ 份，原有 $15$ 份，$15\div 1 = 15$ 天吃完。

$$\text{天数} = \text{原有草} \div (\text{牛数} - \text{草每天长的})$$

牛数必须大于草每天长的份数，草才会被吃完。

另一组数：$14$ 头牛 $20$ 天吃 $280$ 份，$21$ 头牛 $10$ 天吃 $210$ 份。草每天长 $(280-210)\div(20-10)=7$ 份，原有 $280-20\times 7 = 140$ 份。$12$ 头牛每天净吃 $12-7=5$ 份，$140\div 5 = 28$ 天。

# 牛的只数中途改变

先把每一段的“牛数 $\times$ 天数”加起来，得到这一段的总消耗，再和另一段比较，求草速。$15$ 头牛吃 $8$ 天是 $120$ 份；$15$ 头牛吃 $2$ 天再加 $17$ 头牛吃 $5$ 天，是 $15\times 2+17\times 5 = 115$ 份，天数 $7$。草每天长 $(120-115)\div(8-7)=5$ 份，原有 $120-8\times 5 = 80$ 份。

# 羊和牛混在一起

先规定几只羊相当于 $1$ 头牛，全部换成牛，再按上面的步骤算。$3$ 只羊相当于 $1$ 头牛时，$36$ 只羊是 $12$ 头牛。
