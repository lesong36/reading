# 鸡兔同笼

头的总数和腿的总数都知道，求两种动物各有多少。讲义 Q4-01、Q4-02。核心算法是假设调整：先当成同一种，再按每换一只多出来或少掉的腿数改回去。

# 假设全是鸡

$5$ 个头、$14$ 条腿。鸡 $2$ 条腿，兔 $4$ 条腿。

1. 假设 $5$ 只全是鸡，腿数是 $5 \times 2 = 10$。
2. 实际有 $14$ 条腿，少了 $14-10=4$ 条。
3. 每把 $1$ 只鸡换成兔，腿数增加 $4-2=2$。
4. 要换 $4\div 2 = 2$ 只兔。鸡是 $5-2=3$ 只。

# 假设全是兔

$5$ 只兔有 $5\times 4 = 20$ 条腿，比实际多 $20-14=6$ 条。每把 $1$ 只兔换成鸡，腿数减少 $2$，要换 $6\div 2 = 3$ 只鸡。兔仍是 $2$ 只。

$$\text{兔} = (\text{实际腿数} - \text{头数}\times 2) \div (4-2)$$

$$\text{鸡} = \text{头数} - \text{兔}$$

头数很小的时候，也可以从 $0$ 只兔列表试到全部是兔，看哪一行的腿数正好。头数一大，假设调整更直接。

# 倒扣

每做对一份得 $5$ 元，做错倒扣 $10$ 元。按全部做对应得 $500\times 5 = 2500$ 元，实际只得 $1000$ 元，多算了 $1500$ 元。每把一份从“做对”改成“做错”，收入减少 $5+10=15$ 元。要改 $1500\div 15 = 100$ 份。

倒扣时，每调整一次的差额等于原来的得分再加上被扣掉的分数。试卷题也是这样：先按全部做对算出应得分数，再看实际少了多少分，除以“改错一道所减少的分数”。

# 有倍数时打包

兔的只数和鸡的只数成倍数时，把“$1$ 只兔加若干只鸡”打成一包，先除出包数。例如每包 $1$ 只兔和 $3$ 只鸡，一包 $4+2+2+2=10$ 条腿，总腿数 $110$，包数 $110\div 10 = 11$，鸡是 $11\times 3 = 33$ 只。

口诀：先假设成同一种，腿数差除以每换一只的腿数差。

# 第二种：知道脚数差

鸡兔共 $100$ 只，鸡的脚比兔的脚多 $80$ 只。假设全是鸡，每只 $2$ 只脚，脚数差要这样用：

$$\text{兔数} = (2 \times \text{总数} - \text{鸡脚与兔脚之差}) \div (4+2)$$

$$(2 \times 100 - 80) \div 6 = 20$$

兔 $20$ 只，鸡 $80$ 只。鸡脚 $160$，兔脚 $80$，差正好是 $80$。

假设全是兔时，鸡数等于 $(4 \times \text{总数} + \text{脚数差}) \div 6$。

# 单价不同也是同一种假设

$45$ 本本子共 $69$ 元，作业本每本 $3.20$ 元，日记本每本 $0.70$ 元。假设全是日记本，再把多出来的钱除以两种单价的差：

$$(69 - 0.70 \times 45) \div (3.20 - 0.70) = 15$$

作业本 $15$ 本，日记本 $30$ 本。

$100$ 个和尚吃 $100$ 个馍，大和尚每人 $3$ 个，小和尚 $3$ 人吃 $1$ 个。假设全是大和尚，要吃 $300$ 个，多出 $200$ 个。每把一个大和尚换成小和尚，少吃 $3 - \dfrac{1}{3} = \dfrac{8}{3}$ 个。小和尚有 $200 \div \dfrac{8}{3} = 75$ 人，大和尚 $25$ 人。
