# 部分整体图

一条完整线段是整体，截开的每一段是一个部分。部分拼起来是整体，从整体上裁掉已知部分就得到另一部分。课堂里的部分整体模型就是按这个画的。

$$\text{整体} = \text{部分} + \text{部分}$$

$$\text{另一部分} = \text{整体} - \text{已知部分}$$

# 怎么画

1. 先画一条线段，标上整体；整体还不知道时，先留下问号。
2. 已知的部分按数量截成小段，标在线段上。
3. 问的是整体，就把各段相加。问的是缺的那一段，就用整体减去已经画上的段。

$30$ 和 $50$ 拼成一条线段，整体是 $30+50=80$。整体是 $80$、其中一段是 $30$，另一段就是 $80-30=50$。

# 同一张表有两种整体

上午教师 $15$ 人、学生 $32$ 人，一共 $47$ 人。下午教师 $24$ 人、学生 $50$ 人，一共 $74$ 人。

按时间把上午、下午拼起来：$47+74=121$。按身份把教师、学生拼起来：$15+24=39$，$32+50=82$，$39+82=121$。两种拼法得到同一条总线段。表里缺的一格，用它所在的行或列去减已经知道的部分。

社团一共 $95$ 人，男生一共 $50$ 人，女生就是 $95-50=45$。舞蹈女生 $22$、美术女生 $18$，科技女生是 $45-22-18=5$。科技男生 $27$，科技总人数是 $27+5=32$。

# 先乘出每一段，再拼成整体

大巴每辆 $60$ 人坐 $8$ 辆，中巴每辆 $40$ 人坐 $5$ 辆，小巴每辆 $8$ 人坐 $2$ 辆。先把每一段算成一条小线段，再拼起来：

$$8\times 60 + 5\times 40 + 2\times 8 = 480+200+16 = 696$$

另一种方案少了一辆中巴，从小巴上坐的人就是从 $696$ 里裁掉大巴和剩下的中巴。这是 [[归一与归总]] 画在同一条线段上的样子。
