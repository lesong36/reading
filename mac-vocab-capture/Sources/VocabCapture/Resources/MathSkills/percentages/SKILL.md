# 百分数问题

百分数只表示率，不表示具体的量。一个百分点就是 $1\%$。来源是应用题宝典。它和 [[量率问题]] 用的是同一套单位一，只是率写成了百分之几。

$$\text{百分数} = \text{比较量} \div \text{标准量}$$

$$\text{标准量} = \text{比较量} \div \text{百分数}$$

$$\text{比较量} = \text{标准量} \times \text{百分数}$$

# 三种基本问法

求一个数是另一个数的百分之几：比较量除以标准量。化肥用去 $720$ 千克，剩下 $6480$ 千克。用去的占原来的 $720 \div (720+6480) = 10\%$，剩下的占 $90\%$。

已知一个数，求它的百分之几是多少：标准量乘百分数。

已知一个数的百分之几是多少，求这个数：比较量除以百分数。

# 谁是标准量

男职工 $420$ 人，女职工 $525$ 人。

男的比女的少百分之几，标准量是女的：$(525-420)\div 525 = 20\%$。

女的比男的多百分之几，标准量是男的：$(525-420)\div 420 = 25\%$。

两句问的不是同一个标准量，所以 $20\%$ 和 $25\%$ 同时成立。

# 常见的百分率

增长率是增长数除以原来的数。合格率、出勤率、发芽率、成活率、出粉率、及格率，都是“符合条件的数量”除以“参加比较的总数量”。分母是题目里被当作整体的那一个数。
