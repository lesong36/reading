# 对手人数与地区身份推理

## 不同对手与关系口径
适用于人物与地区一一对应，题目同时给出和几名不同运动员比赛过、某些人相互交手或从未交手的身份题。用一条无方向连线表示两人比赛过，重复比赛仍只有一名对手；不能用比赛场次代替对手人数，也不能把比赛过变成战胜。自己不能与自己比赛。朋友或“某人与某地区运动员”若表明两个不同的人，须排除同一身份。项目补充方法须遵守用户拓展知识权限。

## 关系与身份联合传播
先把三人互相交手补齐三条线，因此三人每人至少有两名对手。记录每人的确切对手数、已知连线和已知未赛关系；未知关系保持未知。若某人已知对手数与某地区至少对手数冲突，排除该身份。身份确定后把其关系移到地区标签，再传播已赛/未赛和每人可剩多少对手。一个已知有若干对手的人，在排除自己及明确没比赛的对象后，剩下的人数恰等于配额时，全部必须连线。仍有分支时试各身份并保留全部合法解，无解则报告条件冲突，不能只找到一图就宣称唯一。

## 原题完整推理
五人李平、陈兵、林华、赵新、张强分别来自湖北、广东、福建、北京、上海。李平只和另外两名运动员比赛过；上海运动员和另外三名比赛过；陈兵与广东运动员是好朋友且从未比赛；福建运动员与林华比赛过；赵新只与一名运动员比赛过；广东、福建、北京三人都相互交过手。求张强的地区。

1. 广东、福建、北京互相交手，所以各至少有两名对手；上海有三名对手。赵新只有一名，不能来自这四地区，故赵新来自湖北。
2. 陈兵与广东运动员是两个人，故不是广东；也不是福建或北京，因为这两人都与广东赛过，而陈兵从未与广东赛过。湖北已是赵新，因此陈兵来自上海。
3. 上海有三名对手，却没有与广东比赛。另四地区去掉广东，只剩湖北、福建、北京，这三人必须都与上海赛过。福建和北京各已有广东、彼此以及上海三名不同对手。
4. 李平只有两名对手，不是至少三名对手的上海、福建、北京，也不是已确定赵新的湖北，所以李平来自广东。
5. 剩下林华和张强对应福建、北京。福建运动员与林华比赛过，不能是自己和自己赛，所以林华不是福建，而是北京；张强来自福建。

不要在步骤3前就把福建、北京的两名已知对手说成总共三名。第三名上海是陈兵身份和上海三名配额推出的，必须说明。

|---|---|---|

| 林华 | 北京 | 3 |
| 赵新 | 湖北 | 1 |
| 张强 | 福建 | 3 |

已赛对为广东—福建、广东—北京、福建—北京、上海—湖北、上海—福建、上海—北京；陈兵上海与广东没赛过，福建与林华北京赛过。湖北只与上海赛过，不能再补未知边。六条线均计两端，总对手数12等于6条线的两倍；这是回代检查，不单凭总和认定每条条件都满足。
