# 旋转数码与双向和约束

## 先确认读数约定
适用于题目明确把纸面或整幅图旋转180度后仍须读数并满足条件的填数题。不是镜像，也不是只把数字先后倒序。先从原图字体或题目示范确认哪些数码旋转后仍是数码；常见本题约定为0→0、1→1、8→8、6→9、9→6。2、5、7等不能仅凭想象加入映射；电子字形与印刷体可能不同，原图未能确定时先指出不确定。多位数必须同时倒置位次和变换每一数码，例如19倒看是61，86倒看是98，69倒看仍69。读不出、出现未约定前导零或小数点位置不明时，不能当有效普通整数。

## 正看与倒看分别列配对条件
1. 给原图位置命名，登记每条要求相等的线或区域；旋转后位置也互换，逐线对应原题，不把一条线的条件遗漏。
2. 先由已给端点和目标和求中间空格之和；再用旋转后的端点求对应倒看空格之和。两份条件须同时成立。旋转变换不是加法，不能用“两个数之和倒看”等于“各自倒看再相加”。
3. 如果已知空格内两数和为S，正整数候选各小于S，按允许数码逐个试一数x，另一数为S−x，只保留两数均可倒看且倒看之和合要求的组合；若是多位数或允许0，按题给数域调整边界。不是任意截断无上界的自然数搜索。
4. 配对后按原位置填入；回查每条正看线、倒看线及区域和，最后核查题目有无互异、位数或禁止重复给定数等额外限制。未要求唯一时给一种即可，不虚称唯一。

## 原图20-16的完整构造
大方形四角按左上19、右上91、左下86、右下68登记。正看总和264；倒看分别61、16、98、89，总和也264。

左上到右下对角线的两空和为264−19−68＝177，其倒看两空和须为264−61−89＝114；另一对角线两空和为264−91−86＝87，倒看两空和须为264−16−98＝150。

小方形按左上81、右上18、左下69、右下96填写。正看两对角线分别19+81+96+68＝264、91+18+69+86＝264；小方形81+18+69+96＝264。倒看时原数各变为18、81、69、96，两条对角线各为61+18+96+89＝264、16+81+69+98＝264，小方形18+81+69+96＝264。整图旋转会把对角线上顺序反转，但不改变这条线的和。这是满足全部要求的一种构造，不是唯一解断言。

## 原创迁移和误用边界
两个正整数正看和107，倒看和194，可取18与89：18+89＝107，81+68＝149，故这组不合要求；不能只核正看。改要求倒看和149时这组才可用。另如16与91正看107，倒看91与16和107，不满足149，说明不能只按正看总和判断。

字体未给出2或5旋转的合法性，不强行读作5或2；若题目是左右镜像，不能用本方法的180度规则。只有普通和相等、没有旋转条件时不必调用此方法。图解只有有助于说明位置对应时才需要；可用位置表或原图标号，不强制生成面积图。
