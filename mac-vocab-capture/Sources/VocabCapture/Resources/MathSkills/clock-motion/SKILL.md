# 时钟问题

时针和分针都在顺时针走，夹角就是它们的路程差。这是环形上的追及，偶而也是相遇。讲义 Q6-10、Q6-11。

分针每分钟走 $6°$，时针每分钟走 $0.5°$。速度差是 $5.5°$/分，一圈是 $360°$，每个钟点的刻度相距 $30°$。

# 求夹角

从 $12$ 点开始，$25$ 分时分针走了 $6\times 25 = 150°$，时针走了 $0.5\times 25 = 12.5°$，夹角是 $150-12.5 = 137.5°$。直接用速度差：$(6-0.5)\times 25 = 137.5°$。

从 $3$ 点起算时，时针已经在 $90°$ 的位置。$3$ 点 $40$ 分，分针比 $3$ 点的时针多走 $(6-0.5)\times 40 = 220°$，再减去一开始的 $90°$，夹角是 $220-90 = 130°$。

$$\text{夹角} = \text{速度差} \times \text{分钟数} \pm \text{整点时已有的夹角}$$

# 求重合和垂直

$1$ 点时，时针在 $30°$，分针在 $0°$。分针追上时针：

$$\text{时间} = 30 \div (6-0.5) = \frac{60}{11}\text{分钟}$$

也就是 $1$ 点 $5\dfrac{5}{11}$ 分。

垂直有两种：分针领先时针 $90°$，或领先 $270°$。路程差分别是 $30+90=120°$ 和 $30+270=300°$，时间是 $120\div 5.5$ 和 $300\div 5.5$ 分钟。

# 刻度两侧一样远

$5$ 点的刻度在 $150°$。分针和时针重合，都在 $5$ 的同一侧，这是追及：$150\div 5.5 = \dfrac{300}{11}$ 分钟。

分针和时针分列 $5$ 的两边、到 $5$ 一样远，这是相遇，速度和是 $6+0.5=6.5$：$150\div 6.5 = \dfrac{300}{13}$ 分钟。

# 镜面和走时不准

镜中的时间和真实时间，关于 $12$ 和 $6$ 的连线对称。镜面时间加上真实时间等于 $12$ 点。镜里看到 $10:45$，真实时间是 $12:00$ 减去 $10:45$，即 $1:15$。

表走得慢时，标准时间与表上走过的时间之比不变。标准走 $61$ 分钟、慢表只显示走了 $60$ 分钟，则标准走 $60$ 分钟时，慢表少走的是 $60\div 61$ 分钟。
