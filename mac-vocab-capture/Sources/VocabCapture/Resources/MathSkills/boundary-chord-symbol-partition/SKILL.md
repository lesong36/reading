# 边界选点直线分区与图形计数

## 适用条件
原题提供清晰的边界点和图形实际位置，要求选点连线，将整幅图划成指定区域，每个区域容纳指定数目的图形。先核对边界点总数、图形种类和数量、线段数及每区要求。图形的整个轮廓必须在区域内，不能只用中心点判定。只在图面及约束相同的情况下采用下面的具体连接。

## 构造与核对
对原卷图4-4，正方形每边10个间隔，四角各计一次，共40点。从左上角起按顺时针编号0至39。连接2至22、9至33、15至31；三线使用六个不同端点，形成六个区域。逐区域核对，均为一个三角形和两个小正方形；线段不穿过图形轮廓。这与原卷参考图对应。若题图位置有变化，不能照搬编号。

一般题按边界点编号，先选连线，再逐区核对图形完整轮廓、数量、连通性、端点和线段数。若线穿过图形、某区为空、遗漏图形、端点重复或分区数量不符，应更换连线。仅在图形位置及线段规则已明确时做有限试验；图片模糊或无绘图能力时说明不能确认具体连法，不能声称已画图。六区每区一三角和两方格意味着总共六个三角和十二个方格，但数量匹配本身不保证连法存在。

## 图形展示
在原图上标六个端点和三条线，或画保留原图相对位置的可校验示意；显示不支持时保留文字说明，不伪称图已生成。方法不假设任何没有给出的对称、等距或图形坐标。
