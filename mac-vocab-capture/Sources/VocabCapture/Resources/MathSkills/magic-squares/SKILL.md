# 幻方问题

把 $n \times n$ 个自然数填进正方形，使每行、每列、两条对角线上的和都等于同一个数，这个和叫幻和。来源是应用题宝典。

$$幻和 = \text{全部数的和} \div n$$

$1$ 到 $9$ 的三级幻方，幻和是 $45 \div 3 = 15$。$2$ 到 $10$ 的幻和是 $54 \div 3 = 18$。

# 先定中心

中心格同时在中行、中列和两条对角线上，一共被用 $4$ 次。四角各被用 $3$ 次，每边中点各被用 $2$ 次。

$1$ 到 $9$ 填三级幻方时，八条线上的和都是 $15$。把全部数的和补上中心被多用的次数：

$$45 + 3x = 15 \times 4,\qquad x = 5$$

中心是 $5$。四个偶数放四角，其余奇数放四边中点。一种填法是：

|$2$|$7$|$6$|
|$9$|$5$|$1$|
|$4$|$3$|$8$|

# $2$ 到 $10$

幻和 $18$。写出和为 $18$ 的三数组，看每个数出现几次。$6$ 出现 $4$ 次，放中心。$9$、$7$、$5$、$3$ 各出现 $3$ 次，放四角。其余放四边中点，并让每条对角线的和仍是 $18$。

口诀：先求幻和，再按被用的次数安排中心、四角和四边。
