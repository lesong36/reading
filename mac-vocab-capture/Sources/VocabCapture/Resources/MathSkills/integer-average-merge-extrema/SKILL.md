# 同奇偶取平均合并的终值极值

## 适用与规则
黑板上有有限个整数，每次选两个同奇偶整数，擦去并写下它们的平均数，直到只剩一个。先确认是否有重复数字、每步选两数还是两种不同数、是否必须同奇偶、是否保证能进行到最后。选同奇偶是为了平均数为整数；不因此认为平均数的奇偶与两数相同。保留各个数的实际份数，擦掉两个再添一个。

## 先证明界，再构造
两数的平均数介于两数之间，因此每次操作不会产生超过当前最大值的数。若初始最大数只出现一次且还有其他数，最终不可能仍为这个最大数：一次合并产生最大值，两个输入都必须是最大值；而不同于最大值的初始数总有一条合并链通向最后结果，在其第一次与最大值来源合并时结果严格变小。故最终整数至多为初始最大数减一；这只是上界，必须另找满足每步奇偶条件的合并序列证明能达到。若最大数有多份仍有非最大数，也须说明全部初始数均进入最终合并链；不能只凭最大数出现次数推断任意改变规则的情形。

## 原题例
初始1至10各一个，每次取同奇偶的两个数换成平均数，最后剩一个自然数。所有初始数都经合并进入最后数；要得到10，每次通向最终10的两个输入都必须为10，但最初只有一个10且还含其他数，不可能。最终为整数，故至多9。依次操作：1与3变2；两个2变2；2与4变3；3与5变4；4与6变5；5与7变6；6与8变7；7与9变8；8与10变9。每次两数同奇偶，其他未选数字保留，最后只剩9，达到上界。

## 边界与回查
逐步检查所选数确实存在、奇偶相同、平均后数量减少1；不能重复使用已经擦去的数。若终止前不存在合法配对，应报告该分支无法完成，不能擅自允许非整数平均。允许多个数同时合并或对整数范围有别的规定时须重新证明。
