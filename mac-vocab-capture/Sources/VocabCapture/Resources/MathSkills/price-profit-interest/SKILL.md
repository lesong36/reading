# 经济问题

先分清钱是相对谁算的。利润相对成本，折扣相对原价。讲义 Q6-08、Q6-09。

# 利润

$$\text{利润} = \text{售价} - \text{成本}$$

$$\text{利润率} = \text{利润} \div \text{成本}$$

售价 $80$ 元、成本 $10$ 元，利润是 $70$ 元。定价还没卖出时，期望利润等于定价减成本。

利润率的分母是成本。同样赚 $10$ 元，成本 $100$ 元时利润率是 $10\%$，成本 $1$ 元时利润率是 $1000\%$。

售价等于成本乘 $(1+\text{利润率})$。总成本 $18000$ 元、利润率 $25\%$ 时，总销售额是 $18000\times 1.25 = 22500$ 元。

# 折扣

$$\text{折数} = \frac{\text{售价}}{\text{原价}} \times 10$$

原价 $100$ 元、售价 $80$ 元，是 $8$ 折。定价 $300$ 元、成本 $100$ 元，期望利润率是 $(300-100)\div 100 = 200\%$。打六折以后实际售价 $300\times 0.6 = 180$ 元，实际利润 $80$ 元，实际利润率是 $80\%$。

比较几种优惠时，用实际付出的钱，除以拿到的商品原来值多少钱。

原价 $100$ 元付 $80$ 元，折扣率是 $80\div 100 = 0.8$。买 $100$ 元再送一张价值 $10$ 元的券，付 $80$ 元拿到的原价是 $110$ 元，折扣率是 $80\div 110$。直接少付 $10$ 元，实付 $70$ 元，折扣率是 $70\div 100 = 0.7$。买四送一，付 $4$ 份得到 $5$ 份，折扣率是 $4\div 5 = 0.8$。

# 存款利息

利息由本金、利率、存期三个量决定。

$$\text{利息} = \text{本金} \times \text{存期} \times \text{利率}$$

$$\text{本利和} = \text{本金} \times (1 + \text{利率} \times \text{存期})$$

存入 $1200$ 元，月利率 $0.8\%$，取出本利和 $1488$ 元。利息是 $288$ 元，存期是 $288 \div 1200 \div 0.8\% = 30$ 个月。

分段存和一直存要分开算。先存二年期、到期把本利和再存三年期，第二段的本金已经包含第一段的利息。直存五年期则用原本金乘五年利率再乘 $5$。

# 先涨后跌

涨 $10\%$ 再跌 $10\%$，结果是原来的 $1.1\times 0.9 = 0.99$，也就是 $99\%$。先乘 $1.1$ 再乘 $0.9$，和起点的具体价钱无关。

# 分段计价

先按原价落在哪一段，再用那一段的折扣。已知折后价反推原价时，每一种折扣都除一次，再检查除出来的原价是不是落在这种折扣自己的那一段里。落在段外的结果舍去。
