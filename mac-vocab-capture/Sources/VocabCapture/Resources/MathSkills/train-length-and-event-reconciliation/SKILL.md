# 火车车长与多事件对齐

## 适用条件与基本记录
恒速行驶的火车、行人或骑车人多次相遇、追及、超越，已知车长关系、车头车尾事件和经过时间，要求车长、时刻、距离或两车完全错开时间。先统一米、秒和钟点；把人看作质点仅在题意允许时使用。每个“追上、相遇”判断是否车头到人/车头，每个“离开、超过、完全错开”判断是否车尾通过。速差须是同向后车快于前方，迎面用速度和；同一火车多次完整过人，所通过的相对路程是同一个车长。速度变化、等待、未知观察端点或不确定方向时分别列分支，不凭一个公式断言唯一答案。需要沿线图时可列同一时钟的事件表，图并非所有数值题必需。

## 不同车长与同一观察者的份数比较
两车过同一人的长度可分别写成“各自相对人的速度×通过秒数”；有车长和车速倍数时，用同一速度份比较两式。不要把12秒和30秒当成一个共同经过时间。求出速度比例后，以人作为共同观察对象：两车头先后经过人的两个钟点之间，前者远离人、后者接近人，间隔按两相对速度之比划分；最后错开时间是两车车长之和除相向速度和。

例：8:00货车头追上人，30秒后货尾过人；9:30客车头迎人，12秒后客尾过人；客长2倍货长、客速3倍货速。人速作1份，则货长30×(货速份−1)，客长12×(3×货速份+1)；同车长关系给货速3份、客速9份，可用补偿比较：30份货速减30份人速，等于18份货速加6份人速，所以12份货速等于36份人速。货相对人2份，客相对人10份，90分钟按2:10分割，两车头8:00后75分钟即9:15相遇。货长60份、客长120份，两车合速12份，错开180÷12=15秒。最后代回两次过人秒数与车长倍数。

## 两次过人推两人再相遇
已知车速和车长，先分别由追过人、迎面过人的车长除时间得到相对速度，再扣除或比较车速求人的地速；若方向未知保留可行分支。选第一个车头遇人钟点为基准，把第二次车头遇人的时刻减去它，车头与第一人的相对位移就是第二次时两人的间距。此后两人相向用速度和求时间，换回真实钟点。

例：车长110米、车速30千米/小时即25/3米/秒，14:10追上北行工人、15秒后离开，相对速110÷15=22/3，工人1米/秒；14:16车头迎面遇南行学生、12秒后离开，合速110÷12=55/6，学生5/6米/秒。360秒内车头比工人多走(25/3−1)×360=2640米，14:16时学生与工人间隔2640米；相向速度11/6米/秒，再过1440秒即24分钟相遇，14:40。验证所有方向、单位及钟点。

## 同车长两次追人并反推钟点
同车分别追上两个同向且速率已知的人，用“车长=第一次相对速度×第一次过人时间=第二次相对速度×第二次过人时间”比较；将已知的人速差乘各自对应时间，通过抵消共同车长求车速。再以两次车头追上时刻的差，算车与第二人的追近路程；该路程就是第一次事件时车头与第二人的距离；车头当时与第一人同处，所以也是该时刻两人间距。两人确由同一地点、同一时刻出发时，间距除人速差反推出发时刻；将出发至首次追上间的车与第一人相对路程算成火车当时距出发点的距离。出发条件、方向或过人起止不同则不能直接套用。

例：行人2米/秒、骑车人5米/秒，9:10车头追行人、20秒完全通过；9:18追骑车人、26秒通过。同一车长，20×(车速−2)=26×(车速−5)，用差额抵消得到车速15米/秒，长260米。两事件相隔480秒，车相对骑车人追近10×480=4800米，9:10时车头与行人同处，因此骑车人领先行人4800米。两人同地同时出发，4800÷3=1600秒，出发08:43:20；当时车在A城后方(15−2)×1600=20800米=20.8千米。逐项回代20秒、26秒及全部问项。

## 三车共时端点与等差车长
先列同一时刻各车头尾关系，用相对位移而非将两车长直接相加。甲丙车尾先齐，甲较快且同向，经过t时车头齐，则甲丙车长差等于t内相对位移；再经过u时甲尾与丙头齐，则从最初齐尾到此的(t+u)内相对位移等于丙长。两式按同一相对速度比较得到甲长和丙长的份数。若乙长是甲丙等差中项，乙长是两者平均，注意题目只说居中不代表三个速度相等。乙与丙反向且由车头相遇到车尾错开用u秒时，乙丙速度和=(乙长+丙长)÷u。甲乙速度和再加上甲相对丙速度；甲乙错开用两车长之和除该速度和。

例：齐尾10秒后甲、乙、丙三车头相遇，再过15秒甲恰全超丙、丙乙恰错开，乙长为甲丙中项。以丙长为5份，相对速度为5÷25=1/5份/秒，前10秒车长差2份，甲长3份，乙长4份。乙丙合速(4+5)÷15=3/5份/秒，甲乙合速3/5+1/5=4/5份/秒，甲乙车长和7份，完全错开7÷(4/5)=8.75秒。反查第10秒头齐、第25秒尾头齐、乙丙15秒错开。若“超过”仅指车头而非车尾，或车长不成等差、车不恒速，不能照此求解。

## 结果核查
逐条列出所求并回代每个观察时刻、通过时间、车长、方向；不可把相遇钟点当通过秒数，也不可把速度份数的比例尺度当成现实米数。已知两点只有距离而无方向时保留两侧分支，用车长或运动方向条件筛选。信息缺失时说明不能唯一确定，不补造题面。
