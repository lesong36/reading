# 还原问题

题目从原来的数出发，做了一串运算，最后告诉结果。还原从结果出发，逆着走回去：加变减，减变加，乘变除，除变乘。讲义 Q4-14。量率里从后往前倒推，用的是同一件事，见 [[量率问题]]。

# 一步一步倒

一个数加 $5$，再除以 $3$，商 $5$ 余 $2$。被除数等于商乘除数再加余数：$3\times 5+2=17$。这个 $17$ 是加过 $5$ 以后的数，原来的数是 $17-5=12$。

花掉 $5$ 元以后再花掉一半，还剩 $20$ 元。剩的 $20$ 元是一半，花掉一半之前有 $40$ 元，再把先花的 $5$ 元加回，原来有 $45$ 元。

三天花钱，最后剩 $5$ 元。第三天花了 $3$ 元，花之前有 $5+3=8$ 元。第二天是“花去一半多 $1$ 元”，所以花之前是 $(8+1)\times 2 = 18$ 元。第一天下午若是再花掉一半，花之前是 $18\times 2 = 36$ 元。

# 做法

1. 把题目的运算按时间排成一条链，标出最后的结果。
2. 从最后一步开始，每一步换成逆运算。
3. “一半多几”先把多出来的加回去，再乘 $2$。“一半少几”先把少掉的减去，再乘 $2$。
4. 有余数的除法，先还原被除数：商 $\times$ 除数 $+$ 余数。
5. 走回开头以后，再按原顺序算一遍，看是否回到题目给的结果。

## 删除首项并添平均数：先检查是否丢失信息
若三个有顺序的数为甲、乙、丙，操作是删除甲，并在末尾写乙丙的平均数，新状态是乙、丙、(乙+丙)÷2。结果完全不含甲，不能直接用“平均数乘2”找回甲；同一结果可以来自多个甲。仅在题目另给操作前总和时，才可用原总和减乙减丙还原甲。必须记录有顺序的完整三数和操作次数，不能把三数随意交换。
连续操作时，新添数形成递推链。若最后三个数的最后一个是前两个的平均数，最后总和必为最后一个的3倍；据此确定末项后，仍须保留前两个的可能分配。已知连续三个新添数中的后两项及其平均关系，可以“新平均数乘2减已知数”倒推出另一项；这与恢复最初被删除的首项不同。最终用最初总和补回首项，再按原规则逐步验算。

## 数域、唯一性与停止条件
“整数”允许负数和零，不等于“正整数”；不能为了得到教参中的唯一值自行改题意。不知道候选有限范围时，不能随便限定0至2008来宣称唯一。证明不唯一只需给两组满足全部原条件且目标不同的见证；声称唯一则须完整推导范围和排除其他候选。
例如原题409超越7：三个不同整数初和2008，删除首项并添另两数平均共7次，末和159，所有写过的数是整数。初态(1860,138,10)依次添74、42、58、50、54、52、53，末三数54、52、53；初态(1944,−32,96)依次添32、64、48、56、52、54、53，末三数52、54、53。两者初和均2008、末和均159、每次均为整数、初始三数互异，但最初首数不同。因此按印刷的整数条件不能确定唯一首数。应展示反例并请求确认是否遗漏“正整数”，不能直接把1860当原题唯一答案。
若题目明确改为正整数，这是另一个条件版本，需重新作完整候选证明；不得把这个版本的答案与原题混记。遇到题意不足时，明确缺失条件即可，不强求画图或套用唯一还原路线。
