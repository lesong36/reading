# 方阵问题

人或物排成正方形。实心方阵用每边人数自乘；空心方阵用外圈正方形减去内圈正方形。来源是应用题宝典。角上的人同时属于相邻两边，所以四周人数不是每边人数乘 $4$。

# 实心

$$\text{总人数} = \text{每边人数} \times \text{每边人数}$$

每行 $22$ 人，一共 $22 \times 22 = 484$ 人。

# 四周和每边

$$\text{四周人数} = (\text{每边人数} - 1) \times 4$$

$$\text{每边人数} = \text{四周人数} \div 4 + 1$$

最外层 $52$ 人，每边 $52\div 4 + 1 = 14$ 人。最内层 $28$ 人，每边 $28\div 4 - 1 = 6$ 人。内层公式少加 $1$、改成减 $1$，是因为内层数的是已经空出去之后的那一圈边长。总人数 $14\times 14 - 6\times 6 = 160$。

# 空心、有层数

$3$ 层中空，最外边每边 $10$ 人。内边人数是 $10 - 3\times 2 = 4$。

$$\text{总人数} = \text{外边}^{2} - \text{内边}^{2} = 10^{2} - 4^{2} = 84$$

也可以分成四条矩形边：

$$\text{总人数} = (\text{每边人数} - \text{层数}) \times \text{层数} \times 4$$

# 三角堆

顶点 $1$ 棵，每排比上一排多 $1$ 棵，最下面一排 $5$ 棵。这是 $1$ 到 $5$ 的和：

$$(5+1)\times 5 \div 2 = 15$$

# 多一层、少一层

棋子排成正方形多 $4$ 枚；纵横各加一层则少 $9$ 枚。加一层所需的棋子是 $4+9=13$。新的每边是 $(13+1)\div 2 = 7$，原来有 $7\times 7 - 9 = 40$ 枚。
