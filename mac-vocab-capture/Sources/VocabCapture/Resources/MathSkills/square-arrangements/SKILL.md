# 方阵问题

人或物排成正方形。先辨清题目给的是每边人数、某一圈的总人数、空心层数，还是整队的总人数；这些数量不能互换。只问一排时不求整个方阵。来源为应用题宝典，算术计数仍须逐题核验。

## 适用条件与排除

公式需要完整、等距且每行每列对齐的正方形布局。每边人数和层数必须为正整数。对边长至少2人的完整一圈，四周人数必须是4的整数倍；给出的圈人数不满足时，不能擅自当成每边人数。最外层人数、最内层人数或层数含义未明确时，不补成方法例题的条件。

空心方阵还须有未放人的内部位置：外边人数减去两倍层数得到空洞每边的空位数，必须至少为1。结果为0表示已经填满，应按题面确认实心情形；结果为负表示层数超过可容纳范围，不能套平方差算出人数。

## 实心方阵

明确每行与每列人数相同时，总人数 = 每边人数 × 每边人数。每行22人且排成实心正方形，共22×22=484人。单说某一排22人不能证明全队有484人。

## 一圈人数与每边人数

四角的人各属于两条边，不能重复计数：

四周人数 = (这一圈每边人数 − 1) × 4。

这一圈每边人数 = 四周人数 ÷ 4 + 1。

例：最外圈52人，外边每边52÷4+1=14人。若最内侧**仍放有人**的一圈有28人，该占据圈每边28÷4+1=8人；圈内的空洞每边空位是8−2=6。因此总人数为14×14−6×6=160人。28÷4−1=6求得的是空洞边长，不能称作最内圈每边人数。

“最外层有10人”不是“最外边每边10人”。完整外围人数10也不能被4整除，不能改题意后使用下面84人的例子。

## 空心方阵与层数

外边每边n人、向内占t层时：

空洞每边空位数 = n − 2×t。

总人数 = n×n − (n−2×t)×(n−2×t)。

例如外边每边10人、向内占3层，空洞每边4个空位，总人数10×10−4×4=84人。也可逐圈核对：(10−1)×4 + (8−1)×4 + (6−1)×4 = 36+28+20=84人。

等价的四条矩形边计数为 (n−t)×t×4。仅在上面的整数、完整布局和可容纳层数条件成立时使用；不能把外圈总人数直接代入n。

## 三角堆与加减一层

明确每排依次增加1时，最上排1棵、最下面5棵，共(5+1)×5÷2=15棵；不把正方形计数套给三角排列。

棋子排成原正方形多4枚；纵横各加一层则少9枚。新增边框需要4+9=13枚，新每边(13+1)÷2=7枚，共7×7−9=40枚。回查原每边6枚，6×6+4=40枚。

## 图示限制与来源

当前原生模板不验证方阵空间布局；面积图计算面积，不能把人数当作长度输出“人²”或声称已渲染真实方阵。可用数量列表辅助逐圈计数，并明确空间图示未支持。
