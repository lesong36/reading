# 和倍问题

知道两个数的和，又知道一个是另一个的几倍。把小数看成 $1$ 份，大数就是若干份，和就是全部份数。讲义 Q3-02。

师徒共做 $120$ 个零件，师傅做的是徒弟的 $3$ 倍。

徒弟是 $1$ 份，师傅是 $3$ 份，一共 $1+3=4$ 份。

$$1\text{份} = 120 \div 4 = 30$$

徒弟 $30$ 个，师傅 $30 \times 3 = 90$ 个。

$$1\text{份} = \text{和} \div (\text{倍数} + 1)$$

口诀：和倍用“加一”，因为小数自己也是 $1$ 份。

# 倍多、倍少：先补或先截

倍数旁边还有零头时，先把零头处理掉，再变成整倍数。

两人共 $42$ 颗糖，爸爸比小明的 $3$ 倍少 $6$ 颗。少了就补：把缺的 $6$ 颗补进总数，$42+6=48$，正好是 $4$ 份。小明 $48\div 4 = 12$ 颗，爸爸 $42-12=30$ 颗。验算：$12\times 3 - 6 = 30$。

两人共 $48$ 颗糖，爸爸比小明的 $3$ 倍多 $4$ 颗。多了就截：从总数里去掉多出来的 $4$ 颗，$48-4=44$，再是 $4$ 份。小明 $44\div 4 = 11$ 颗，爸爸 $48-11=37$ 颗。验算：$11\times 3 + 4 = 37$。

口诀：少了就补，多了就截，补完或截完再除。

# 每堆取走同样多

三堆小球共 $2022$ 颗。每堆取走同样多之后，第二堆剩 $27$ 颗，第一堆剩下的是第三堆剩下的 $2$ 倍。问第三堆原来有多少。

1. 先去掉第二堆剩下的 $27$：$2022-27=1995$。
2. 第一堆比第三堆多剩 $1$ 份。把这 $1$ 份移给已经空出的第二堆，三堆就一样长，而且每一堆都等于第三堆原来的数量。
3. $1995 \div 3 = 665$。第三堆原来有 $665$ 颗。

取走的部分一样多，就可以把剩下的份数重新配平，再平均分。
