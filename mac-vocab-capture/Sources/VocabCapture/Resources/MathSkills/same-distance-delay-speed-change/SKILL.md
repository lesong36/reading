# 同路程延迟出发与速度变化

## 适用与前提
两种情景中的某人走相同路程，且某个出发延迟、速度变化与共同到达事件可对齐。先确认原路程、相遇点、出发钟点和各阶段速度是否相同；通常匀速的理解应根据题目说明，停留或分段变速时必须另行分段。不要把同一天的经过时间与各自出发后的时间混在一起。

## 先对齐时间，再比较同程
先用未改变速度的人走相同路程确定其新情景所需时间；加上他延迟的时间，得到另一人从原出发钟点到共同到达的时间。若另一人每小时比原来慢固定的量，将这段时间想象成按原速走，再减去每小时少走的路程，实际恰为原来的路程。因两次总路程相等，多出来的原速那一段路程恰等于各小时减少的路程总和。求出原速后回代原情景，检查新速度为正及会合时间合理。延迟、减速和谁先出发都必须按原题，不能把晚出发误认为两人新情景都少走该时长。

## 原题例
甲乙从两地同时出发，6小时在中点相遇。甲晚出发1小时，乙每小时少走4千米，仍在中点相遇。甲速度不变且仍走原来的一半路程，所以甲仍走6小时，乙从原出发时算走了7小时。乙若7小时仍按原速，比原来的6小时半程多走1小时原速路程；实际每小时少4千米，7小时一共少走28千米，恰好抵掉多的一小时路程，因此乙原速28千米/小时。半程28×6＝168千米，全程336千米。回查：新乙速24千米/小时，24×7＝168；甲6小时也走半程。

## 边界
两次不在同一地点相遇、某人的速度改变、出发时间基准不同或出现等待时不能照搬7小时；应重新建立各人的时间线。只求速度比时不凭任意假设的单位数给有单位的距离；若可行条件不足应说明。
