# 列方程与消去法

题目里的等量关系可以直接写成等式。未知数用字母代替，解出以后再代回题目检查。来源是应用题宝典。算术方法能做的题，方程是同一关系的另一种写法。

# 六步

1. 审：找出已知量、未知量，以及哪两个量相等。
2. 设：把要求的未知数设为 $x$，设的时候写上单位。
3. 列：按等量关系写方程，方程里的数不带单位。
4. 解：求出 $x$。
5. 验：代回原题，看是否符合题意。检验要做，过程可以不写出来。
6. 答：写出带单位的答案。

甲乙两班共 $90$ 人，甲班比乙班人数的 $2$ 倍少 $30$ 人。设乙班 $x$ 人，甲班 $90-x$ 人：

$$90 - x = 2x - 30,\qquad x = 40$$

乙班 $40$ 人，甲班 $50$ 人。也可以设乙班 $x$ 人，甲班就是 $2x-30$ 人，方程写成 $(2x-30)+x = 90$，结果相同。

# 消去法

两个式子里有同一个量，两式相减，这个量就消失。

$4$ 张桌子加 $1$ 把椅子是 $510$ 元，$6$ 张桌子加 $1$ 把椅子是 $750$ 元。多出来的 $2$ 张桌子是 $750-510=240$ 元，每张桌子 $240\div 2 = 120$ 元，椅子是 $510 - 120\times 4 = 30$ 元。

口诀：两个式子里重复出现的量，用大的减去小的，先求出多出来的那一份。
