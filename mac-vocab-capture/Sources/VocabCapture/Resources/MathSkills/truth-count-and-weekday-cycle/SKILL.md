# 真假数量与星期循环核验

## 恰定数量真话：阈值分区
先确认数域及真假话数量。将所有等号和大小比较的阈值作为分界，单独检查等号点，并把其余连续整数分为真假模式相同的区间。每个区间逐条判断真假并计数，不可只猜一个数。完整列出满足真话数量的所有区间或数，再核对非负、整数等题设；若有多个结果应保留。

原题藏书量是非负整数，四句话分别为恰500、至少1000、不到2000、至少1，恰一句真。1至1999的不到2000与至少1同时真；2000及以上的至少1000和至少1同时真；0仅不到2000真，其他均假。故0本，500、1000和2000的边界均已覆盖。

## 周期日历：说话日与所指日分开
逐日列星期一至日。对每位说话者分别标记今天诚实还是说谎，再计算其陈述所指的昨天是否是该人说谎日；陈述真值必须与今天诚实状态相等。星期一昨天是星期日。分别列每人可行今天，求交集；没有共同日期或多于一个日期时如实说明。若问答跨天，分别计算实际说话日，不得默认同一天。

原题狮子周一至三说谎、独角兽周四至六说谎，其余日诚实；同一天都说“昨天是我说谎的日子”。狮子可在周一（今天说谎、昨天没说谎）或周四（今天诚实、昨天说谎）；独角兽可在周四或周日；交集为周四。核查全部星期及真假状态。

## 边界
条件是至少一句、恰一句或恰两句必须分别计数；阈值变动时重新分区，不能套用原题结果。日程非七天周期、陈述指明不同日期或询问跨日时另行建表；不能擅设每人永远诚实或永远说谎。
