# 公约公倍

要切得一样大、又没有剩余，用最大公约数。要若干件事再次同时发生，用最小公倍数。来源是应用题宝典。

# 最大公约数

硬纸板长 $60$ 厘米、宽 $56$ 厘米，剪成同样大的正方形且没有剩余。边长是 $60$ 和 $56$ 的最大公约数 $4$ 厘米。

四边形广场四边 $60$、$72$、$96$、$84$ 米，四角和四边种树，间距相等，棵数尽量少。间距取这四个数的最大公约数 $12$ 米。封闭一圈，棵数等于段数：

$$(60+72+96+84)\div 12 = 26$$

# 最小公倍数

三辆车绕圈，一周分别要 $36$、$30$、$48$ 分钟，同时从起点出发。再次同时回到起点的时间，是三个数的最小公倍数 $720$ 分钟，也就是 $12$ 小时。

# 除了都余同一个数

$4$ 个 $4$ 个数多 $1$，$5$ 个 $5$ 个数多 $1$，$6$ 个 $6$ 个数多 $1$，总数在 $150$ 到 $200$ 之间。去掉这 $1$ 个，剩下的数是 $4$、$5$、$6$ 的公倍数。最小公倍数是 $60$，$60\times 3 + 1 = 181$。

口诀：对齐切块用最大公约数，再次相遇用最小公倍数，余数相同就先去掉那个余数再找公倍数。
