# 线段图

把数量画成线段的长短。两条线段上下对齐时，长的比短的多出来的一截用虚线标出，总和用大括号括住。`Gemini_A` 用这种双线段做和差、和倍、差倍和年龄。讲义 Q2-05、Q2-06 则先找单位 $1$，再按倍数画。

# 画的三步

1. 找单位 $1$。谁最小，谁就是 $1$ 段。
2. 按倍数把其余的线段画成若干段。
3. 从图上读出 $1$ 段对应多少，再乘回各人的段数。

小明是小红的 $3$ 倍，小黄是小红的 $4$ 倍。小红最短，画 $1$ 段；小明画 $3$ 段；小黄画 $4$ 段。

连环倍数要一层一层乘。小黄是小明的 $2$ 倍，小明是小红的 $3$ 倍。小红 $1$ 段，小明 $3$ 段，小黄是 $2$ 个“$3$ 段”，共 $6$ 段。

“小明是小红的一半”先倒过来说：小红是小明的 $2$ 倍。小明改当 $1$ 段，就不用画半段。

# 比较：差相加还是相减

同向的差连在一条线上，差相加。明比红高 $5$ 厘米，黄比明高 $3$ 厘米。从红到明是 $5$，从明到黄是 $3$，黄比红高 $5+3=8$ 厘米。

两个人都去和同一个人比，差相减。明比红高 $5$ 厘米，明比黄高 $3$ 厘米。明最长。黄离明只差 $3$，红离明差 $5$，黄比红高 $5-3=2$ 厘米。

# 倍数变了：抓增加的段

小明原来是 $1$ 份。爸爸买来以后变成 $3$ 倍，妈妈再买 $15$ 颗以后变成 $6$ 倍。

图上从 $3$ 段变成 $6$ 段，增加了 $3$ 段。这 $3$ 段就是 $15$ 颗。

$$1\text{段} = 15 \div 3 = 5$$

小明原来有 $5$ 颗。

# 两个状态里有一个量不变

杯子加重 $1$ 份水是 $4$ 千克，加重 $2$ 份水是 $5$ 千克。杯子的重量两次都在。

第二幅比第一幅多 $1$ 份水，重量多 $5-4=1$ 千克。所以 $1$ 份水是 $1$ 千克，杯子是 $4-1=3$ 千克。

# 双线段：和、差、倍放在一起

椅子是 $1$ 份，桌子是 $3$ 份，一共 $120$。

椅子画 $1$ 段。桌子在下面画 $3$ 段，每段和椅子一样长。右边用大括号括住两行，括号上写 $120$。总份数是 $1+3=4$，$1$ 份是 $120\div 4 = 30$，桌子是 $90$。

和差题里，短的画实线，长的比短的多出来的一截画虚线。虚线标差，大括号标和。大数是（和 $+$ 差）$\div 2$，小数是（和 $-$ 差）$\div 2$。见 [[和差问题]]。

年龄题里，两条线段的虚线差在若干年后长度不变。两人各向右延长同样一段，虚线仍是原来那么长。见 [[年龄问题]]。

植树把这条线段再打上点：段是间隔，点是树。两端的点算不算，决定点数比段数多 $1$、少 $1$，还是相等。见 [[植树问题]]。

收费或速度中途改变时，在总长度上按分界切一刀。停车场 $6$ 小时：前 $3$ 小时一段，标 $15$ 元；后 $3$ 小时一段，每小时 $6$ 元，是 $18$ 元。两段相加得 $33$ 元。

两人走路时，在同一条路上画两个箭头。相向的箭头指向同一个点，这一点到两端的长度之和是全程。同向的箭头指向同一边，快的比慢的多出来的长度是路程差。见 [[行程问题]]。

口诀：最小的画成 $1$ 段；同向的差相加，对着同一个标准的差相减；两个状态相减，减掉的是没变的那个量。和与差同时出现时，实线是共有的部分，虚线是多出来的差。
