# 规则数表中的平移窗口与相邻定和极值

## 范围与先备
用于已确定行优先连续整数表中平移固定形状求和、反求位置、窗口最大数，以及奇偶行反向的满行蛇形表里上下相邻两数的定和乘积极值。先会四则、位次、整数除法和用交换比较两个乘积。行列只是位置标签，不要求列方程或函数求极值。任意空格表、变长行、旋转图案、非连续数值、不同步长网格须先重建值规则；不套本方法。现有分层定位解决“哪格是什么”，极值框架要求“界和构造”；这里补窗口偏移、合法落位和定和乘积的具体步骤，不声称小学课程已认证。

## 1. 从原图抄固定窗口，分清位置与重数
先确认总列数W、第一格起点和填数方向；满行且首项1时，第r行第c列的值是前面r−1行共W(r−1)个数，再数c个。r、c从1开始，1≤c≤W；有限表还须核行上限。给窗口选一个有明确行列的锚点，逐格记录相对行差dy、列差dx。阴影只数一次；若不同图案重叠而题意要重复计贡献，另记录该格权数，不能悄悄去重或重复。禁止旋转/翻转时，所有偏移固定。
窗口落位必须对每个偏移核1≤r＋dy和1≤c＋dx≤W；有行上限H再核r＋dy≤H。不在纸上画出来的空格不是合法窗口。整行末的相邻数虽然差1，却可能不左右相邻，禁止“数字连续就当同一行”。

## 2. 把平移和压成锚点贡献
行优先满表中，相对格的值为锚点值加W×dy＋dx。因此m格窗口总和等于m份锚点值，再加全部偏移值之和；有权数就按权数累加m和偏移。先算一次偏移常数，不能套“格数乘中心”而不检查偏移是否正好抵消。
已给总和S，先减偏移常数，再除m：非整数就无解；得到正整数锚点值后，用该值减1做整除/余数，反求行列，再逐格核边界。整除只是必要条件：锚点可能落在最右列，而窗口还需向右一格；这种候选必须排除。通过后列出实际覆盖数及逐项总和。
最大数不必重新搜索：按每格真实偏移W×dy＋dx取最大，再加锚点值；负偏移不自动代表小值，必须一起比较。例如固定三格偏移(0,0)、(0,1)、(1,0)，六列表中常数为0＋1＋6=7；给和70，锚点是(70−7)÷3=21，位于第4行第3列，三值21、22、27，最大27。若给和79得到锚点24，虽能整除，却在第4行第6列，右邻越出表，故无合法平移。
对称3×3窗口选中心时，左右、上下偏移逐对抵消，所以九格和是9份中心值；中心仍须行至少2、列2至W−1，有限表还须不在最后一行。非中心对称形状应算实际常数。

## 3. 满行蛇形的上下相邻定和
这里限每行W格、第一行从1向右填，第二行反向、依此交替。第r行值域从W(r−1)＋1至Wr；奇行第c格值为W(r−1)＋c，偶行第c格值为Wr−c＋1。
把第r行和下一行同列的两值相加：奇行在上时为W(r−1)＋c与W(r＋1)−c＋1；偶行在上时为Wr−c＋1与Wr＋c。两种和都恰为2Wr＋1，与列号无关。因此给相邻和S，先减1再除2W：不是正整数则不存在这样的相邻行；整数结果就是上面一行的行号r，再核下行仍在表内。奇偶决定具体两个格，不可把同一公式用于普通同向表。

## 4. 定和积小：先证明，再找达到列
两正数和固定，设较小a、较大b。若把两数向中间挪1，乘积由ab变成(a＋1)(b−1)，增量为b−a−1；只要差大于1，乘积严格增加。所以在本表允许的配对里，差越大乘积越小，不是越平均越小。不能把a任意取1，因为实际数还受相邻行位置约束。
上述相邻两行恰可配成同一段2W个连续数的首尾对：最外对是W(r−1)＋1与W(r＋1)，差为2W−1，其他对逐渐向中间收，故最外对给全体最小乘积。r奇数时最外对在第1列，r偶数时在第W列；W=1时只有唯一一对。回代实际格与给定和，给出最小乘积及达到列。若问所有最优位置须保留全部，不能随意除镜像数；本规则下W>1时最小列唯一。

## 边界与交付
零格窗口不可除格数；偏移有重复时先按题意合并权数或去重。图案某格读不清，保留该偏移的不确定性而不是补成对称形。有限表要检查上下界；多个可旋转形状要另逐种做同样证明而非忽略禁转条件。回答所有小问，区分“整除无解”“落位越界”和“合法构造”，保留偏移表、锚点位置及实际数值。数表规则只由有限样本推测时，明确结论以该规则为条件。本稿是项目补充草案，不是运行时工具或人工教学批准。
