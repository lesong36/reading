# 平均数问题

平均数是把高低不同的数拉到同一条水平线上。讲义 Q3-06、Q3-07。

# 基本关系

$$\text{平均数} = \text{总数} \div \text{份数}$$

$$\text{总数} = \text{平均数} \times \text{份数}$$

$85$、$90$、$95$ 的平均数是 $(85+90+95)\div 3 = 90$。再增加一个 $100$，新的平均数是 $(85+90+95+100)\div 4 = 92.5$。看到平均数，先回到总数。

# 移多补少

$8$ 颗、$4$ 颗、$6$ 颗。把多出来的移给少的，三人都会停在 $6$ 颗。这个 $6$ 就是平均数。$120$、$80$、$100$、$100$ 毫升，以 $100$ 为水平线，第一杯多 $20$，第二杯少 $20$，移过去以后每杯都是 $100$ 毫升。

# 每次都已经平均分过

第一次每组 $5$ 个，第二次每组 $3$ 个。每次都是公平分配，每组得到的就是 $5+3=8$，不必先乘人数再除回来。

# 份数不一样时

两组的平均数不能直接把两个平均数再平均，除非两组人数相同。人数不同时，先分别乘回总数，加起来，再除以总人数。这就是加权平均。混合单价也是同一件事：总价除以总数量，而不是两个单价相加再除以 $2$。

# 做题时

1. 问平均，先确认份数是否相同。
2. 份数相同，总数除以份数，或把每次的平均数相加。
3. 份数不同，先还原成总数，再除以总份数。
4. 已知平均数求某一个未知数，用平均数乘份数得到总数，再减去已知的那些数。

## 同一基准的偏差与未知人数
取同一平均值作标准，每组“实际均分减标准”乘该组真实人数，得到该组相对标准多出或不足的总量。全体标准取总平均时，各组多出总量与不足总量相等；讲解可说多/少，不要求学生写负数。不能把均分差直接相加，或把人数不等的两组当等权。
若一组人数已知，另一组均分比合并平均多或少一个非零差，用已知组的总偏差除另一组每人偏差，求其人数，再回查总分和人数正整数。差为0时要另判：两组均等于合均则人数可能不唯一；一组等于合均而另一组偏差非零，两组人数均正时不相容。
414兴趣9：甲57人均132，乙均163，合均144。甲少57×12=684，乙每人多19，所以乙684÷19=36人；回查总13392、人93，均144。
若两组人数都未知但已知各组总分，先由每人正负偏差得人数倍数，再把总分缩放至同样人数，利用同人数总分差除均分差。414超越7：男均比总均多2、女少1，女生人数为男生2倍；女生总1800先除2为900，与男总942同人数比较，差42，每人差3，男14、女28。均分可以是分数，题目只要求人数整数，不能擅加每人分数或均分为整数。

## 重叠子集先还原偏差总量
每个子集的平均差先乘它实际所含份数，再用补集、交叠项与总偏差为0消去共有部分。集合是否重叠必须按实际成员列清；只求某子集均分差时，不必强行求每个人的分数。多个单次成绩不唯一，也不妨碍目标差唯一。
414超越1：六次总均作标准，后4次多12，所以前2次少12。第1、2、6次共少3.6×3=10.8，故第6次多12−10.8=1.2；前5次共少1.2，平均少1.2÷5=0.24分。不是把3和3.6直接相减，也不是用6或4作最后分母。

## 转组用新旧人数和同一转移组衔接
先写移出前人数、移出后人数、移入后人数。移出组均分升高，是留下者相对旧标准多出的总量，等于被移走者相对该旧标准少的总量；移入组均分升高，新增者相对旧标准多出的总量等于新人数乘均分增量。分别除转移人数得到同一转移组与两旧均分的距离，再连接两个旧标准。不能用旧移入人数代替新人数；均分降低时按多/少方向重新列，不硬加绝对差。
414超越5：一等奖10人移末4至原20人二等奖，前组剩6人均升3，后组现24人均升1。转移4人比旧一等奖均少6×3÷4=4.5，比旧二等奖均多24×1÷4=6，故原两均分差10.5。最后4人的排序与均分关系也须相容；这里只确定差，不唯一确定两组绝对均分。

## 连续整数删数的范围和唯一性
从1至最大自然数的一串中删1个，剩余平均最低发生在删最大值，最高发生在删最小值。分别算两种极端平均，将可能的最大数限在有限整数范围，再要求“剩余平均乘剩余个数”仍为整数，恢复被删数并核在原串内。不能仅用平均范围就跳过整数总和条件；条件不同可能多解或无解，应完整保留。
414超越3：剩均10.8。若最大数为n，删最大剩均n÷2，删最小剩均(n+2)÷2，因此n只可20或21。20时剩19数总应205.2，非整数而排除；21时原总231，剩总216，擦去15，回查(231−15)÷20=10.8。n是数量标签，解释可直接比较相邻候选，不要求列方程。

## 图表先核计数再用平均总量
靶图的分区标数不是弹孔，逐区数标记并核总数等于题给枪数；边界处看不清不猜归属。414兴趣1外至内2/4/6/8/10分区标记数2/4/2/2/0，合10枪、总48，均4.8；不是把五个环分直接平均。
表格缺位时，以平均乘真实天数还原总量，扣已知格后结合可见首尾数字、进位和非负范围列所有可能补全，不能照答案补图。414拓展3周一81、二74、五69、5天均73，三四合141；三首位6、四末位7，个位须4且进1，所以三64、四77。即使破损长度未明，600或更大6开头数超过141，单独6又不合个位和，故唯一。原图无证据的天数、缺位长度、额外数字不补造。

## 单独删最高最低与评分极值
明确两个删除实验是各自从原全体删一人，还是同一次连续删两人。各自删一人的情况，用原总量减删除后总量恢复该最高/最低分。也可按剩余人数计算相对原均分的偏差：原均分减删高后均分，乘剩余人数，得到最高分比原均分多多少；删低后均分减原均分同理得到最低分少多少。
利用原题给的评分上界、人数为正整数限制候选，再检查最高≥其余≥最低、全部评分符合原上界，给实际达到方案；下界不自动能达到。未给最小计分步长或整数评分时，不自行添加。
414超越8：原均9.64，分别只去最高均9.60、只去最低均9.68，每相差0.04。剩k人则最高9.64+0.04k、最低9.64−0.04k。最高不得超过10，故k至多9；最低随k增加而降低，k=9时原10人、最低9.28。方案为1人9.28、8人9.64、1人10，总96.4，两种单独删除后均值9.60/9.68都成立。给出达到方案才可说最少9.28，不把两个删除同时算成8人。
