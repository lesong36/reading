# 平均数问题

平均数是把高低不同的数拉到同一条水平线上。讲义 Q3-06、Q3-07。

# 基本关系

$$\text{平均数} = \text{总数} \div \text{份数}$$

$$\text{总数} = \text{平均数} \times \text{份数}$$

$85$、$90$、$95$ 的平均数是 $(85+90+95)\div 3 = 90$。再增加一个 $100$，新的平均数是 $(85+90+95+100)\div 4 = 92.5$。看到平均数，先回到总数。

# 移多补少

$8$ 颗、$4$ 颗、$6$ 颗。把多出来的移给少的，三人都会停在 $6$ 颗。这个 $6$ 就是平均数。$120$、$80$、$100$、$100$ 毫升，以 $100$ 为水平线，第一杯多 $20$，第二杯少 $20$，移过去以后每杯都是 $100$ 毫升。

# 每次都已经平均分过

第一次每组 $5$ 个，第二次每组 $3$ 个。每次都是公平分配，每组得到的就是 $5+3=8$，不必先乘人数再除回来。

# 份数不一样时

两组的平均数不能直接把两个平均数再平均，除非两组人数相同。人数不同时，先分别乘回总数，加起来，再除以总人数。这就是加权平均。混合单价也是同一件事：总价除以总数量，而不是两个单价相加再除以 $2$。

# 做题时

1. 问平均，先确认份数是否相同。
2. 份数相同，总数除以份数，或把每次的平均数相加。
3. 份数不同，先还原成总数，再除以总份数。
4. 已知平均数求某一个未知数，用平均数乘份数得到总数，再减去已知的那些数。
