# 统一不变量

比发生变化时，先找出没有变的那个量，把两次的份数都写成这个不变量是同样的份数。讲义 Q6-03。

# 连比

$A:B = 3:4$，$B:C = 5:3$。两个比里的 $B$ 份数不同，先把 $B$ 对齐。$3:4$ 乘 $5$ 得 $15:20$，$5:3$ 乘 $4$ 得 $20:12$。于是 $A:B:C = 15:20:12$。$A$ 的 $15$ 份大于 $C$ 的 $12$ 份。

# 和不变

$A$ 给 $B$ 一些，$A+B$ 不变。$A:B = 5:2$，给完以后 $A:B = 3:11$。

原来和是 $5+2=7$ 份，现在和是 $3+11=14$ 份。把原来的比乘 $2$，和也变成 $14$ 份：$10:4:14$ 和 $3:11:14$。同一份和上，原来的 $B$ 是 $4$ 份，现在的 $A$ 是 $3$ 份，原来的 $B$ 更多。

甲、乙分数从 $5:4$ 变成 $5:7$，和不变。和分别是 $9$ 份和 $12$ 份，对齐到 $36$ 份：原来 $20:16:36$，现在 $15:21:36$。甲减少的 $5$ 份等于乙增加的 $5$ 份。若这 $5$ 份是 $22.5$ 分，$1$ 份是 $4.5$ 分，原来两人相差 $4\times 4.5 = 18$ 分。

# 差不变

每人拿出同样多，$A-B$ 不变。$A:B = 3:1$，拿出以后 $A:B = 4:1$。

原来差是 $3-1=2$ 份，现在差是 $4-1=3$ 份。把原来的比乘 $3$、现在的比乘 $2$，差都变成 $6$ 份：原来 $9:3$，现在 $8:2$。

年龄也是差不变。今年小明和爸爸是 $1:4$，差是 $3$ 份；$15$ 年后是 $5:11$，差是 $6$ 份。把今年的比乘 $2$，差也是 $6$ 份：今年 $2:8:6$，$15$ 年后 $5:11:6$。多出来的 $3$ 份等于 $15$ 年，$1$ 份是 $5$ 年，今年小明 $2\times 5 = 10$ 岁。

# 只有一个量不变

女生人数不变。原来男:女 $=1:3$，后来男:女 $=3:5$。女生分别是 $3$ 份和 $5$ 份，对齐到 $15$ 份：原来 $5:15$，现在 $9:15$。男生从 $5$ 份到 $9$ 份，增加 $4$ 份。若增加的是 $20$ 人，$1$ 份是 $5$ 人，现在男生 $9\times 5 = 45$ 人。

口诀：先问谁没变。和没变就对齐和，差没变就对齐差，某一个量没变就把那个量的份数化成一样。
