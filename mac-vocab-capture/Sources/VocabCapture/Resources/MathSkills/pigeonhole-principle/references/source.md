# 抽屉原则

把物体放进抽屉。只要物体比抽屉多，就一定有一个抽屉里至少有 $2$ 个。来源是应用题宝典。这里的“至少”是保证发生，不是可能发生。

# 基本

$n+1$ 个物体放进 $n$ 个抽屉，至少有一个抽屉里有 $2$ 个或更多。

$367$ 个学生出生在同一年，这一年有 $366$ 天。把一天当作一个抽屉，$367$ 个学生放进 $366$ 个抽屉，至少有 $2$ 个学生生日在同一天。

# 推广

$m$ 个抽屉，$k \times m + r$ 个物体，其中 $0 < r \le m$。至少有一个抽屉里有 $k+1$ 个或更多。

头发不超过 $20$ 万根，当作 $20$ 万个抽屉。$3645$ 万人：$3645 \div 20 = 182$ 余 $5$，所以至少有 $183$ 人头发根数一样多。

# 要保证某种颜色够数

红球 $10$、白球 $9$、黄球 $8$、蓝球 $2$，要保证至少 $4$ 个球同色。最不利的是每种颜色先拿 $3$ 个，蓝球只有 $2$ 个，一共 $3+3+3+2=11$ 个，这时还没有任何颜色达到 $4$ 个。再拿 $1$ 个，就一定有一种颜色达到 $4$ 个。至少取 $12$ 个。

# 三步

1. 说清什么是抽屉，什么是放进去的物体。
2. 先按最不利的方式把物体放满，让每个抽屉都还差一个才达到要求。
3. 再加 $1$，得到保证成立的最少个数。
