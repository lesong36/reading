# 排列组合与限制计数

## 适用与先备
用于有限对象排队、选组、多位数排列，带相邻、不相邻、固定位置或相对次序等限制。需分步与分类计数，能清晰区分对象与位置。属于小学竞赛拓展，不能因不用排列组合符号就宣称已是四年级默认课程；需允许相应拓展。复杂圆排列、旋转反射等价、任意重复物品、多条件交叠过大时应说明另需专门推导。

## 先确认同一种结果
排成一列时各位置有顺序，选一组人而无职务时顺序不计。不同颜色但同色物品是否可区分由题意决定。排列中首位非零、固定对象、相对次序等都是限制，不可先算一个大数再随意减。要求所有排法时不能给几种示例就结束。

## 小学枚举路线
1. 小规模可按第一位是谁分互斥类，再逐位排剩下对象。每排一位剩余数减少1；明确为什么一条选择链唯一对应一种排列，不使用未学的阶乘记号也能写乘法。
2. 固定位置先放指定对象，再排其余。要求两对象相邻，可以把这两人临时捆成一个块，先排块与其余人，再数块内允许的顺序；若规定甲在乙前，块内只算1种而不是2种。
3. 要求不相邻，可先算全部再减相邻；也可先排其他对象再利用空隙插入。空隙有几个、每个允许插几人必须说明。多个对象相互不邻时，不能允许两人落同一空隙后仍称不相邻。
4. 选组可按最小编号分组，后续只选更大编号，直接避免顺序重复；若从有序选择数换成无序数，说明每组恰被算相同次数。相同物品不能当不同人随意排后不去重，去重倍数不统一则改直接分类。
5. 多项限制一起出现，逐分支核查。把互相重叠的坏情况分别减去可能重复扣除，不得沿用单一限制的结果。若结果为0，给出冲突原因；计数必须非负整数。

## 正例与核验
甲乙丙丁四人排成一列，甲乙不能相邻。全部4×3×2×1＝24种。甲乙相邻时把他们当一块，与丙丁共3个对象，有3×2×1＝6种排块方式；块内甲乙或乙甲2种，共12种。因此不相邻有24−12＝12种。另一核法：先排丙丁有2种，形成前、中、后3个空隙；甲选3处，乙选剩余2处，共2×3×2＝12种。两种方法对象与限制相同，结果一致。

## 反例与排除
若只要求从四人中选两人而不排职位，甲乙与乙甲同组；4×3＝12把每组算2次，实际6组。若两件同色物品无区别，不能把交换它们算一种新排列。圆桌旋转视同题也不能直接用直线总数，因为“第一个位置”没有被固定；应先说明需要圆排列的额外等价约定，本技能不自动给直线答案。

## 交付
列明哪些对象可区分、顺序是否计入、限制如何落实以及为何无重无漏。对复杂题只声明已验证的范围，不凭一个例子声称覆盖所有排列组合。不强制画图；需要时画真实位置或空隙，未明确的圆桌座次与标签不自行补造。所有小问分别核验，不留下与最终计数矛盾的分支结论。
