# 大小约束的可用位置与完整顺序计数

## 适用条件与符号登记
适用于n个具名位置恰好各填一次n个不同的数，只要求若干位置之间严格大于或小于，问合法填法数或全部填法。先按从小到大排好给定数；数值是否连续不影响下面的次序计数。若还有和、差、整除、固定数值等条件，本方法只负责大小条件，不能忽略其他限制。允许重复数或非严格不等号时，不能照搬“一个位置占一个名次”。

给位置记名字或行列坐标。每条大小关系统一写成“小位置＜大位置”；竖写的∨尖端朝下，故下方小于上方；∧尖端朝上，故上方小于下方。不得把不等号当运动箭头。先逐符号登记，再利用传递性：甲＜乙且乙＜丙，推出甲＜丙，不是补加新条件。

## 从最小数开始：可用位置分支
1. 在尚未填的位置中，寻找“不再有其他未填位置必须比它小”的位置。这些位置才可放当前剩余的最小数；不是只找画在最低一排的位置。
2. 只有一个可用位置就确定它；有几个便按最小数放在哪个位置分成几支。每支填入最小数后划去该位置与相关关系，对剩余位置重复。不能把同一步的几个可用位置当作永远独立，填一个以后可能解锁新位置。
3. 全填完记一种；还剩位置却无一可用，则这一支有严格大小环，记0。例如甲＜乙＜丙＜甲不可能，不必试数字。
4. 问全部填法时保存每支位置顺序，按顺序填排序后的数，再回查原图每条不等号。问数目可只累计分支数；若不同分支剩下完全相同的位置集合，其剩余限制也相同，可复用该集合的计数，避免重复做后半题。

计数为什么不漏不重：任一合法填法最小数所在的位置一定没有未填的更小前驱，所以必进入某一支；不同支的最小数位置不同，不会是同一种填法。去掉已填位置后同样成立，逐步对应全部合法填法。若所有位置填完，所存顺序恰好给每个数唯一位置。

## 先压成确定长链，再看真正自由处
若传递关系已经把许多位置连成从小到大的长链，可先画链；只比较未定位置之间是否还受限制。两条互不相连且内部顺序固定的链，可用逐步“下一位取左链还是右链”的小表数交错次数；有跨链大小边时必须检查该边，不能直接套无约束交错数。无论简化多少，最后回查原图边。

## 原图九宫实例：图20-18
按行命名为a,b,c／d,e,f／g,h,i。六条横向原关系是a＜b、c＜b、e＜d、f＜e、h＜g、i＜h；六条纵向原关系是d＜a、e＜b、c＜f、g＜d、h＜e、f＜i。不能补对角关系、行和相等或逐行递增。

沿原关系串起c＜f＜i＜h；随后e和g都比h大、都比d小；最后d＜a＜b。因此c,f,i,h依次只能放1,2,3,4，d,a,b依次放7,8,9。e与g之间没有关系，分别放5,6或6,5，恰2种：

- a,b,c／d,e,f／g,h,i＝8,9,1／7,5,2／6,4,3。
- a,b,c／d,e,f／g,h,i＝8,9,1／7,6,2／5,4,3。

这两种逐条满足12个原不等号；链强制前4和后3个名次，中间仅两个次序，故同时给出存在与“没有其他填法”的证明。图中e＜d与g＜d都须登记，不能只看到某条漂亮长链而漏掉旁支。

## 原创迁移与边界
四个位置甲、乙、丙、丁，规定甲＜丙、乙＜丙、乙＜丁。最小数1放甲时，余下先乙，再丙丁任选顺序，2种；放乙时，剩甲＜丙而丁自由，顺序为甲丙丁、甲丁丙、丁甲丙，3种，共5种。把1,2,3,4改成2,5,8,20仍5种，因为只变名次数值。

增加丙＜甲会与甲＜丙构成环，0种。若允许用1、2重复填两个位置且没有大小边，有4种(1,1)、(1,2)、(2,1)、(2,2)，不是本法不同数字名次的2种。只有甲＜乙、每格允许1或2重复时恰1种；若改甲≤乙则有3种，说明严格/非严格不能互换。若给了n个不同数但可任选部分、不要求用尽，也不能直接说填法等于n位置完整次序数，须先确定实际用数集合。
