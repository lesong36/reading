# 份数线段图

一条总线段代表整体，按比切开。先数总份数，再求 $1$ 份是多少，最后读出每一段的长度。`Gemini_A` 用它做按比例分配和正反比例。它和 [[线段图]] 的差别是：这里先有整体，再切成份；普通线段图先有 $1$ 份，再拼成整体。

# 怎么画

1. 画一条线段，标上总数。
2. 把比的各项加起来，得到总份数，在线段上按这个份数打刻度。
3. 用不同标记把各部分的份数涂开。
4. $1$ 份等于总数除以总份数。某一部分等于 $1$ 份乘它的份数。

$560$ 按 $3:4:5$ 分配。总份数 $3+4+5=12$。

$$1\text{份} = 560 \div 12$$

三段依次是 $3$ 份、$4$ 份、$5$ 份。整数题里总份数要能整除总数；不能整除时，$1$ 份可以先保留成除式，再乘份数。

百分数是把整段当成 $100$ 份，再切出百分之几。标准量画成整段，比较量是其中一段。见 [[百分数问题]]。

# 正反比例怎么看

正比例：一条边的份数变了，另一条对应的量按同样的份数变，商不变。把两次的份数画成上下对齐的两段。

反比例：整块面积或总页数不变。一条边的份数变多，另一条边的份数就变少，两段的乘积仍等于原来的总数。见 [[正反比例]]。
