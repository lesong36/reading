# 盈亏问题

同一批东西，按两种分法去分。可以一盈一亏、两次都盈、两次都亏，也可以一次有余或不足而另一次正好分完。对象的个数等于总差除以单差。它和 [[鸡兔同笼]] 是同一件事：两次方案的差别，除以每一份的差别。讲义 Q4-03、Q4-04。


## 适用边界：包括一次正好

必须确认两次分配是同一批物品、同一组接受对象，或已经依据原题合法对齐份数；每份分配数量不同。先按本题实际余缺选择分支，不要求所有题都符合“两次都盈或都亏”。一盈一亏、同盈、同亏、一次正好是可选分支，各分支的条件不能同时要求。

一次正好分完，剩余或不足的数量就是 **0**，它是题面事实，不是缺失条件。另一次每人分得少且有剩余时，总差就是该剩余数量；另一次每人分得多且不足时，总差就是该不足数量。人数＝总差÷每人分配数量之差。题目说“剩下的还能分给若干人”时，剩余总数＝还能分给的人数×该分法每人分配数量，不能把还能分给的人数当成剩余物品数。

总差和每份差须保持正确方向：同一批物品、同一组人，每人分得更多，余数只能减少或不足只能增加。从少分到多分，剩余减少、由剩变缺，或不足增加，才可按相应正总差计算人数。不能取绝对值掩盖题面方向矛盾。人数和物品个数必须是正整数，不能把除不尽的结果四舍五入；每份差为0、方向矛盾或人数非正整数时，不能给出符合本题条件的唯一分配。

如果两种不同的每人分配量都正好分完，在总量和正整数人数相同的条件下互相矛盾，不能套公式求人数。未确认总量、人数或余缺含义时，不从方法例题补条件。

## 一次正好时的算术步骤

1. 把“正好分完”的余缺写成0。若另一次剩余以人数描述，先乘该分法每人数量，换成剩余物品数。
2. 求每人分配量的正差，并检查余缺方向与少分、多分一致。
3. 用剩余或不足的总数量除以每人差，得到正整数人数。
4. 用正好分完时的每人数量乘人数求总物品数，再回代另一种分法核对剩余或不足数量。


# 一盈一亏

每只小猴分 $6$ 个桃，还剩 $4$ 个；每只分 $8$ 个，还差 $10$ 个。

1. 单差：每只多分 $8-6=2$ 个。
2. 总差：从“剩 $4$”变成“差 $10$”，需求一共多了 $4+10=14$ 个。
3. 只数：$14\div 2 = 7$。
4. 桃子：$6\times 7 + 4 = 46$。用另一句验算：$8\times 7 - 10 = 46$。

$$\text{份数} = (\text{盈} + \text{亏}) \div \text{每份差}$$

每只分 $5$ 个剩 $9$ 个，每只分 $8$ 个差 $12$ 个：单差 $3$，总差 $9+12=21$，只数 $21\div 3 = 7$，桃子 $7\times 5+9=44$。

# 两次都盈，或两次都亏

两次都剩下，或两次都不够，总差是两个余数相减。

$$\text{份数} = |\text{盈}_1 - \text{盈}_2| \div \text{每份差}$$

每只分 $8$ 个剩 $13$ 个，每只分 $10$ 个剩 $3$ 个。单差 $10-8=2$，总差 $13-3=10$，猴子 $10\div 2 = 5$ 只。桃子 $5\times 8+13=53$。

口诀：一盈一亏，两个数相加再除；两次都盈或两次都亏，两个数相减再除。

# 分法里的个数也不相同

先把两次方案改成“份数相同、每份不同”，再套上面的公式。

树杈数量不同：一种分法少了几个树杈。先把少的树杈补上，每个补上的树杈要按那种分法的每份数补萤火虫，总差跟着变大，再做一次标准盈亏。

小狗变成原来的 $3$ 倍、每只骨头也变了：把 $3$ 只小狗打成 $1$ 只“大狗”，每份骨头乘 $3$，份数对齐以后再除。

两种水果的个数成倍数：先把少的那种乘到和多的那种一样多，剩余也乘同样的倍数，再比较两种分法。

口诀：先让两次分配的“份”对齐，再算总差和单差。
