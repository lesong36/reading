# 盈亏问题

同一批东西，按两种分法去分。一种分法多出来，一种分法不够，或者两种都多、两种都不够。对象的个数等于总差除以单差。它和 [[鸡兔同笼]] 是同一件事：两次方案的差别，除以每一份的差别。讲义 Q4-03、Q4-04。

# 一盈一亏

每只小猴分 $6$ 个桃，还剩 $4$ 个；每只分 $8$ 个，还差 $10$ 个。

1. 单差：每只多分 $8-6=2$ 个。
2. 总差：从“剩 $4$”变成“差 $10$”，需求一共多了 $4+10=14$ 个。
3. 只数：$14\div 2 = 7$。
4. 桃子：$6\times 7 + 4 = 46$。用另一句验算：$8\times 7 - 10 = 46$。

$$\text{份数} = (\text{盈} + \text{亏}) \div \text{每份差}$$

每只分 $5$ 个剩 $9$ 个，每只分 $8$ 个差 $12$ 个：单差 $3$，总差 $9+12=21$，只数 $21\div 3 = 7$，桃子 $7\times 5+9=44$。

# 两次都盈，或两次都亏

两次都剩下，或两次都不够，总差是两个余数相减。

$$\text{份数} = |\text{盈}_1 - \text{盈}_2| \div \text{每份差}$$

每只分 $8$ 个剩 $13$ 个，每只分 $10$ 个剩 $3$ 个。单差 $10-8=2$，总差 $13-3=10$，猴子 $10\div 2 = 5$ 只。桃子 $5\times 8+13=53$。

口诀：一盈一亏，两个数相加再除；两次都盈或两次都亏，两个数相减再除。

# 分法里的个数也不相同

先把两次方案改成“份数相同、每份不同”，再套上面的公式。

树杈数量不同：一种分法少了几个树杈。先把少的树杈补上，每个补上的树杈要按那种分法的每份数补萤火虫，总差跟着变大，再做一次标准盈亏。

小狗变成原来的 $3$ 倍、每只骨头也变了：把 $3$ 只小狗打成 $1$ 只“大狗”，每份骨头乘 $3$，份数对齐以后再除。

两种水果的个数成倍数：先把少的那种乘到和多的那种一样多，剩余也乘同样的倍数，再比较两种分法。

口诀：先让两次分配的“份”对齐，再算总差和单差。
