# 差倍问题

知道两个数的差，又知道一个是另一个的几倍。差正好是多出来的那几份。讲义 Q3-03。

哥哥比弟弟多 $24$ 本书，哥哥的书是弟弟的 $4$ 倍。

弟弟是 $1$ 份，哥哥是 $4$ 份，多出来的是 $4-1=3$ 份，这 $3$ 份等于 $24$ 本。

$$1\text{份} = 24 \div 3 = 8$$

弟弟 $8$ 本，哥哥 $8 \times 4 = 32$ 本。

$$1\text{份} = \text{差} \div (\text{倍数} - 1)$$

哥哥比弟弟大 $12$ 岁，哥哥的年龄是弟弟的 $3$ 倍：份数差是 $3-1=2$，$1$ 份是 $12\div 2 = 6$。弟弟 $6$ 岁，哥哥 $18$ 岁。

小明的钱是小红的 $4$ 倍，小明比小红多 $45$ 元：份数差是 $3$，$1$ 份是 $45\div 3 = 15$。小红 $15$ 元，小明 $60$ 元。

口诀：差倍用“减一”。差除以份数差，得到 $1$ 份。

# 差的五种说法

题目里的差不一定写成“多几”。先把它翻译成同一个差。

1. 直接说：甲比乙多 $8$，差就是 $8$。
2. 用运算说：甲减去 $8$ 就和乙一样多，差仍是 $8$。
3. 两边同时加或同时减：两人同时增加 $5$ 以后，甲仍比乙大 $8$。同加同减，差不变，原来的差就是 $8$。
4. 经过中间量：甲比丙大 $2$，丙比乙大 $6$，甲比乙大 $2+6=8$。
5. 一方给另一方：甲给乙 $4$ 个以后两人一样多。甲少 $4$、乙多 $4$，差缩小 $8$，原来的差是 $4 \times 2 = 8$。

第五种的口诀：一给一收，差变两倍，给出的数乘 $2$ 才是原来的差。

# 三步

1. 把题目里的差翻译成一个数。
2. 看这个差是几份：倍数减 $1$，或者线段图上多出来的份数。
3. 差除以份数差，得到 $1$ 份，再乘回各个倍数。
