# 多属性位置与定向相邻推理

## 适用范围与位置口径
五个有序位置中，人物、城市、物品、饮品、颜色等多类属性各用一次；每个位置在每类属性中恰有一个值。先按题目给定方向编号；同一类别的不同标签不能同格，不同类别的标签可以同格。不能把全部标签一起当成互异，也不能把此题的方法套到允许重复、环形位置或没有确定左右方向的问题。项目补充方法须遵守用户拓展知识权限。

“某人开某车”表示两种属性同位；“相邻、旁边”保留左右两支，距离为1；“紧挨左边”同时要求方向和距离1，不能放宽为只在左边或只相邻。最左、最右和中间先落位，相邻对象碰到端点时只有一个位置可选。

## 联动排除方法
把多类属性放进同一张位置表。优先处理端点相邻、固定中间和定向双格：列出双格所有可能位置，再用已经占用的同类位置和同位属性矛盾逐组排除。每次落位后，同步传播同位标签、同类剩余位置及相邻支持。若仍有两支，明确假设其中一支，沿关系推出冲突或合法候选；保留所有合法分支，不能根据最终表倒填推理，也不能找到一张合法表便断言唯一。缺少条件时报告多解，条件冲突时报告无解。

## 来源题的完整排除链
五个车位从左至右编号1至5，人物甲乙丙丁戊，城市北京天津上海广州重庆，车奔驰宝马奥迪丰田别克，茶碧螺春铁观音龙井菊花乌龙，颜色绿蓝红白黑。

原条件：甲开奔驰；乙穿绿；丙喝碧螺春；宝马紧挨奥迪左边；宝马主人喝铁观音；北京人穿蓝；丰田主人来自天津；中间喝龙井；丁最左；上海人挨红衬衫主人；白衬衫主人挨天津人；广州人喝菊花；戊来自重庆；丁挨别克主人；上海人挨乌龙茶主人。求黑衬衫的人的身份、城市、车和茶。

1. 丁在1号，别克只能2号。宝马—奥迪双格可为1—2、2—3、3—4、4—5；前两组占用别克2号，不行。3—4让3号的宝马主人同时喝铁观音和龙井，不行。因此宝马4号、奥迪5号。奔驰属于甲，不能在丁的1号；其他2、4、5号车已确定，故奔驰与甲在3号，丰田及天津在1号。
2. 龙井3号、铁观音4号。丙喝碧螺春，丙不是丁1号或甲3号；再排除铁观音4号，碧螺春只有2、5号。菊花主人来自广州，不能在天津1号，也不能在已有其他茶的3、4号，因此菊花也只有2、5号。
3. 假设菊花2号，则碧螺春5号，乌龙只剩1号。上海挨乌龙1号，只能上海2号；但菊花2号又是广州，两座城市不能同格，矛盾。故菊花不在2号，而在5号。
4. 菊花及广州5号，碧螺春及丙2号，乌龙1号，上海挨乌龙故在2号。人物已有丁1、丙2、甲3，乙戊只剩4、5；戊是重庆人，不能在广州5号，所以戊4、乙5。城市已有天津1、上海2、重庆4、广州5，北京只剩3号。
5. 乙穿绿，故5号绿；北京穿蓝，故3号蓝；白挨天津1号，故2号白；红挨上海2号，只能1号或3号，3号已蓝，故1号红。剩下4号黑，答案为戊、重庆、宝马、铁观音。
