# 共同路程与情景事件对齐

## 适用条件和事件记录
题目中有多种运动方案或多次相遇，且给出同一起终点、同一人、同一段路或同一相遇点时，可把每种情景分开画成事件表，再在确有共同关系的地方比较。先统一方向、时间与距离单位；同路程不等于同速度，同一点也不等于同一钟点。必须核对各人是否同时出发、是否匀速、行人方向及相遇是否在运动区间内；如果某事件发生前有人停走或换速，应先分段。不能仅凭相似名称把两个情景的时刻、车辆或位置当作相同。

## 不同方案同一会合地点
先用已知相向速度和确定原来或另一方案的相遇时刻。另一方案如果说明相遇地点是原来追及的同一点 C，就用另一方案里已知的速度及相遇经过时间求 C 的位置；不要把两个方案人物在 C 的钟点默认为相等。回到原方案，在共同起始钟点下分别求“甲遇丙”和“乙到 C”的时间与位置，再比较丙在这两个事件之间走的方向、路程和经过时间，得到丙速。若 C 的位置、相遇方向或事件先后没有唯一确定，逐支检查，不补造丙的出发点。

例：两地相距120千米，甲速50千米/时，两人相向1小时30分相遇，乙速120÷1.5−50=30千米/时。另一方案甲44、乙36，仍以速度和80相向1.5小时，故它们的共同地点 C 距甲出发地44×1.5=66千米。原方案相遇后6分钟，即出发后1.6小时，甲在50×1.6=80千米处遇丙。乙在原方案到 C 的经过时间为(120−66)÷30=1.8小时。丙从80走到66，走14千米，用1.8−1.6=0.2小时，速14÷0.2=70千米/时。回查两种方案的 C 是同一点，但发生时刻不同；丙遇甲后向 C 追乙，且题目未给丙的出发位置，不把猜测的起点当事实。

## 相同全程、不同到达时间与共同初距
几辆车从同一出发地同时开往同一终点、均匀速行驶时，取它们到终点时间的一个共同倍数作为“全程份数”；各车速度份数分别是该共同倍数除以各自的到达时间，时间短则速度份数大。对于同一行人在同一初始位置迎面匀速而来，分别把两次相遇的车程和行人程相加；两次和是同一个初距。比较两次会合时长，先求各车在这些时长内路程份数差，再与行人多走或少走的已知路程比较，求一份的实际速度；若差为零且没有其他约束，可能无解或不能唯一确定。求出初距后按第三辆车与行人的合速求相遇时间，检查相遇发生在第三车到终点之前、行人仍在题设运动区间内。

例：快中慢车同一全程分别100、120、150分钟，取全程600份，速度依次6、5、4份/分钟。行人每分钟走100米，快车30分钟、中车35分钟分别与其相遇。两次相遇的车程分别180份、175份；初距相同，后者行人多走5分钟即500米，所以5份对应500米，每份速度为100米/分钟。全程600×100=60000米，行人初距30×(600+100)=21000米；慢车速400米/分钟，与行人合速500米/分钟，21000÷500=42分钟。代回30、35分钟、三车全程和行人方向；份数只是消去同一全程，真实路程须由已知100米/分钟确定。

## 迁移、边界与复核
A、B相距100千米，甲乙原速60和40千米/时，相向出发；原方案相遇后6分钟甲在66千米处遇丙，另一方案甲40、乙60并在同一地点 C 相遇；C 距 A 40千米，原方案乙需(100−40)÷40=1.5小时到 C，因此丙从66到40用1.5−1.1=0.4小时，速26÷0.4=65千米/时。这里两种方案恰好合速相同，不应推广为所有方案合速相同。

若两车到不同终点、出发时刻不同、行人掉头或中途停留，不能把“车程＋人程”直接当同一初距；若只知两个地点相距若干却不知方向，应保留位置分支。逐项检查原题所有问题、时间先后、单位及完整运动条件；数值题不强制画图。
