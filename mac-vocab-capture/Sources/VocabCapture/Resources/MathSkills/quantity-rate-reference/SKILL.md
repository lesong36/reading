# 量率问题

量是具体的数，可以带单位，例如 $3$ 元、$30$ 人。率是两个量相除的结果，不带单位，例如 $\dfrac{1}{5}$。讲义 Q6-01、Q6-02。

量和率不能相加。率可以乘在量上，也可以用一个量去除以一个率。

# 单位一

把谁平均分，谁就是单位一。

已知单位一，用乘法。$A$ 有 $50$ 元，$B$ 是 $A$ 的 $\dfrac{1}{5}$，则 $B = 50 \times \dfrac{1}{5} = 10$ 元。$B$ 比 $A$ 多 $\dfrac{1}{5}$，则 $B = 50 \times \left(1+\dfrac{1}{5}\right) = 60$ 元。

未知单位一，用除法。$B$ 是 $A$ 的 $\dfrac{1}{5}$，并且 $B$ 是 $50$ 元，则 $A = 50 \div \dfrac{1}{5} = 250$ 元。

“多 $\dfrac{1}{2}$ 元”带了单位，这是量，正过来说和反过来说都是五角钱。“多 $\dfrac{1}{2}$”不带单位，这是率，不能把“甲比乙多 $\dfrac{1}{2}$”直接说成“乙比甲少 $\dfrac{1}{2}$”。

# 量率和线段对齐

线段上面写量，下面写率。不参加语文小组的有 $30$ 人，参加的是全班的 $\dfrac{1}{3}$，那么 $30$ 人对应的是 $1-\dfrac{1}{3}=\dfrac{2}{3}$。

$$\frac{2}{3}x = 30,\qquad x = 30 \div \frac{2}{3} = 45$$

前 $4$ 天每天背 $15$ 个单词，背了 $60$ 个，又知道还剩全书的 $\dfrac{2}{5}$ 没背，另外还给出已背单词里另有 $30$ 个。已背的 $60+30=90$ 个对应 $1-\dfrac{2}{5}=\dfrac{3}{5}$，全书是 $90 \div \dfrac{3}{5} = 150$ 个。

# 量的差对应率的差

两个率之间夹着一段具体数量，总量等于这段数量除以两个率的差。

一半与三分之一相差 $30$：

$$\frac{1}{2}-\frac{1}{3} = \frac{1}{6},\qquad \text{总量} = 30 \div \frac{1}{6} = 180$$

# 单位一不统一时先化成同一个

第二天看的是“剩下的 $\dfrac{2}{5}$”，全书才是单位一。剩下的是全书的 $1-\dfrac{1}{6}=\dfrac{5}{6}$，第二天看的是全书的 $\dfrac{5}{6}\times\dfrac{2}{5}=\dfrac{1}{3}$。再和第一天的率相减，得到夹在中间的那一段率。

也可以从最后剩下的页数倒推，每一步用 [[还原问题]]：除以剩下的率，加回送走或吃掉的具体数量。全书看了 $\dfrac{1}{4}$ 以后，又看了剩下的 $\dfrac{2}{3}$，最后剩 $20$ 页。倒推时，$20$ 是第二天没看的那 $\dfrac{1}{3}$，第二天开始前有 $20\div\dfrac{1}{3}=60$ 页；这 $60$ 页是全书的 $\dfrac{3}{4}$，全书是 $60\div\dfrac{3}{4}=80$ 页。
