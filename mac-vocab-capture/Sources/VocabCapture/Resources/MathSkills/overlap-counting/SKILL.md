# 重叠问题

两部分叠在一起时，中间那一块同时属于两边。直接相加，这一块会被算两次。两个圆怎么画见 [[韦恩图]]。讲义 U1-02。

# 先加再减

$$A \cup B = A + B - A \cap B$$

只做一件的、只做另一件的、两件都做的，三段互不重叠，再相加，总数也一样。

知道总数和两部分，求重叠：

$$\text{重叠} = A + B - \text{总数}$$

# 图形上的重叠

数方阵、数图形时，公共的边或公共的点同样只能算一次。先按完整图形数，再减去被重复计算的那一条边或那一个顶点。

两条线段接在一起，接头的那一点是公共端点。总长度等于两段长度相加再减去重叠的那一截；已知总长求重叠，就是两段之和减去总长。

口诀：加在一起多算了一次，减掉一次就回到原来的整体。
