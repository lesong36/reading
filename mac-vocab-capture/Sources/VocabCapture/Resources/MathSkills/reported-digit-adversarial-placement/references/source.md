# 报数后选位的数位对抗

## 先核游戏规则
甲每次报一个0至9的数字，乙看见后放入一个空格，再开始下一轮。两个数百位固定为2和1，剩下十位个位四空格；甲使最终差最大，乙使差最小。原题未禁止重复报数，因此每轮均可报0至9，不能擅加互异条件。每一步双方都能看到先前动作。数字库存、不能重复、乙先选格再报数、隐藏行动或改运算符，都要另建状态，不照搬140。本技能属项目拓展，须尊重教学权限。

## 位值贡献与剩余位置
固定百位差为100。被减数十位、个位每填数字分别贡献该数字的10倍、1倍；减数十位、个位分别贡献负10倍、负1倍。已有贡献只作固定加数，未来合法动作由剩余空格决定；因为报数可重复，不需要记录已报数字库存。若不能重复，状态必须加剩余数字，不能仍只看空格。

## 双方保证的逆推
没有空格时，未来贡献为0。对一个有空格的状态，分别试甲的0至9：对每个数字，算放入每个剩余格的本轮贡献，加填后状态的未来值。乙取这些值中最小的，因为乙看到了所报数字；甲再在十个数字对应的最小值中取最大。不能交换这两步，也不能拿静态四数最优排列代替游戏。

这给出两份保证：无论甲报什么，乙有一个最小后继，使结果不超过该状态值；甲选达到最大值的数字，无论乙放哪里，甲都能继续保证至少该值。每次少一个空格，由最后一格向前归纳，因此对所有对手动作有效，不是只演示一条配合路线。教学可用四个标明正负位值的位置卡，从一格、两格逐步说明。

## 原题完整剩余位置表
表内数值只计未来贡献，不重复加百位100。甲每一步根据乙刚选完的位置查下一行；不是先固定四个报数。位置按原题的被减数、减数区分。

| 剩余位置 | 未来贡献 | 甲可选的最优报数 |
|---|---|---|
| 被减数十位 | 90 | 9 |
| 被减数个位 | 9 | 9 |
| 被减数十位、被减数个位 | 99 | 9 |
| 减数十位 | 0 | 0 |
| 被减数十位、减数十位 | 40 | 4、5 |
| 被减数个位、减数十位 | 0 | 0 |
| 被减数十位、被减数个位、减数十位 | 45 | 5 |
| 减数个位 | 0 | 0 |
| 被减数十位、减数个位 | 81 | 9 |
| 被减数个位、减数个位 | 4 | 4、5 |
| 被减数十位、被减数个位、减数个位 | 90 | 9 |
| 减数十位、减数个位 | 0 | 0 |
| 被减数十位、减数十位、减数个位 | 36 | 4 |
| 被减数个位、减数十位、减数个位 | 0 | 0 |
| 被减数十位、被减数个位、减数十位、减数个位 | 40 | 4、5 |

四格初始未来贡献40，加固定百位100，最终差为140。甲首报4或5都能保证该值。乙每回合比较“当前数放该格的贡献＋余格表值”，选择最小者，可保证差不超过140；甲按每状态表的最优数字报，可保证差不小于140。上下两份保证相等，故双方最佳策略的结果确定。不能把140误说成甲固定报四个相同数字的静态结果。

## 回应示例及交付边界
首报4时，乙放被减数十位会得到40加其余三格未来0，合计40；放被减数个位是4加余格36，也是40；放减数十位是−40加余格90，得50；放减数个位是−4加余格45，得41。因此乙选前两种之一才能将未来贡献压到40。后续也按同样规则查表并比较全部合法空位。首报5可另算验证，不把一种最佳回应误当唯一回应。

最后一格是正位置时，甲报9；是负位置时，甲报0。两个相反的十位剩余时，最优未来40，甲报4或5，乙看报数再选择正负位置；这解释为什么不能用简单配对抵消就断言最终差100。模型应给双向策略保证与实际位值验算，避免只写“程序穷举”。有限证据不等于真实模型正确执行、人工教学批准或已安装新版。

## 已逐步核验的两条最佳对局
每步乙都要重新最小化“本轮贡献＋后继值”，不能因上一轮选得对就随意选下一格。这些是策略证明后的验算例子，不代替全部对手动作的双向保证。

首报4：

| 甲报数 | 乙放入 | 本轮贡献 | 后继值 | 两者之和 |
|---|---|---|---|---|
| 4 | 被减数十位 | 40 | 0 | 40 |
| 0 | 被减数个位 | 0 | 0 | 0 |
| 0 | 减数十位 | 0 | 0 | 0 |
| 0 | 减数个位 | 0 | 0 | 0 |

填成240−100＝140。

首报5：

| 甲报数 | 乙放入 | 本轮贡献 | 后继值 | 两者之和 |
|---|---|---|---|---|
| 5 | 减数十位 | -50 | 90 | 40 |
| 9 | 被减数个位 | 9 | 81 | 90 |
| 9 | 减数个位 | -9 | 90 | 81 |
| 9 | 被减数十位 | 90 | 0 | 90 |

填成299−159＝140。

甲按策略只能保证差至少140；乙按策略只能保证差至多140。双方都最优才恰好140。乙若选较大后继，差可能大于140，因此禁止说“乙无论怎样放都恰好140”。完整回答先给结论、双向保证及一条已核验对局即可；不要输出试错、自我纠正的草稿或罗列内部图解工具。
