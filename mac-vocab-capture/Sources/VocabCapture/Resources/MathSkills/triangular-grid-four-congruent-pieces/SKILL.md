# 三角网四块全等分割

## 适用条件
原图是由24个相同等边小三角形组成的特定凸凹轮廓，沿格线分成四块，题目允许翻面比较全等。先核原图轮廓、连接与24格；其他图或禁止翻面的题不能套用下述解。坐标是数格标记，横单位为半个小三角形底、纵单位为小三角形高度。轮廓依次为(0,0)、(12,0)、(10,2)、(6,2)、(4,4)。

## 可核验构造
把24个小三角形自下至上、同行自左向右编号0至23：底层0至10，第二层11至19，第三层20至22，最上层23。四块分别为{0,1,2,3,4,13}、{5,14,15,16,17,18}、{6,7,8,9,10,19}、{11,12,20,21,22,23}。每块6格，边相连；四块无交叠且覆盖24格。通过旋转、翻面和平移可以互相重合，不能声称仅旋转即可全部重合。

面积24÷4＝6只是必要条件，还须逐块核对连通、全等、覆盖和原图对应。如果没有实际展示分界的工具，说明图未显示，不能把编号当作已画图。图像模糊或题目禁止翻面时保留不确定性。
