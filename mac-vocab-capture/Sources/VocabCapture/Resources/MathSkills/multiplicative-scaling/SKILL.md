# 倍比问题

两个同类量成倍数，先求出这个倍数，再把另一个量乘上同样的倍数。它和 [[归一与归总]] 相邻：归一先求出 1 份，倍比先求出几倍。来源是应用题宝典。

$$倍数 = 总量 \div 一个数量$$

$$另一总量 = 另一个数量 \times 倍数$$

$100$ 千克油菜籽榨油 $40$ 千克，现有 $3700$ 千克油菜籽。$3700$ 是 $100$ 的 $37$ 倍，榨油 $40 \times 37 = 1480$ 千克。

$$40 \times (3700 \div 100) = 1480$$

$300$ 名师生植树 $400$ 棵，全县 $48000$ 名师生：$48000 \div 300 = 160$ 倍，植树 $400 \times 160 = 64000$ 棵。

口诀：先问新的数量是原来的几倍，再把对应的结果乘上这个倍数。
