# 和差问题

知道两个数的和与差，就能求出这两个数。讲义 Q3-01。

甲、乙共有 $30$ 元，甲比乙多 $14$ 元。

# 两个公式

把甲多出来的 $14$ 元拿走，剩下的 $30-14=16$ 元是两个乙，乙是 $16 \div 2 = 8$ 元。

给乙补上缺少的 $14$ 元，变成 $30+14=44$ 元，是两个甲，甲是 $44 \div 2 = 22$ 元。

$$\text{大数} = (\text{和} + \text{差}) \div 2$$

$$\text{小数} = (\text{和} - \text{差}) \div 2$$

和是 $50$、差是 $14$ 时，大数是 $(50+14)\div 2 = 32$，小数是 $(50-14)\div 2 = 18$。

两筐苹果共 $50$ 个，大筐比小筐多 $10$ 个：小筐 $(50-10)\div 2 = 20$，大筐 $(50+10)\div 2 = 30$。

# 为什么要先处理差

和直接除以 $2$，得到的是两人都一样多时的数。题目里两人已经不一样多，要先把差砍掉或补上，线段才会一样长。

# 三个数：剥洋葱

$A$、$B$、$C$ 共 $180$ 人，$A$ 比 $B+C$ 多 $12$ 人，$B$ 比 $C$ 多 $4$ 人。

1. 把 $B+C$ 捆成一个整体 $D$。$A$ 和 $D$ 的和是 $180$，差是 $12$。
2. $A = (180+12)\div 2 = 96$，$D = (180-12)\div 2 = 84$。
3. 再拆 $D$：$B$ 和 $C$ 的和是 $84$，差是 $4$。$B = (84+4)\div 2 = 44$，$C = (84-4)\div 2 = 40$。

验算：$96+44+40 = 180$。

口诀：和加差除以 $2$ 得大数，和减差除以 $2$ 得小数。三个数时，先捆成两个数。
