# 正反比例

两种量一起变化。对应的两个数相除，商始终不变，就是正比例。对应的两个数相乘，积始终不变，就是反比例。来源是应用题宝典。许多和倍、工程、行程题都可以改写成比例。

# 正比例

商一定。做题效率不变时，题数和时间成正比例。$4$ 道题用 $28$ 分钟，$91$ 分钟能做 $x$ 道：

$$28 : 4 = 91 : x,\qquad x = 91 \times 4 \div 28 = 13$$

已修的是未修的 $\dfrac{1}{3}$，再修 $300$ 米后，已修的变成未修的 $\dfrac{1}{2}$。公路总长不变，把它对齐成同样的份数。

原来已修占全长的 $\dfrac{1}{4}$，写成 $3:12$。现在已修占全长的 $\dfrac{1}{3}$，写成 $4:12$。多出来的 $1$ 份是 $300$ 米，全长 $12$ 份是 $300 \times 12 = 3600$ 米。这和 [[统一不变量]] 是同一种对齐。

# 反比例

积一定。书的页数不变，每天看的页数和天数成反比例。每天 $24$ 页要 $15$ 天，每天 $36$ 页要 $x$ 天：

$$24 : 36 = x : 15,\qquad x = 24 \times 15 \div 36 = 10$$

# 怎么判断

先问哪个量没变。没变的是两个量的商，用正比例，写成比再交叉相乘。没变的是两个量的积，用反比例，大的一份对应小的另一份。
