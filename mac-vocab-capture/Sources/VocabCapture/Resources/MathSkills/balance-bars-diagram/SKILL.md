# 条形对比图

两条竖条靠在一起，高的表示多，矮的表示少。高出的那一截切成两半，一半移到矮的上面，两条就一样高。`Gemini_A` 的专家建议把移多补少画成这种图。移动多少仍按 [[移多补少]] 计算。

# 怎么画

1. 左边画高条，右边画矮条，高度按两个数来。
2. 在矮条的高度上画一条水平线，穿到高条上。线以上的一截就是差。
3. 把这一截从中间切开。下面一半留在高条上，上面一半移到矮条顶上。
4. 移动量等于差除以 $2$。移完后，两条都等于平均数。

小乖 $10$ 个苹果，小明 $6$ 个。差是 $4$，切开后每半是 $2$。小乖留下 $8$，小明变成 $8$。

$$\text{移动量} = (10-6)\div 2 = 2$$

两人最后都是 $(10+6)\div 2 = 8$。

三个人时，先把三条的总高度加起来，再除以 $3$，画出一条一样高的横线。高出横线的切下来，补到低于横线的条上。补进去的和切下来的相等。

口诀：高出的一截对半切，一半移过去，两边齐平。
