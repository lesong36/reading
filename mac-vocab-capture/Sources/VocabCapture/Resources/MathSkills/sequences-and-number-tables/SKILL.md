# 数列与数表

## 适用与先备
用于有明确生成规则的数列、等差排列、周期数列及规则数表的定位、求项、求和。需整数四则、按序列举、带余除法；较长求和和递推属于项目拓展提示，应尊重学习权限。只展示有限几项又没有限定规则时，可以提出候选并验证已知项，不能证明下一项唯一，更不能承诺任意数列通法。

## 先读规则再找位置
记下从第几项开始、首项、相邻变化以及排列方向。数表每行多少个、是否从1起、左右是否交替、是否有缺格都要确认。不能把“一行图”读成“一列”，也不能把蛇形表当逐行同向表。图看不清时明确需要确认的行列，不能靠题名猜排布。

## 计算路线
1. 直接递推先列足够多的项，检查每次使用前一项还是前两项。若差是固定数，跳到第n项需走n−1次相邻间隔，不是n次；用重复相加或“间隔数×每次增加量”解释。
2. 若差也按题设递增，先列差再累加；若仅观察到前三个差相同，这只是暂定候选。平方、奇偶交替等规律必须逐项核对，尤其不能只符合前两个数就宣称找到规律。
3. 周期需有题设或结构支持，不能从少量重复数就断定无限重复。用指定项序号除以周期长度；余数0对应周期末项，其余对应相应位置。要把第1项和余数的约定说清。
4. 逐行同向、每行固定k个且从1递增的表，第r行前有r−1整行，跳过（r−1）×k个数后再数到第c个。反求行列时用“序号减1”再做带余除法，避免整行末尾被算到下一行。蛇形偶数行须从右向左定位。
5. 等差求和可首尾配对，每对和相同；偶数项有一半项数那么多对，奇数项留下中间一项。只对确有同差的连续项使用，不能把任意数列都套首尾平均。

## 正例
每行4个数，从1起逐行向右递增，第6行第3列前有5整行共20个数，再数3个得23。反查23：22÷4＝5余2，故第6行第3列。明确每次加3的数列2、5、8……第7项跨6个间隔，是2＋6×3＝20；顺写2、5、8、11、14、17、20核对。求2＋5＋8＋11＋14＋17，三对首尾各19，和57，也可逐项累加核对。

## 反例与边界
只给1、2、4，下一项可按“每次乘2”取8，也可按“依次加1、2、3……”取7，不能唯一确定。若要求按小学常见规律填空，应说“按每次乘2这一候选规律”，而不是否认还有其他可能。排列表每行长度改变时，上面的整行乘法定位也不成立。

## 交付
标明规则来自题设还是观察，核对项号、首尾、余数0及所有小问。需要表格时只呈现明确读出的或依已说明规则计算的单元格，不编造不可见标签；无法唯一确定时给条件式回答和缺失条件。

## 交错子列：按位置拆开再合并
相邻项看不出同一规则时，先按奇数位置、偶数位置分别抄出；更一般地，按每k项中相同位置拆成k条子列。必须核对每个已展示的值，不能只取前两项猜规律。只有例项时，要明确“按下面这一与全部已知项相符的候选规律”，不声称有限项保证唯一延伸。
1. 写清各子列的首项、方向、等差步长或完整周期；它们可以使用不同规则，不能把整个交错数列当一条等差数列。
2. 先判断最后给定的值属于哪条子列。总长为2n时奇偶位置各n项；末项在第2n−1位时奇位n项、偶位n−1项。若仅给末尾数值而同值可能出现在多个位置，需按停止条件判断，不能任取第一次出现。
3. 等差子列在步长非零且方向吻合时，用“末首差÷步长+1”求项数，并核差可整除；步长为0或端点不在该列则单独处理。周期子列以自己的项号除周期长度，算整周期和、剩余前缀和；余0不添加下一周期。两个子列各自求和后相加。
4. 问某个值出现几次，必须分别在全部子列中计数，再相加：等差列检查目标是否在首尾之间且差可整除，成立计1；常数列目标等于常数则计该列全部项；周期列每整周期计周期内该值的频数，再逐个核尾段。即使两个子列出现同值，也是不同位置，都要计数。
5. 用总项数、最后几项和分组求和交叉检查。按k个位置拆分时，N除k得q余r，前r条各q+1项，其余各q项；不要把总列的项号余数直接当子列周期余数。

## 原题410兴趣2：等差与周期交错
按与全部展示项相符的候选：奇位1、4、7、10……100，每次加3，共(100−1)÷3+1=34项；100为奇位末项，因此偶位只有33项，依次重复1、2、3。全列34+33=67项。奇位首尾配17对，每对101，和1717；偶位11个周期，每周期6，和66；总和1783。末尾应为97、3、100，不能在100后多添周期项。

## 原题410拓展1：值相同也要分别计数
按与全部展示项相符的候选：偶位100、98、96……0，共51项；末项在偶位，奇位也有51项，循环1、2、3、2。奇位12整周期后余1、2、3，值2出现12×2+1=25次；偶位中的2另出现1次，全列共26个2。奇位和12×8+1+2+3=102；偶位首尾配25对每对100并留中间50，和2550；总和2652。不能把偶位的2漏掉，也不能把周期误读为1、2、3。
