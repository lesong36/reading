# 构图布数

按条件把树或数字放到图形的顶点、边上，让每条线上的个数或数字和满足题目。来源是应用题宝典。先算如果没有交叉会数重多少，再决定顶点上的点被几条线共用。

# 树要种成若干行

十棵树栽五行，每行四棵。五角星有 $5$ 条边，每边 $4$ 棵，每个点被两条边共用：

$$4 \times 5 \div 2 = 10$$

九棵树栽三行，每行四棵。三角形每边 $4$ 棵，三个顶点各被数了两次，要减掉 $3$：

$$4 \times 3 - 3 = 9$$

# 每条线上的数和相等

把 $12$ 拆成 $1$ 到 $7$ 里三个不同数的和，有五种：$1+4+7$、$1+5+6$、$2+3+7$、$2+4+6$、$3+4+5$。

$4$ 出现三次，其余每个数出现两次。出现次数多的数，放在更多条线的交点上。$4$ 放在三条线的交点，其余的数放在两条线的交点。

口诀：先统计每个数或每个点被用了几次，次数多的放在交叉更多的位置。
