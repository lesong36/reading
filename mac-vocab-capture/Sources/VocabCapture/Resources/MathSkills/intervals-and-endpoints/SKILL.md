# 植树问题

等量间隔中的树、灯、楼层或锯段，先区分点与间隔，再检查排列形状、端点和整数条件。讲义 Q3-10、Q3-11。

## 适用条件与排除

从本题原图确认总长、间距以及两端是否计算，不能从方法例题补条件。直线两端情况缺失时，可解释不同情况，但不选择本方法直接给唯一棵数；若本次选择任务要求条件不足时返回 null，主方法和画法都应留空。起点、终点或间距看不清时同样不猜。

要求物体恰好等距、覆盖整段且规定端点有物体时，相应长度必须整除间距。封闭环先检查周长能否整除；若还要求多边形各角都有物体，**每一条边的长度也必须整除间距**。周长整除不能替代每边检查。任一必要条件不满足时，说明不存在符合这些条件的排列，不能把所得小数或余数舍去后套公式。

## 直线上的三种

段数 = 总长 ÷ 间距。确认段数为非负整数，再按题面端点条件计数：

- 两端都种：棵数 = 段数 + 1。30米、每5米一棵，两端都种，共30÷5+1=7棵。
- 只种一端：棵数 = 段数。40米、每4米一盏灯，只算一个端点，共40÷4=10盏。
- 两端都不种：棵数 = 段数 − 1。两栋楼之间40米、每4米一盏，楼旁两个端点都不能装，共40÷4−1=9盏。

若题目允许末段不等长、剩余长度或未覆盖端点，应先核对该题的规则，不能默认以上整段等距公式。

## 封闭环与指定角点

围成一圈时，首尾是同一点，不再加1。满足等距整数条件时，棵数 = 周长 ÷ 间距。周长30米、每隔3米种一棵，共10棵。

正方形四角都要装灯时，逐边验证后再计数。例如每边24米、间距8米，每边3段，四边共12段，闭环12盏灯。若每边22米、间距8米，22÷8不是整数，即使周长88米可整除8，也不可能同时满足四角有灯与全程每8米一灯。不能返回88÷8=11盏作为符合要求的答案。

点与间隔图的原生 interval 模板只支持连续编号的直线位置，不支持闭环。不要为了画图把环形排列套入该模板。

## 楼梯、锯木头与反求总长

从1楼到8楼实际有8−1=7个楼层间隔。每层间的台阶数乘7得到总台阶数，不把出发楼层自身算一段。

一根木头锯成5段，切口不在两头，刀数为5−1=4；必须确认一次一刀、没有叠放等改变切割规则的条件。

已知棵数求总长时，先按端点条件还原段数，再乘间距。两端都种时，段数 = 棵数 − 1；只种一端时段数 = 棵数；两端都不种时段数 = 棵数 + 1。反向检查所得长度、段数和端点是否满足原题。
