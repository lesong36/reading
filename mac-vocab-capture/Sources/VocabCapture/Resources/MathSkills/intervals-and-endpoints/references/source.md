# 植树问题

先把路分成一段一段，段数等于总长除以间距。棵数比段数多 $1$、少 $1$，还是相等，只看两端算不算。讲义 Q3-10、Q3-11。

$$\text{段数} = \text{总长} \div \text{间距}$$

# 直线上的三种

两端都种。$30$ 米的路，每 $5$ 米一棵，两端都种。段数 $30\div 5 = 6$，棵数 $6+1=7$。

$$\text{棵数} = \text{段数} + 1$$

只种一端。$40$ 米的路，每 $4$ 米一盏灯，只在起点装。段数 $40\div 4 = 10$，灯数就是 $10$。

$$\text{棵数} = \text{段数}$$

两端都不种。两栋楼之间 $40$ 米，每 $4$ 米一盏，楼的两端不能装。段数 $10$，灯数 $10-1=9$。

$$\text{棵数} = \text{段数} - 1$$

$60$ 米、每 $6$ 米、两端都种：$60\div 6 + 1 = 11$ 棵。$80$ 米、每 $8$ 米、只装一端：$80\div 8 = 10$ 盏。两楼之间 $50$ 米、每 $5$ 米、两端都不种：$50\div 5 - 1 = 9$ 棵。

# 封闭、楼梯、锯木头

围成一圈时，首尾连在一起，没有单独的两端。棵数等于段数。周长 $30$ 米、每隔 $3$ 米种一棵：$30\div 3 = 10$ 棵。

从 $1$ 楼爬到 $8$ 楼，两端的楼层都算，要爬的层数是 $8-1=7$。物体数等于间隔数加 $1$，间隔数等于物体数减 $1$。

把一根木头锯成 $5$ 段，切口不在两头，刀数是 $5-1=4$。刀数等于段数减 $1$。

# 已知棵数求总长

先由两端的情况把棵数还原成段数，再乘间距。两端都种时，段数等于棵数减 $1$，总长等于段数乘间距。

口诀：两端都算，加 $1$；只算一端，不加不减；两端都不算，减 $1$；围成圈，棵数等于段数。
