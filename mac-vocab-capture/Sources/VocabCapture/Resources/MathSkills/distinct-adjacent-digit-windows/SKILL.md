# 相邻数码对互异的数位最值

## 适用条件
题目限定从给定数字集合选用数字组成自然数，每两个相邻数码组成的两位数互不相同。确认数字能否重复、自然数首位能否为零、是否比较相邻有序对而非无序对；有数字使用次数、固定位数等额外限制时，必须一并检查。

## 先限定长度再择优
每一个相邻位置产生一个有序数码对，长为n的数有n−1个相邻对。若可用不同有序对只有m种，n−1不能超过m，因此长度至多m+1。位数越多的正整数越大；先寻找最长可行长度，若上界不可达到，就依次降低长度并检查。对某一长度从左到右尝试允许的较大数字，但每次须同时检查新相邻对未使用且剩余位置仍有合法接法；不能因某一位大就忽略后面无法填完。用记录表写已用的有序对和当前末位，末位就是下一对的首位。

## 原题例
只用8和9，所有相邻两位数互不相同。可能的对只有88、89、98、99，故至多5位。求最大五位数，前两位优先99；第三位不能再填9（否则重复99），填8。第四位若填9，则用到89，最后一位填9会重复99，填8会重复98，没有合法末位，因此第四位填8，最后填9，得到99889。它的四个相邻对为99、98、88、89，恰好各不相同，达到五位上界；比它前缀大的候选已逐位排除，故它是最大数。

## 边界与回查
89与98是不同的有序对；两次出现88则重复，即使数字8本身允许重复。若有前导零或每种数字出现次数限制，要在每步一起检查。最多位数只是上界，必须展示实际构造才能说达到。若题目要求所有方案，保留所有合法分支，不只输出字典序最大的一个。
