# 年龄问题

两人一起长大，每人每年都长 $1$ 岁，年龄差始终不变。讲义 Q3-08、Q3-09。

# 差不变

胡老师 $37$ 岁，学生 $10$ 岁，差是 $37-10=27$ 岁。$5$ 年后是 $42$ 岁和 $15$ 岁，差仍是 $27$ 岁。

$$(A+n)-(B+n) = A-B$$

两人同时加上或减去同样的年数，差不变。题目说“几年后甲比乙大多少”，差就是现在的差。

# 和怎么变

$1$ 个人过 $1$ 年，和增加 $1$ 岁。$N$ 个人过 $M$ 年，年龄和增加 $N \times M$ 岁。$2$ 人过 $5$ 年，和增加 $2\times 5 = 10$ 岁。

人数一样的两组，例如父母 $2$ 人和子女 $2$ 人，过同样的年数，两组的年龄和都增加一样多，两组之和的差也不变。

人数不一样时，人多的那一组每年多长几岁。父母 $2$ 人、子女 $3$ 人，子女每年比父母多长 $1$ 岁，$5$ 年后两组年龄和的差缩小 $5$ 岁。

# 和倍数连在一起

“哥哥比弟弟大 $12$ 岁，哥哥的年龄是弟弟的 $3$ 倍”，差不变，倍数会随时间变。这种题先按 [[差倍问题]] 处理：差 $12$ 对应 $3-1=2$ 份。

若干年后倍数变了，仍然抓住差不变，把两个时间的比写成同一份差，再对齐份数。做法和 [[统一不变量]] 里“差不变”相同。

# 做题时

1. 先写出现在的差。差在同一组人身上过同样的年数以后不变。
2. 问年龄和，用人数乘年数，加到原来的和上。
3. 两组人数不同，先算每年年龄和相差几岁，再乘年数。
4. 题目把不同年份的年龄放在一起，先把所有人平移到同一年，再列和或倍。
