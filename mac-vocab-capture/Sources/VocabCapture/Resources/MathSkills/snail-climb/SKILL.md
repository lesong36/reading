# 蜗牛爬井

白天向上爬，晚上向下滑。最后一天爬出井口以后，不再下滑。讲义 Q4-16。

# 先留下最后一次

白天爬 $4$ 米，晚上滑 $2$ 米，井深 $50$ 米。

最后一次白天能爬 $4$ 米出井，这 $4$ 米单独留下：$50-4=46$ 米。前面每天净爬 $4-2=2$ 米，$46\div 2 = 23$ 天。再加上出井的那一天，共 $24$ 天。

井深 $16$ 米、每次爬升后休息，若按完整周期去数，数完再去掉最后一次并没有发生的休息。

口诀：先减去最后一次能爬出去的高度，剩下的高度除以每天的净高度，再加回这最后一天。

# 直接用净高度会多算

白天爬 $2$ 米、晚上滑 $1$ 米、井深 $4$ 米。若写成 $4\div(2-1)=4$ 天，默认第四天晚上还在往下滑。实际上第三天白天已经可以爬出井口。先检查：前几天的净高度加上最后一次白天的高度，是否已经够到井口。

# 余数还要再爬一天

白天爬 $5$ 米，每天净爬 $3$ 米，井深 $40$ 米。先留下最后一次白天能爬的 $5$ 米，剩 $35$ 米。$35\div 3 = 11$ 天余 $2$ 米，前面需要 $12$ 个完整日夜，才能达到至少 $35$ 米。第 $12$ 天白天最多达到 $11\times 3+5=38$ 米，尚未出井；第 $12$ 天夜晚后在 $36$ 米，第 $13$ 天白天到达 $40$ 米后立即停止。因此共 $12+1=13$ 天。剩余高度除以净高度有余数时，完整日夜数要向上取整，再加最后出井的一天。

# 已知天数求每天爬多少

$8$ 天爬完，最后一天爬 $4$ 米，前 $7$ 天净爬，每晚滑 $3$ 米，总高 $25$ 米。去掉最后一天：$25-4=21$ 米，每天净爬 $21\div 7 = 3$ 米。白天爬的是净爬加上下滑：$3+3=6$ 米。
