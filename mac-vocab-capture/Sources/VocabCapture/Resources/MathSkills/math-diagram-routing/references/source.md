# 数形结合

先判断题目里的关系是哪一种，再选一种图。图上的长度、面积、方框或一行，要能直接读出算式。下面六种是 `Gemini_A` 里固定使用的画法。

# 先选哪一种图

数量沿着时间变，同一个对象在加减，用 [[状态图]]。例如上车下车、购物找零、从结果倒推。

两个量相乘，或者要先求出 $1$ 份，用 [[面积图]]。例如单价和数量、速度和时间、工作效率。

要先假设再调整，用 [[列表法]]。例如鸡兔同笼、盈亏。头数很大时，改用面积图把多算的一块切掉。

一个整体按比切开，用 [[份数线段图]]。例如按比例分配、百分数。

同一段过程反复出现，用 [[周期图]]。例如彩灯、报数、蜗牛每天爬一段再滑一段。

其余比较长短、和差、倍数、年龄差，用 [[线段图]]。

两种关系套在一起时，分两步画。速度比是 $3:4$，先用份数线段把速度分成 $3$ 份和 $4$ 份，再用线段图把两人所走的路拼成路程和。

# 已经写好的画法

- [[状态图]]：方框是某一时刻的数量，箭头是加或减。
- [[线段图]]：短的是 $1$ 份或共有的部分，多出来的差用虚线。
- [[面积图]]：长乘宽是总量；多画出来的一块可以切掉。
- [[列表法]]：一行一种假设，差变成 $0$ 的那一行是答案。
- [[份数线段图]]：先加出总份数，再把一条线段切开。
- [[周期图]]：重复的画成相同的格，最后一次画到结束为止。

部分和整体的拼裁见 [[部分整体图]]。进货、卖出、剩余是状态图的一种，见 [[进销存图]]。

两边要拉平，用 [[条形对比图]]：高出的一截切一半移过去。两个集合相交，用 [[韦恩图]]：中间重叠的一块减一次。先把若干个圈成一组再平均分，仍是先加后除，用 [[归一与归总]]，不必再单画一种图。
