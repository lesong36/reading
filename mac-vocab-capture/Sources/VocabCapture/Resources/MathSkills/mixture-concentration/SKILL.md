# 浓度问题

浓度是溶质占整杯溶液的几分之几，和速度是路程占单位时间的几分之几是同一类比。讲义 Q6-12 到 Q6-14。

$$\text{浓度} = \frac{\text{溶质}}{\text{溶液}}$$

$$\text{溶液} = \text{溶质} + \text{溶剂}$$

# 知二求二

溶质 $30$ 克、溶剂 $70$ 克：溶液 $100$ 克，浓度 $30\div 100 = 30\%$。

浓度 $30\%$、溶液 $100$ 克：溶质 $100\times 30\% = 30$ 克，溶剂 $100-30=70$ 克。

浓度 $20\%$、溶质 $100$ 克：溶液 $100\div 20\% = 500$ 克，溶剂 $500-100=400$ 克。

$$\text{溶质} = \text{溶液} \times \text{浓度}$$

$$\text{溶液} = \text{溶质} \div \text{浓度}$$

# 变甜或变淡

$100$ 克、$10\%$ 的糖水，里面有糖 $10$ 克。

加糖 $100$ 克：溶质变成 $110$ 克，溶液变成 $200$ 克，浓度是 $110\div 200 = 55\%$。

加水只增加溶液，溶质不变，浓度变小。蒸发水只减少溶液，溶质不变，浓度变大。倒进另一杯时，两杯的溶质相加，两杯的溶液相加，再相除。

# 稀释和加浓

$16\%$ 的糖水 $50$ 克，里面糖 $8$ 克，水 $42$ 克。

稀释到 $10\%$，糖不变。新溶液是 $8 \div 10\% = 80$ 克，要加水 $80-50=30$ 克。

$$50 \times 16\% \div 10\% - 50 = 30$$

加浓到 $30\%$，水不变。水是 $50\times(1-16\%)=42$ 克，新溶液里水占 $1-30\%=70\%$，新溶液是 $42\div 70\% = 60$ 克，要加糖 $60-50=10$ 克。

$$50 \times (1-16\%) \div (1-30\%) - 50 = 10$$

两种糖水配成 $25\%$ 的 $600$ 克，手里有 $30\%$ 和 $15\%$。假设 $600$ 克全是 $30\%$，糖多出 $600\times(30\%-25\%)=30$ 克。每把 $100$ 克 $30\%$ 换成 $100$ 克 $15\%$，糖减少 $15$ 克。要换 $30\div 15 \times 100 = 200$ 克，所以 $15\%$ 的用 $200$ 克，$30\%$ 的用 $400$ 克。这和 [[鸡兔同笼]] 的假设调整是同一件事。

# 谁不变

加糖时水的质量不变。$10\%$ 的糖水要变成 $20\%$，水从占 $90\%$ 变成占 $80\%$。抓住水的克数，就能求出新的溶液质量，再减去原来的溶液，就是要加的糖。

两种溶液混合，混合前各自的溶质之和等于混合后的溶质。浓度高的多出来的部分，正好补浓度低的不足的部分，两部分的质量比与它们离目标浓度的距离成反比。这就是十字交叉：高浓度与目标的差，比上目标与低浓度的差，等于两杯质量的反比。
