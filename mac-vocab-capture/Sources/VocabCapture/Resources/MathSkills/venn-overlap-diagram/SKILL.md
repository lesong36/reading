# 韦恩图

两个圈相交。左圈是第一种，右圈是第二种，中间重叠的一块两边都算过。总人数等于两圈相加再减掉中间这一块。`Gemini_A` 的分类把它当作集合重叠的画法，算式和 [[重叠问题]] 相同。

# 怎么画

1. 画两个相交的圆。左圆上面写第一种的人数，右圆上面写第二种的人数。
2. 中间的交集写两样都有的人数。
3. 左圆剩下的一块等于左圆人数减去交集。右圆剩下的一块同样减一次。
4. 两圆盖住的全部，等于左圆加右圆再减去交集。

订语文报 $25$ 人，订数学报 $22$ 人，两种都订 $10$ 人。

中间写 $10$。只订语文的是 $25-10=15$，只订数学的是 $22-10=12$。至少订一种的是

$$25 + 22 - 10 = 37$$

班上若有 $40$ 人，两种都没订的是 $40-37=3$。这 $3$ 人画在两个圆的外面。

知道总人数和两个圆、不知道交集时，交集等于两圆之和减去并集。

口诀：中间那一块加了两次，减一次才是真正的总数。
