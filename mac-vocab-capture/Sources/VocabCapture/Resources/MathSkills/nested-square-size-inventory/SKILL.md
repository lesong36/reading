# 正方形嵌套细分与面积种类

## 入口与边界
原题要求把一个正方形分成小正方形，并同时限制成品总数与不同面积的种类。先核对“恰好”“至少”“全部相等”等措辞。这不是把所有块分成同一形状大小的问题，也不是任意长方形分割。以下是存在性构造，不证明最少切数或唯一方案；若题目给定固定边长、指定小块边长或禁止辅助格，要另行核对。
正边长不同就对应面积不同，但边长比例与面积比例不可混写。原题未给尺寸/单位时，以下数字只表示辅助份数，不写成题给的厘米。可以按同一比例缩放全部线段。

## 只数当前叶块
先画辅助虚线，再确定真正的实线分界。把3×3辅助格的左下2×2区域保留为一整块，内部辅助格线都不作为切线；其余五个单位格各一块，得到6块、两种面积。不能先剪散九格，再胶合四格冒充一块，题目没有授权胶合。
将一个当前完整小正方形横竖各等分为二，得到四个新方形：成品总数净增3，父方形不再计数。区分“细分两个不同原小块”和“继续细分刚产生的一小块”；两者会产生不同面积种类。每种面积必须至少有一个当前成品，细分历史里出现过的尺寸不算一种。

## 输出前逐项核对
只计算最终叶块：总数、每块都是正方形、成品面积种类数、无重叠和无缺口，全部同时满足。可用每种面积×块数的和复核总面积，但面积和相同不能替代分界图和覆盖证明。展示对应本题小问的完整math-grid围栏；一次有三个小问就分别给三个方案，不只回答第一问。新数字或不同块数需要重新构造和核验，不复制原例后只改数量标题。
本技能不承诺任意指定块数/种类都有解。题目要求全部小块等面积时，不能套用这些混合尺寸方案；题目要求形状不同长方形时也不是本构造范围。显示端仅检查输入格阵连通与对应块的同形，不替代这里的“每块为正方形、数量、面积种类”核对，也不代表用户已确认答案。
