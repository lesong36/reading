# 周期图

把重复的一段画成一格，格与格排开。普通的格用同一种画法，最后一次若不再重复，就单独画实线。`Gemini_A` 用它看蜗牛爬井、报数、彩灯和星期。算式仍是 [[周期问题]]：先定一格有多长，再做除法看余数。

# 找第几个

1. 把一个周期画成一排小格，按顺序写上内容。
2. 用总数除以一排的格数。
3. 余数是几，就点亮这一排的第几格。
4. 余数是 $0$，点亮这一排的最后一格。

彩灯按红、黄、蓝、绿重复。一排 $4$ 格。第 $25$ 盏是 $25\div 4 = 6$ 余 $1$，点在第一格，红色。

# 每天进一点、最后一天不同

井深、白天向上、晚上向下，每一天画两截：向上的一截和向下的一截。净上升是两截的差。

井深 $10$ 米，白天爬 $3$ 米，晚上滑 $2$ 米。前几天每天净升 $1$ 米。画到某一天白天的箭头已经碰到 $10$ 米，这一天的下滑不再画。

从 $7$ 米再爬 $3$ 米到达 $10$ 米，当天到顶。前面净升 $7$ 米用了 $7$ 天，加上到顶这一天，是 $8$ 天。直接用总深除以每天净升，会把已经出井的那个晚上也算成下滑。先在图上标出到顶的那一截，再数前面有几个完整的来回。详见 [[蜗牛爬井]]。

口诀：重复的画成相同的格；最后一次若中途结束，格就画到结束的地方为止。
