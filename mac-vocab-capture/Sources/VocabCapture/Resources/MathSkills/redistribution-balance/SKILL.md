# 移多补少

总量不变，只把多的移给少的，直到两边一样多。移动的数量是差的一半。两条竖条怎么切见 [[条形对比图]]。讲义 Q2-04。

# 两人平衡

小熊有 $10$ 颗巧克力，狐狸有 $4$ 颗。小熊给狐狸几颗，两人就一样多。

1. 求差：$10 - 4 = 6$。
2. 差平分：$6 \div 2 = 3$。
3. 小熊留下 $10 - 3 = 7$，狐狸变成 $4 + 3 = 7$。

$$\text{移动量} = (\text{大数} - \text{小数}) \div 2$$

小乖给小明 $1$ 个苹果，小明就多 $1$ 个，两人的差一下子缩小 $2$。所以只移动差的一半。

若每次只搬固定个数，先求出移动量，再除以每次的个数。盒子里有 $96$ 个和 $32$ 个乒乓球，每次从多的盒子拿 $8$ 个放到少的盒子。

$$(96 - 32) \div 2 = 32,\qquad 32 \div 8 = 4$$

需要搬 $4$ 次。差直接除以每次的个数，会把次数算成两倍。

# 多人平衡

目标是每人一样多，这个一样多的数就是平均数。

$$\text{每人} = \text{总数} \div \text{人数}$$

再看每人比这个数多几或少几，多的移给少的。$8$ 颗、$4$ 颗、$6$ 颗，总数 $18$，每人 $6$。多的 $2$ 颗正好补给少的 $2$ 颗。

# 三条守恒

1. 移来移去，总数不变。
2. 两人时，移动量等于差的一半。
3. 多人时，最后每人等于总数除以人数。

同一条守恒也能用来凑整。$98 + 47$ 可以从 $47$ 里借 $2$ 给 $98$，变成 $100 + 45 = 145$。
