# 工程问题

工作总量、工作效率、工作时间，和 [[行程问题]] 里的路程、速度、时间是同一套关系。讲义 Q6-04、Q6-05。

$$\text{工作总量} = \text{工作效率} \times \text{工作时间}$$

$$\text{工作效率} = \text{工作总量} \div \text{工作时间}$$

$$\text{工作时间} = \text{工作总量} \div \text{工作效率}$$

一根绳子 $100$ 厘米，$5$ 天编完，每天编 $100\div 5 = 20$ 厘米。要编 $40$ 厘米，需要 $40\div 20 = 2$ 天。

# 总量看成 1

绳子的具体长度不影响“几天做完”。把全部工作看成 $1$，单独做完要用 $10$ 天，每天的效率就是 $\dfrac{1}{10}$。乙 $15$ 天做完，效率是 $\dfrac{1}{15}$。

合作时效率相加：

$$\frac{1}{10}+\frac{1}{15} = \frac{3}{30}+\frac{2}{30} = \frac{1}{6}$$

两人合作 $1$ 天完成全部的 $\dfrac{1}{6}$，单独合作做完要用 $6$ 天。

中间有人休息时，先把各自单独做的天数乘上各自的效率，从 $1$ 里减去，剩下的再除以合作效率。

# 合做时一人比另一人多做

甲每小时完成 $\dfrac{1}{6}$，乙每小时完成 $\dfrac{1}{8}$。合做完成时，两人工作量之比是 $\dfrac{1}{6}:\dfrac{1}{8} = 4:3$。甲比乙多做的是总量的 $\dfrac{4-3}{4+3} = \dfrac{1}{7}$。若这多做的部分是 $24$ 个零件，总量就是 $24 \div \dfrac{1}{7} = 168$ 个。

不想用分数时，把总量设成各人单独完成时间的最小公倍数。甲 $12$ 小时、乙 $10$ 小时、丙 $15$ 小时，总量设为 $60$。效率分别是 $5$、$6$、$4$。甲先做 $2$ 小时后，剩下 $(60-5\times 2)\div(6+4) = 5$ 小时由乙、丙合做。

# 一边进、一边出

水池底部有排水管，上面有同样的进水管。打开 $4$ 个进水管，$5$ 小时注满；打开 $2$ 个，$15$ 小时注满。设每个进水管每小时进水 $1$ 份。

$4$ 个进水管 $5$ 小时进 $20$ 份，$2$ 个进水管 $15$ 小时进 $30$ 份。多出来的 $10$ 小时里，排水管排出了 $30-20=10$ 份，每小时排水 $1$ 份。一池水是 $4\times 5 - 1\times 5 = 15$ 份。

要在 $2$ 小时注满，这 $2$ 小时还要补上同时排走的 $2$ 份，一共需要 $17$ 份。每个进水管 $2$ 小时进 $2$ 份，$17\div 2 = 8.5$，至少打开 $9$ 个。

# 总量不变时的补偿

两种安排完成的是同一件工作。甲多做的，就是乙少做的。若“小明 $4$ 天的工作量等于小红 $6$ 天的工作量”，两人的效率比就是 $6:4$，再按份数去分这件工作。
