# 等量代换

两个式子里有同一个未知量时，先求出这一个，再代进另一个式子。讲义 Q2-03 把这件事分成三招。

# 先求一个，再求另一个

$2$ 个圆等于 $6$，所以 $1$ 个圆等于 $3$。另一个式子是“$1$ 个圆加 $1$ 个三角形等于 $10$”，三角形就是 $10 - 3 = 7$。

步骤：

1. 找出只含一个未知量、并且能直接算出来的那一句。
2. 求出这个量的 1 份。
3. 把它代进含两个量的那一句，求出第二个量。

# 按倍数代换

两个量成倍数时，先把大的换成若干个小的，全题就只剩一种量。师傅的零件是徒弟的 $3$ 倍，就可以把师傅换成 $3$ 个徒弟，再和徒弟的 $1$ 份合在一起。这一招和 [[和倍问题]] 是同一件事。

# 整组代换

题目把几个量捆在一起出现时，先把这一组看成一个新名字，求出这一组，再把这一组拆开。$A$ 比 $B+C$ 多，就先把 $B+C$ 叫成一个整体。这一招和 [[和差问题]] 里的剥洋葱是同一件事。

口诀：能单独求出的先求，求出来再代入；能换成同一种的先换；能捆成一组的先捆。
