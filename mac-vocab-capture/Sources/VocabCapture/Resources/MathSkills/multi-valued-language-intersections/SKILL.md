# 多人语言集合与直接交谈

## 建模与适用边界
每人可能会多种语言，应给每人列出允许的语言组合，不能当成一人只对应一种语言的配对表。只用题目给出的语言范围和每人会几种的配额。两人能直接交谈表示至少会一种共同语言；不能直接交谈表示没有共同语言。经第三人翻译能交流，不等于能直接交谈；如果题目允许翻译或只谈学习语言偏好，不能套用直接交谈规则。本方法是项目补充，遵守用户的拓展知识权限。

## 传播与完整性
先列每人的候选组合，划去明确不会的语言和禁止同时会的组合。把“某种语言有三人会”看作同一语言的三人组；任何不能交谈的两人都不能同在这组三人中。列出并筛掉不可能的三人组，再用会/不会和禁配条件确定共有语言。按每人配额补齐候选，并逐条回代交谈关系和每种语言的人数。一般情形若仍有多个组合，逐人试一个候选、传播剩余配额，矛盾则返回；保留全部解，不因找到一组就宣称唯一。也可能无解，不能自行添加每种语言至少一人或所有人各不相同等条件。

## 原题逐步证明
甲乙丙各会2种语言，丁只会1种；语言是汉、英、法、日。有一种语言四人中三人都会。甲会日语，丁不会日语，乙不会英语。甲丙、丙丁不能直接交谈，乙甲、乙丙可以。无人同时会日语与法语。

四种三人组逐一看：甲乙丙含不能交谈的甲丙；甲丙丁也含甲丙、丙丁；乙丙丁含丙丁；故共同语言的三人只能是甲乙丁。共同语言不是英语（乙不会）、不是日语（丁不会）、不是法语（甲会日语而禁日法同会），只能是汉语。

丁只会汉语。甲两种已确定为汉语、日语。丙与甲不能直接交谈，不会汉语、日语；丙两种只能是英语、法语。乙已会汉语，又要和丙直接交谈，第二种必须是英语或法语；乙不会英语，所以是法语。

| 人 | 会的语言 |
|---|---|
| 甲 | 汉语、日语 |
| 乙 | 汉语、法语 |
| 丙 | 英语、法语 |
| 丁 | 汉语 |

## 回代与交付
每人种数为2、2、2、1；汉语由甲乙丁三人共有。甲丙、丙丁无共同语言；乙甲共有汉语、乙丙共有法语。指定会/不会和日法禁配全部满足。上述每一步都是强制推断，因此唯一。不要把“所有语言由三人共有”或“两两均可交谈”当成原条件。

给学生的回答用共有语言三人组的排除、配额补齐和逐条回代即可，不必展示位矩阵或程序枚举。离线枚举验证不等于真实模型已正确执行或人工教学已批准。
