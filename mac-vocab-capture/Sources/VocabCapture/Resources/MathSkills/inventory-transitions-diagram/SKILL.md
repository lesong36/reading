# 进销存图

数量沿时间变化。原来有的是存，加进来的是进，离开的是销。图上每个时刻画一个方框，方框之间用箭头写上加或减。这是 [[状态图]] 用在库存上的一种画法。课堂里的进销存模型按这个推。

$$\text{现在的存} = \text{原来的存} - \text{销} + \text{进}$$

# 正向

从左边的初始数量画起，每发生一次变化就画一个箭头。

借还点有 $30$ 辆车，骑走 $30$ 辆，还回 $5$ 辆。

$$[30] \xrightarrow{-30} [0] \xrightarrow{+5} [5]$$

公交车按站结算。每一站先减去下车的人数，再加上上车的人数，得到开车时车上的人数，再作为下一站的初始存。

# 倒推

知道最后剩下多少，以及中途做了什么，就从最后一个方框往左走。箭头上的运算换成逆运算：减变成加，加变成减，除以 $2$ 变成乘 $2$。这就是画在流程图上的 [[还原问题]]。

空调第一天上午卖掉一半，下午卖掉 $4$ 台；第二天上午卖掉剩下的一半，下午卖掉 $2$ 台，最后剩 $3$ 台。

从 $3$ 开始往回：

1. 第二天下午卖掉 $2$ 台之前有 $3+2=5$ 台。
2. 第二天上午卖掉一半之前有 $5\times 2 = 10$ 台。
3. 第一天下午卖掉 $4$ 台之前有 $10+4=14$ 台。
4. 第一天上午卖掉一半之前有 $14\times 2 = 28$ 台。

原来有 $28$ 台。

口诀：正向从左往右，存减去销再加上进。倒推从右往左，每一步用逆运算。
