# 位值与小数数位

## 适用与先备
用于多位数与小数的读写、数位对应、大小比较、数字换位或小数点移动引起的数量变化。先理解十进制、整数加减乘除及小数的十分之一、百分之一含义。小数虽可用小学方式解释，并不代表任意含小数的高级数论问题都属四年级默认内容；未学知识需要明确说明。

## 用数位表还原事实
把数写入“百、十、个、小数点、十分、百分、千分”的对应位置，位数不够处仅为对齐补0。一个数字在不同位置代表不同量：4.07的7代表7个百分之一，4.7的7代表7个十分之一。整数前面的0不改变值但会影响“几位数”的表述；小数末尾补0不改数值，但测量精度是否相同取决于题意，不能混为一谈。

## 计算路线
1. 比较先看整数部分，整数相同则从十分位起依次比。可把小数部分补0到同样长度再比较，不能单看小数点后哪个整数大，也不能以小数位多判定更大。
2. 小数点右移一位表示数值乘10，右移两位乘100；左移则除以相应的10、100。说明动的是小数点还是某个数字：互换两数位与整串数字平移是两种不同操作。
3. 题给移位后的数比原数多或少多少，先对比它们相当于原数的几份，再求一份；如果“移动某个数字到首尾”，应按所有数字位置重新写数，不能直接认定乘10。
4. 数位填空可以按已知位值逐项拼合，检查十进制多位整数首位非零；单个数字0和小数0.xxx合法，应按题面位数与格式核对。若问所有可能数，按首位到末位有序列举并遵守重复限制；一个可行结果不能证明唯一或极值。
5. 单位换算先写等量关系。小数点移动是数值运算；米与厘米的换算还依赖1米＝100厘米，平方单位的倍数另算，不能因看到“平方”就仍乘100。

## 正例与验算
比较4.07和4.7，写为4.07与4.70：个位相同，十分位0小于7，所以4.07小。求6.08×100：六个一变成六个百，八个百分之一变成八个一，结果608；608÷100＝6.08。求0.56米是多少厘米，依据1米＝100厘米，所以0.56×100＝56厘米；56÷100米也等于0.56米。

## 反例及排除
4.07不是4.7；两者的0位于小数中间，不能删掉。4.70与4.7数值相等，是小数末尾的0情况。把352的末位2移到最前得到235，并非352×10或352÷10。若只说“移动一位”却没有说数字、小数点和方向，结论不足，不能自己补条件。

## 结果要求
回到原来的位值逐项复核；比较题写清比较对象，换算题带完整单位，移位题核对新旧数值与变化量。必要时展示数位表，表格每一列须对应真实位名，不画没有证据的数量图。若题目包含多个小问，每问都独立核对，不用一个数值代表全部答案。

## 整数部分范围与原题413超越2
非负有限小数去掉小数部分，得到不超过原数的整数；被去掉部分至少0、严格小于1。不能四舍五入，也不能把0.999当1。若所得整数加原数k倍得到T（k为正数），相当于整数部分的k+1倍，再加一个至少0、严格小于k的尾量。先用这个严格范围列可能整数，再用(T减该整数)除k还原原数，回查整数部分确实相符；没有候选则原条件无解。不能仅算T除(k+1)后就认定原数。
413超越2为所得整数加原数4倍=27.6。整数部分若至多4，原数小于5，所求和小于24；若至少6，所求和至少30。因此整数部分只可能5，原数为(27.6−5)÷4=5.65；回查去掉0.65得5，5+4×5.65=27.6。此例用范围和算术，不要求列方程。负数的“去小数部分”通常向0截去，不同于向下取整；若题含负数，须先明确规则，本分支的非负范围不能直接套用。
