# 五格十字剪拼正方形

适用条件：五个相同单位正方形组成十字，允许沿直线剪开并平移，题目没有规定更少的块数。以下构造保留中间整体，剪下四个三角形，共五块；无需翻面。坐标仅用于明确切线，实际教学可在方格纸上标记边的中点。

把十字放入 3×3 方格，左下角为 (0,0)，五格分别是下 (1,0)、左 (0,1)、中 (1,1)、右 (2,1)、上 (1,2)。沿以下线段剪开，并按向量移动靠外侧的小三角形：

| 切线两端 | 移动三角形的第三个顶点 | 平移向量（向右、向上） |
|---|---|---|
| (0,1) 与 (1/2,2) | (0,2) | (2,-1) |
| (2,0) 与 (1,1/2) | (1,0) | (1,2) |
| (1,3) 与 (2,5/2) | (2,3) | (-1,-2) |
| (3,1) 与 (5/2,1) | (3,2) | (-2,1) |

拼成的正方形顶点为 (0,1)、(2,0)、(3,2)、(1,3)。相邻边向量 (2,-1) 与 (1,2) 长度相同且垂直，因而是正方形。四块均只平移；证书用有理数验证原图每格覆盖一次，拼后各块不重叠、全部位于目标正方形中且面积之和为 5。


学生讲解优先展示方格和切块，说明四条切线从图中的边中点出发、每块平移后的位置。坐标只是定位，不要求小学生使用坐标或勾股定理。如果无法展示清晰图形，说明图未显示，不能声称已经画图。题图不清、五格不等大或题目对块数、移动方式另有限制时不要机械套用。
