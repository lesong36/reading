# 绝对差数塔的极差与双向候选

用于已知有限数集与“下圈等于相连上方两圈两数之差”的数塔。先确认差为大减小即绝对差，而非固定左减右；登记每排位置与每个直接父圈。记下圈z=|x−y|。若x与z已知，另一父圈只能是x+z或x−z，后者须在题给域；若z=0两候选相同须去重。由两个父圈求下圈则唯一。用尽1至n时可用库存直接限域；只说自然数而无上界时，不能自行截断搜索。

## 极差锚点与逐层传播
1. 若域在[L,U]内，差不超过U−L；差恰为U−L时父圈必须是L,U，左右次序各保留。一般差d的候选父对为域内(x,x+d)，再筛库存。
2. 已固定一对后，每填一个自由父圈，就立即向下算所有可算的圈；若生成数不在库存、与已用数重复（仅当题目要求互异）或违背固定数，则这一分支不行。
3. 优先选择候选最少的圈。未知父圈借助下圈反推时，两种符号都要核查；已知父圈本身未定时，用父数对表而非凭图面假设左大右小。
4. 回查所有局部绝对差、已知位置和数集频次。问一种给一个构造；问全部则对每个极差次序及剩余候选分支穷尽，反射是否合并按题意。不得用一条成功分支声称唯一。

## 四层、1至10各一次、中排中心9
按行从左到右记上排a,b,c,d；第二排x,y,z；第三排u,v；底w。y=9=|b−c|锁定(b,c)为(1,10)或(10,1)。余数库存为2至8。对各次序，仅需给a,d从库存取两个不同数，然后立即生成x=|a−b|、z=|c−d|、u=|x−9|、v=|9−z|、w=|u−v|，逐个核库存。范围直接来自1至10，无任意试算上限。

取上排6,1,10,8，依次得5,9,2；4,7；3。所有位置有序解还有6,10,1,8→4,9,7→5,2→3，以及前两解的左右反射，共4个；原题只需补一种，不将4个核验解当原题额外所问。

## 原创迁移与反例
域1至6的三层塔，上排2,6,5→4,1→3，六数恰好各一次；这展示最大数6可在上层但差不可能是6。只有固定父圈5与下圈2、域1至9时，另一父圈为3或7，不能只取5−2。允许重复的0,2,0→2,2→0是合法绝对差塔；若题目要求互异则不合法。固定左减右会错判上排1,4,2得到−3,2，而绝对差规则正确中排为3,2、底1。
