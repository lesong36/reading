# 重叠纸片遮挡顺序

## 使用条件
题目有多张相互遮挡的纸片或图形，要求判断上、下层顺序。先核对纸片是否同形同大、是否不透明、边缘能否辨认、是否允许旋转或错位。透明纸或真实边界模糊时不能直接用不透明纸的遮挡关系。

## 方法
1. 逐片记录可见区域和确定的边，确认图中标识属于哪一片。一个完整可见的纸片不一定在全部其他互不相交的纸片之上；只能从它与其他片实际相交的部分判断上下。
2. 在可确认的交界处，边线被另一片遮住可支持遮挡片在上；列成“上片→下片”，不要把单纯线条相交、画图边框或不可辨认处当作遮挡。若显示线条不足以分辨，保留多种解释。
3. 综合相同形状、大小和可见边，列每片可能的原始位置，不把隐藏部分或网格对齐当作题目明确条件。逐个检查候选放置和上下顺序能否重现所有可见区域。
4. 只有实际遮挡关系要求某片在另一片上时才能建立约束。若多种顺序均符合，给出多种并解释未确定原因；若只有一个符合，也需说清怎样排除其余候选。存在矛盾说明读图或假设有误。单靠一个局部先后关系不能推断不相交的两片一定存在唯一上下顺序。

## 来源图：先从边界确定朝向
第424讲超越1图中8张大小相同正方形纸片重叠。按图上可见轮廓，A有完整横竖边；B拥有整图左/上外边界的一段，C拥有上边，D上/右，E右/下，F下，G下/左，H左。每段都是正长度线段，不是仅碰到一个顶点。所属纸片必须有一条边与这段线共线，否则有限条倾斜边无法覆盖整段，且线段若在纸片内部会使整图外侧也被覆盖。因此朝向来自原图边界，而非额外添加“不许旋转”。

## 来源图：隐藏位置与连续错位的排除
按原图等距轮廓作精确示意，以A边长的一半为1，外框为4×4，可见区域四行是BCDD、BAAD、HAAE、GGFE。这个比例和字母区域归属是读图前提，不是题干单独给出的数字，更不是由OCR自动证明。若图不清或比例不能确认，应保留不确定，不把以下坐标当作题面已知。

正方形边长2。A左上角(1,1)，B(0,0)、D(2,0)、E(2,2)、G(0,2)由完整边或外侧可见范围固定。余下C左端c可在0至1之间、上端0；H左端0、上端h在1至2；F下端4、左端f在1至2。无需先假定它们落在整数格点。

C在可见区域遮B，若c小于1，又会覆盖左侧可见B条带，反而要求B在C上，矛盾。因此C左端只能1。H在可见区域遮G，若h大于1，会侵入下方可见G条带，反而要求G在H上，矛盾，因此H上端只能1。F在可见区域遮E，若f大于1，会侵入右侧可见E条带，反而要求E在F上，矛盾，因此F左端只能1。这些矛盾条带对任意非零错位都有正面积，不只检查几个整数位置。

## 来源图：逐对遮挡与唯一顺序
得到各片左上角A(1,1)、B(0,0)、C(1,0)、D(2,0)、E(2,2)、F(1,2)、G(0,2)、H(0,1)。用单位小区域标示可直接复核的先后边（横坐标x、纵坐标y均从0开始）：

| 上片→下片 | 可见重叠区域的左上角(x,y) | 正面积的可见依据（从上往下数行、从左往右数列） |
|---|---|---|
| A→D | (2,1) | 第2行第3格露出A，该格也在D的完整范围里 |
| D→C | (2,0) | 第1行第3格露出D，该格也在C范围里 |
| C→B | (1,0) | 第1行第2格露出C，该格也在B范围里 |
| B→H | (0,1) | 第2行第1格露出B，该格也在H范围里 |
| H→G | (0,2) | 第3行第1格露出H，该格也在G范围里 |
| G→F | (1,3) | 第4行第2格露出G，该格也在F范围里 |
| F→E | (2,3) | 第4行第3格露出F，该格也在E范围里 |

这七条链已比较全部八片，所以上到下唯一为A、D、C、B、H、G、F、E。逐格重绘还原BCDD/BAAD/HAAE/GGFE，检查全部可见区域，而非只核对参考答案。若任意两片在约束图中仍不可比较，可能有多种合法次序，不能照搬本例唯一性。给学生优先解释可见边、拿去上层后露出的下一片及逐对依据，不必讲程序枚举或所有坐标。

## 来源解答的易错处
边界的一段只确定方向或部分坐标，不能直接说“贴着外框，所以位置全定了”；先用上面的C、H、F错位会产生相反遮挡的反证排除滑动，再用七个正面积区域建立链。给学生可说“C若再向左一点，就会同时要求C压B和B压C”，H、F也分别说明对应的反向冲突，不必堆坐标方程。

表中每条依据是一块可见区域，不能改写成未核实的“某个角露出来”：C的依据在最上行，G的依据在最下行；仅仅一个边界顶点接触不证明谁压谁。回代应复核四行全部字母，不能说D除被A盖的部分外没有别的可见区域。

原题没写禁止旋转，方向由已读出的外轮廓归属推得，不应添“不许旋转”作为外加条件，也不能声称只要允许旋转就必有多解。需要保留的不确定性是图像模糊、比例或字母归属无法可靠读取时，是否仍满足该精确示意的前提。

## 验证边界
项目已有离线位置/次序枚举和连续条带反证；它们只检验明确读出的精确示意，不代替实际模型读图、归属、保存PDF或人工教学审核。参考解用于核对意图，不能反过来把参考顺序当成识图证据。
