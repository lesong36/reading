# 正方形长条的环绕裁剪

## 适用条件
原图是一张边长为 2n−1 的正方形纸，需裁同样的 n×1 完整矩形条，n 是不小于2的整数，长度单位一致。允许把长条横放或竖放，纸条之间不可重叠；如另有限制切割次数、必须沿特定方向裁或其他加工要求，本方法不自动适用。给定尺寸不符时，不强套这个公式，改用其他构造或说明未确定。

## 上界和达到上界
面积为 (2n−1)²＝4n(n−1)+1，每条面积 n，因此数量不超过 4(n−1)。这一面积上界对任意方向均成立。证明最大值还必须构造：分别在上、右、下、左放四组，每组 n−1 条，各组横竖交替，围住中间的一个 1×1 小方格。每组占 n×(n−1) 的长方形，四组不重叠，恰好覆盖除中心格外的全部纸张。所得到 4(n−1) 条达到上界，故是最大值。

## 画图与核对
用边长为1的方格，标注每一张纸条；一张纸条必须由 n 个连续共线格组成。检查每条在边界内、纸条互不重叠、中心未用、各组各有 n−1 条。数学条件的纸张可自由裁，不能先剪碎后拼接小条当作完整纸条。需要显示图时，仅在实际支持的图形工具允许足够行列和块数时提供有效数据；超出显示能力则明确说明，不能声称已经画出图。用户要求具体裁法时不要仅输出面积上界。

## 反例与边界
7×7 中裁 4×1 条满足 n＝4，故上界和构造均为12，剩1格。7×7 中裁 3×1 条不满足边长等于2n−1，不能套用12。即使题目满足面积上界，若禁止横竖混排，四组构造也不自动合法。
