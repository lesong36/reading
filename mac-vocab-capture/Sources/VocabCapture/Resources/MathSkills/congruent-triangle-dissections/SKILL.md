# 全等直角三角形分割构造

## 适用范围
需要自行选择并画大三角形，把它分成5个或13个全等小三角形；两问可选择不同的大三角形。若题目要求同一个预先指定的大三角形、固定边长或不同块数，不直接套用本方法。必须画出实际分界；仅说明面积比不能证明存在分割。

## 构造与校验
五块：画顶点为(0,0)、(5,0)、(1,2)的大三角形，分割出的每个小三角形直角边为1和2。各块顶点依次为：(0,0)、(1,0)、(1,2)；(1,0)、(3,0)、(3,1)；(1,0)、(3,1)、(1,1)；(1,2)、(1,1)、(3,1)；(3,0)、(3,1)、(5,0)。
十三块：画顶点为(0,0)、(13,0)、(4,6)的大三角形，每个小三角形直角边为2和3。各块顶点依次为：(0,0)、(2,0)、(2,3)；(2,0)、(4,0)、(4,3)；(2,0)、(2,3)、(4,3)；(2,3)、(4,3)、(4,6)；(4,4)、(4,6)、(7,4)；(4,2)、(4,4)、(7,2)；(4,4)、(7,4)、(7,2)；(7,2)、(7,4)、(10,2)；(4,0)、(4,2)、(7,0)；(4,2)、(7,2)、(7,0)；(7,0)、(7,2)、(10,0)；(7,2)、(10,2)、(10,0)；(10,0)、(10,2)、(13,0)。

坐标是定位和核验工具，面向小学生可以用方格数辅助画图，不必引入方程。逐块核对两直角边长度，确认所有线段在大三角形内，任意块内部不重叠，合计面积等于大三角形。图像识别、显示或切线不确定时明确说明，不能把坐标列表冒充已经画出的图。

## 限制
图形输出工具需能显示三角形实际边界；不支持时保留坐标和文字、说明图尚未显示，不能宣称已画图。数字5或13只是这两种构造的块数，不能推断任意块数都能同样分割。

## 显示预设
题目允许自行选择大三角形且需要这两种构造时，使用一般解答工具 inline_triangle，并在答案中给出所需完整围栏。两个预设只能表示上文所列的5块或13块，不能代表别的三角形或原题尺寸。

```math-triangle-dissection
{"pieces":5}
```

```math-triangle-dissection
{"pieces":13}
```
