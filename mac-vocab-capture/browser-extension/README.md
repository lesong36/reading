# 拾词助手网页取句扩展

用于 Edge 与 Chrome 的通用网页取句扩展。它只在用户主动右键选择“拾词助手：查词”时读取当前选区所在句，并通过本机 `vocabcapture://` 协议交给已安装的拾词助手。

## 安装（开发者模式）

1. 打开 Edge 的 `edge://extensions`，或 Chrome 的 `chrome://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择此 `browser-extension` 文件夹。
5. 网页中选中英文词或短语，右键选择“拾词助手：查词”。

扩展不会在后台收集网页内容，也不会上传文本。
