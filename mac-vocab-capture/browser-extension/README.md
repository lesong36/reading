# 拾词助手网页取句扩展

用于 Edge 与 Chrome 的通用网页取句扩展。选中文字后，它会把选区所在的完整原句暂存到本机拾词助手；随后仍可使用原来的全局快捷键、鼠标手势或浮动“拾词”按钮。右键“拾词助手：查词”也仍可直接查询。

## 安装（开发者模式）

1. 打开 Edge 的 `edge://extensions`，或 Chrome 的 `chrome://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择此 `browser-extension` 文件夹。
5. 网页中选中英文词或短语；之后可继续使用拾词助手原有的全局快捷键、浮动“拾词”按钮或鼠标手势。扩展会在本机短暂提供该选区所在的完整句。右键选择“拾词助手：查词”也仍可直接唤起查询。

若阅读器是直接打开的本地 HTML 文件，请在该扩展的详情页额外打开「允许访问文件网址」。

扩展不会在后台收集网页内容，也不会上传文本。
