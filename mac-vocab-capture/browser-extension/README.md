# 拾词助手网页取句扩展

Edge / Chrome 扩展把活动网页中选区所在的可见原句交给本机拾词助手。支持全局快捷键、浮动按钮、鼠标手势；右键“拾词助手：查词”或扩展“查当前选中词”可显式查询。

## 安装与配对

1. 打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式，加载本目录。
2. 在拾词助手菜单选择“配对浏览器扩展…”，复制本机配对码。
3. 打开扩展窗口，粘贴配对码并点击“配对”。升级旧扩展后需重新配对、刷新网页。
4. 本地 HTML 文件需另外开启扩展详情的“允许访问文件网址”。

扩展 0.2.1 需要同时升级本机应用。Chrome 与 Edge 的发布会话、失效通知和原句缓存分别维护，应用只读取实际前台浏览器的缓存；其他 Chromium 浏览器使用辅助功能取句，不复用 Chrome / Edge 缓存。此隔离以浏览器类型为单位，尚未覆盖同一浏览器多个用户配置文件的并发取句。

配对码只保存在本机应用和浏览器扩展配置中。退出配对可使用扩展的“忘记配对”；应用菜单“撤销浏览器配对”立即使旧配对码和待执行查词失效。显式查询使用15秒有效的一次性凭证，长期配对码不会进入网页DOM或查词URL。

## 原句与隐私

默认在选区变化后向本机提供可见原句；可关闭“选中时自动提供原句”，仅右键显式查词。扩展窗口可暂停当前站点。隐藏节点、脚本、样式、模板不会进入原句。主框架活动tab和窗口由后台确认，并再次读取当前选区；导航、换tab、失焦或清空选区立即失效，原句仅内存暂存并定期确认，应用缓存最多2.5秒。浏览器原句不写入持久化存储；升级会删除旧版本的 `bridgePayload`。

扩展使用带本机配对码的 loopback HTTP；应用仅允许匹配的扩展来源，不允许网页通配跨域。扩展本身不向互联网发送原句；用户查词时应用会按AI服务配置发送所需原句。应用生产诊断默认仅含长度与耗时，原文诊断需主动开启，10分钟后停止；已有日志可通过菜单清除。

## 回归验证
