# 拾词助手释义延迟与系统验证

日期：2026-10-04（Asia/Shanghai）。最终安装版本：0.2.57，位置：`~/Applications/拾词助手.app`。

## 修改与简化

- `AIClient.swift`：按 meaning 优先顺序流式返回紧凑 JSON；只显示完整解码的中文释义，全部字段通过校验后才允许保存并缓存。缓存最多 100 条，按目标词、完整原句、服务、模型及凭据区分，应用退出后清空。兼容返回普通 JSON 的服务，并处理取消、流式错误、截断与 Unicode 转义。
- `OCRLookupPanel.swift`：删除 180 毫秒固定等待；等待期间回车复用当前请求；切换词或关闭窗口后忽略旧释义；查询失败清除未完成的预览。
- `VocabCaptureApp.swift`：普通选词立即显示非模态窗口，提前展示释义；完整结果前禁止保存；取消窗口会取消查询，已确认保存不被后续取词取消。修正原句文本视图尺寸和伸缩，实际截图确认原句可见。
- `VocabCaptureApp.swift`：系统 URL 在启动完成前先排队，菜单初始化后再处理，避免冷启动访问未创建的状态栏对象。
- `OCRCapture.swift`：移除 Vision 完成回调，统一由同步识别后的单个分支返回结果，避免一次失败恢复 continuation 两次导致崩溃。
- 新增 `DictionaryClientTests.swift`、`DefinitionPreviewPanelTests.swift`、`OCRClientTests.swift`，扩展 `OCRLookupPanelTests.swift` 和 `CaptureShortcutSettingsTests.swift`；更新 README 与 VERSION。

没有新增依赖，没有修改 AI 服务、账户或用户快捷键配置。
