# 小学数学截图错题库：多维标签与收录方案

日期：2026-10-08；2026-10-09 更新。状态：本地照片收录 MVP 已实现，详见 [实际数据库与使用说明](MATH_QUESTION_STORAGE.md)。标签编辑、学生作答和错因分析仍在规划；未调用用户模型、上传题目或凭据。

本方案承接 [原有存储设计](./MATH_MISTAKE_DATABASE_DESIGN.md)，补充小学数学范围、多维标签、错因证据及验收办法。原有 SQL 是设计原型，不能视为已经可用的错题库。以下新增表和字段均为建议，尚未修改 SQL。

第一步研究产物：[小学数学多维标签目录 v0.1](./PRIMARY_MATH_TAG_CATALOGUE_V0.1.md)，配套 [结构化目录 JSON](./taxonomies/primary-math-v0.1.json)。这是待教学审核的应用目录，已记录课标映射、定义、示例、边界和证据要求；不是自动诊断已通过验收的声明。

## 产品目标与第一版边界

按用户2026-10-08最新选择，原照片是题目的权威来源，OCR仅用于可修正的检索索引。收录入口复用现有“截图问一问”：截图后用户可点击“保存题目”直接收藏原图，也可先点击现有“解题”再保存。未解题也能保存，解题过程是可选附加内容，不要求完整结构化、逐字校对或等待AI后才能收藏。同一道题可以在不同时间产生新的作答和错误记录。

第一版以小学数学为范围，先支持单题及带小问的题目。多题截图发现多个题号时提示拆分或重新框选，不静默丢掉其余题目。允许追加截图以补齐题干或图示。

最小闭环是：现有截图问一问 → 用户点击“保存题目” → 原图持久化成功 → 后台OCR索引和建议标签 → 检索或按标签浏览 → 打开原图。OCR为空、失败或尚未完成，不阻塞收藏；可以后续重建索引。所有截图不自动加入题库，只有点击保存才正式收藏。作答图片、错误形式和错误本质均可补录；没有学生答案时也可以收录，但不能确认它是学生错题，错因保持“未分析”。

“解题”复用现有问一问的模型、思考选项和回答展示，不新增独立解题模块。点击保存时若已有完整解题回答，可随原图保存；尚未解题则解题记录为空，允许以后追加。正在生成时题目可以先保存，完整回答生成后再关联已保存的题目，避免重复入库。失败或中断的回答不得标成完整解题过程。AI解答与原题、学生作答及教师参考答案分别保存，不把模型回答自动视为正确标准答案。

收到的图片可能本身已被裁切。只能保存收到的完整文件，不能假称拥有未提供的整页或相机原片。应用内裁题应保留整张输入照片，再保存裁切坐标/派生裁图；原图不压缩、不覆盖。列表缩略图、OCR结果、AI转录或解释都不是原题替代品。

自动解题、自动诊断、推荐练习、生成变式题、云端同步和整卷批量收录不作为第一版的完成条件。难度可后续增加，不与错因混用。

## 课程知识点的来源

课程轴以教育部 [《义务教育数学课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf) 为基线；[发布通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html) 指定了数学课标的更正版。小学按 1–2、3–4、5–6 年级三个学段组织，课程领域包括数与代数、图形与几何、统计与概率、综合与实践。

课标的领域、主题及学段要求用于建立上层分类。应用中便于检索的细分知识点，需要由课程条目映射和教学审核形成，不能把应用自行细分的目录称为官方标签全集。

建议结构为“课程版本 → 学段 → 领域 → 主题 → 知识点”。知识点可以跨学段重复出现，应以适用学段关系表达递进要求，不复制同名标签。具体到某年级、上下册、教材单元的顺序，需要另行选择教材版本并建立映射；不能由国家课标直接猜测。

例：图形与几何 → 图形的认识与测量 → 长方形面积。前两层来自课标，末层是应用可检索的知识点。保存官方来源、印刷页码/条目定位和映射审核状态。初中、高中及未来课标更新作为新的课程包加入，保留旧标签和旧题目映射。

## 多维标签：五个主要轴

| 维度 | 回答的问题 | 第一版示例 | 标注依据 |
|---|---|---|---|
| 题目形式 | 要怎样作答？ | 选择、判断、填空、计算、解答、作图、混合 | 原题要求、用户校对 |
| 课程知识点 | 考查什么内容？ | 位值、小数运算、分数运算、面积、数据读图 | 版本化课程目录；可多选 |
| 问题类型 | 问题怎样组织？ | 求总量、比较多少、平均分、求未知量、数量关系应用、图形测量 | 题干及条件；应用自定义目录 |
| 错误形式 | 哪一步出现了什么错误？ | 抄错数字、运算结果错误、小数点错位、漏条件、单位遗漏、答非所问 | 某次学生作答及原题；可多选 |
| 错误本质 | 什么理解或方法可能不足？ | 位值概念、运算规则、数量关系建模、单位量纲、图形度量概念理解不足 | 作答步骤、学生解释或教师/用户确认 |

这些示例是待审核的产品分类，不是完整教学目录。错因分类也不是课标官方分类：课标约束“学习什么”，不能直接提供某名学生“为什么做错”的结论。

题目形式和问题类型可以按小问分别标注；知识点可分主知识点和辅助知识点，列表默认显示主知识点，筛选时包含全部关联。错因属于“学生的某一次作答”，不能成为题目的永久属性。

### 错误形式与错误本质的关系

两者是多对多关系，不做一一自动转换。相同的表面错误可能有不同原因，相同的知识理解问题也可能产生多种表面错误。

例如原题是 `3.6 + 0.48`，某次学生答案是 `0.84`：

- 仅有最终答案：可记录“计算结果错误”，不足以确定小数点对齐或位值理解问题。
- 有竖式，能看到按末位而非小数点对齐：可增加“小数点错位”这一错误形式。
- 学生解释了错误的对齐规则，或经教师确认：才可确认“位值/小数加法规则理解不足”。

“粗心”不作为自动默认原因。学生偶然写错、尚未理解规则和未掌握检查方法，应允许分别记录；证据不足保持未分析或待确认，不能贴成稳定的个人特征。

每条错误记录保存：所属作答、小问、错误步骤、相关文字/图片区域、观察到的现象、原因假设、来源（用户/教师/AI）、确认状态。AI 自报的置信度只能作为提示，不能替代证据或直接决定已确认。用户可增加、删除和纠正标签。

可选的少量确认问题，如“为什么这样对齐？”用于区分原因，但不强制用户完成教学问答后才能收录。

## 自动标注方法

1. 先保存原图；后台OCR产生可重建的搜索文本。需要结构化或AI分析时再从原图提取，校验数字、运算符、单位和图文关联，生成待校对提示。
2. 根据用户选择的小学学段、课程包和已有题目内容，提供相关候选知识点。模型从合法 ID 中选择，不随意造标签。
3. 题目形式、知识点、问题类型可在一次提取请求中给出建议。标签须附简短的原题依据，应用校验所属课程版本和 ID。
4. 有学生作答时，另行产生错误形式和原因假设；若没有可核对答案，不把模型自行求解结果当已核实标准答案。
5. 原图可以独立完成收录。校对后的文字另存为派生版本，不覆盖原图；内容和标签审核状态分开：文字已经校对，不代表原因假设已经确认。

候选目录随用户当前学段和课程包确定，知识点可跨领域、跨学段。无法归类时返回“待分类”，而不是强行选一个看似相近的标签。

原题、参考答案、学生作答和 AI 解析分开存储。原截图中的教师批注可以作为来源证据，但不能自动当作标准答案或真实错因。题目内容修订后，既有作答和诊断保留它们对应的题目版本，并提示是否需要复核。

## 截图与识别路线

当前 [OCRCapture.swift](../Sources/VocabCapture/OCRCapture.swift) 使用 macOS Vision，识别语言仅配置 `en-US`；[VocabCaptureApp.swift](../Sources/VocabCapture/VocabCaptureApp.swift) 的 `questionImageData` 将问答送图限制到最长边 1600 像素。两者均不能直接充当数学题归档与完整提取的完成证明。

收录必须保留原始清晰度的图片。发送识别时可以生成派生图，但记录缩放/裁剪变换。分数、带分数、竖式、平方单位、角度符号、空格占位、图中小字和表格需要专门样本检验，不能靠普通文字 OCR 的成功率推断。

| 路线 | 作用 | 取舍 |
|---|---|---|
| 现有已配置的视觉模型 | 提取题目结构、建议知识点和图示区域 | 集成路径短；必须逐模型实测，不能以问答默认模型直接决定提取默认模型 |
| PaddleOCR PP-StructureV3 | 候选的版面、表格、公式识别和本地处理路线 | 官方提供这些模块；安装包、模型资源和本机速度需要另行评估 |
| Mathpix | 候选的印刷/手写公式及混合文字识别 | 官方提供数学图片结构化接口；需要独立服务配置及费用评估 |

上述能力来自 [PaddleOCR 官方文档](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/pipeline_usage/PP-StructureV3.en.md) 与 [Mathpix 官方图片识别文档](https://docs.mathpix.com/guides/image-ocr)，不是本项目的准确率实测。建议先对照现有视觉模型；出现系统性的公式或版面缺陷，再比较专用识别路线，不提前引入新依赖。

保存位置是本地，不等于识别过程离线：选择云端视觉模型或 Mathpix 时会发送截图到相应服务。界面应显示正在使用的识别服务。完全离线方案要另行测量本地识别和标注能力。联网搜索不属于题目提取的必要步骤。

配图从原图裁出，保留图内文字、刻度、图例和单位。自动边界需允许调整；不确定时保留整个题目截图，不能为了独立配图丢失信息。模型不能重画几何图来替代原图，也不能根据示意图外观增加未给出的条件。

查看、复习、打印和AI分析以原图为依据；不能仅凭OCR推断图形关系或补出缺失内容。可编辑Markdown + LaTeX、表格结构及单独配图是后续可选的派生表示，不是收录前置条件。竖式或复杂表格不能忠实重建时，直接展示原图，不宣称已完整结构化。

英文取词保持现有`en-US`配置，数学照片独立采用`zh-Hans`加`en-US`的候选配置。不引入全局语言切换，不在英文热路径增加中文检测、重试或云调用；上线前用相同英文语料对文字、数字、单位、选词边界和p50/p95做配对回归。本轮尚未完成英文语料回归。

## 本地数据结构的补充建议

继续采用 SQLite + 本地原图/裁片文件，跨平台共享相同的数据约定。macOS、Windows 仅替换截图及系统界面适配。

| 对象 | 主要用途 |
|---|---|
| `questions` / `question_versions` | 题目记录与原图资产快照；正文/小问/选项可为空，OCR或校对文字属于可选派生版本 |
| `assets` / `question_sources` / `question_figures` | 原截图、配图、坐标和来源；沿用旧设计 |
| `taxonomy_versions` / `tag_nodes` | 各标签轴的版本、稳定 ID、层级、说明、来源及适用学段 |
| `tag_curriculum_mappings` | 应用知识点与课标条目、学段要求的映射；教材映射后续增加 |
| `question_tag_assignments` | 题目/小问标签、主次、来源、确认状态及标注内容版本 |
| `learners` / `question_attempts` | 简单本地学生标识及各次作答；第一版可默认一个档案，无需账号系统 |
| 可选的题目解答记录 | 关联原图题目及现有问一问回答，保留提问、回答、模型、时间与完成状态；未解题时为空，不冒充学生作答或已核实答案 |
| `attempt_errors` / `attempt_tag_assignments` | 错误事件、可观察形式、原因假设、多标签与证据；绑定作答及小问 |
| `extraction_runs` / `review_issues` | 模型、输入资产、变换、响应版本、字段疑点及处理情况 |
| `ocr_runs` / 可重建检索索引 | 按资产/区域保存raw OCR、校对文本、识别配置和版本；索引失败不影响原图记录 |

旧 SQL 仅有 `knowledge_tags_json` 和题目级 `mistake_note`，不足以支持上述独立维度与作答历史；旧 `question_type` 也需要补充判断、计算和作图形式。以上是迁移方向，不在本轮执行。

旧设计把`stem_markup`作为结构化正文来源，不适用于本轮“照片先收录、OCR仅索引”的决定；必须先修改设计和迁移约定，再开发，不直接运行旧SQL当新方案。数据库记录资产引用，原图文件保留不可变字节与hash；索引可删除重建而不改原图、手工标签或作答记录。备份/导出同时包含图片文件、记录及资产清单，只导出文字数据库不足以恢复原题。

中文检索需用真实关键词测命中和误命中，特别是背面透字与漏字。SQLite [FTS5官方文档](https://www.sqlite.org/fts5.html#tokenizers)提供普通词元与trigram候选；trigram的全文查询不能直接匹配少于三个Unicode字符，因此“白糖”“头盔”等短词须另行设计匹配或标签回退，不能把默认索引当作中文检索已解决。本轮没有新增分词依赖或建立索引库。

不把课程包更新变成覆盖旧数据：节点保留稳定 ID，显示名称可以更新；拆分/合并节点通过显式映射迁移。系统标签与用户自定义标签分命名空间，用户修改不能破坏官方课程出处。

同字节图片可按 hash 去重。题目重复则另用题干、数字、公式、小问、选项及图示生成候选：相同题目的不同截图可以关联已有题目并新增来源/作答；仅数字不同的变式题仍保留为不同题。模糊相似只提示，不自动合并或删除。

## 界面建议

截图后继续打开并前置现有“截图问一问”窗口。在现有快捷问题“解题”旁增加“保存题目”操作；不再另设截图收录入口或要求二次截图。保持原有提问/追问/模型切换体验，保存只依赖当前截图原图，不依赖回答或OCR成功。

保存成功后显示“题目已保存”，按钮切为“已保存”并可打开对应题目。已有完整解题回答随题目作为可选附加内容保存；没有解题时显示“暂无解题过程”，仍可正常查看原图。之后的完整解题可追加到同一题目。保存失败清楚提示，保留当前窗口中的原图供重试；不要只根据回答已经出现就展示已入库。

采用 macOS 常见的侧栏和分栏：左侧题库导航，中间照片缩略图列表，右侧默认展示可缩放原图。OCR草稿、标签及可选的结构化内容放在可展开区域，不要求用户逐字改稿才能保存。顶部以课程/学段筛选；标签作为可移除的胶囊，更多标签在弹出面板编辑，不在主界面铺满整个课程树。

详情分为“原题”“我的作答”“错误分析”。课程知识点与问题类型跟随原题；错误形式和错误本质跟随当前作答。列表默认展示主知识点和复习状态，待确认原因带标记，避免形成诊断已确定的错觉。

第一版复习状态由用户选择“待重做/已重做/已掌握”，不把一次答对自动等同长期掌握。可以先以原图复习；需要去除学生答案的练习稿应由已校对内容生成，不自动涂抹掉可能属于题干的文字。

## 下一步研究与验收

先建立经过人工标注的 120 道小学样本（每年级约 20 道），涵盖课程领域、题目形式、图文结构和常见错误记录。开发调优样本与保留验收样本按原题分组隔离，重复题不跨集合；没有学生作答的样本用于验证系统是否拒绝猜测错因。

对候选视觉模型使用相同输入和结构契约，比对：

| 指标 | 统计办法与建议门槛 |
|---|---|
| 原图保存可靠性 | 每次显示保存成功均有可恢复题目和完整原图，失败清楚提示；目标100%，不受模型结果影响；未点击保存的截图不自动入库 |
| 问一问收录闭环 | 未解题直接保存、解题后保存、生成中先存图、解题失败后存图、已存题追加解答及重复点击均单独验收；不因AI失败丢题或生成重复记录 |
| 检索与原图定位 | 用真实查询测命中/误命中和原图打开正确率；OCR漏词时仍能按标签、日期和缩略图找到记录；目标待样本冻结后确定 |
| 可选整题忠实提取率 | 仅评估后续结构化功能，不作为照片收藏门槛；题干、数字/符号、选项、小问、单位、配图均正确才计成功，不能用文字可读率替代 |
| 知识点自动标注 | 分别统计精确率、召回率、待分类率；目标精确率 ≥95%，覆盖率同时报告 |
| 错误形式与本质 | 各自测量，并检查原因是否有证据；仅答案错误的样本不得自动确认本质 |
