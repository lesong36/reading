# 问答渲染与复制修复（0.3.27）

0.3.24 的问答面板直接显示纯文本，缺失 Markdown、数学公式排版及一键复制。0.3.27 恢复离线 WebKit 渲染，使用已有的 Marked、DOMPurify、KaTeX 和本地字体；打包脚本明确复制全部渲染资源，原生富文本作为加载失败时的回退。

回答框内部右下角固定“复制回答”，复制最新回答的原始 Markdown 和公式源码，生成中亦可复制已输出内容。历史会话、流式回答及缩放共用渲染链路，恢复会话状态提示使用正确字符串插值。

验证：完整 Swift 测试 459 项，7 项跳过，0 失败。实际 WebKit 截图覆盖行内与独立公式、求和、连乘、下标及公式编号。正式安装的 76 个渲染资源文件与源码哈希一致，版本号和深度严格签名验证通过。未在 macOS 13 真机验证；应用使用 Apple Development 签名，未做 Developer ID 公证。

0.3.25、0.3.26 为本地修复验证版本，未正式发布。正式修复发布统一为 0.3.27。
