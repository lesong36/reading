# 原生设置与截图面板布局 · v0.2.79

## 用户入口

菜单栏保留查选中词、截图取词、截图问一问、最近收藏、设置、帮助与诊断、退出。设置统一支持 ⌘,，模型与检索不再分散在多层菜单里。截图面板齿轮直接定位统一设置窗口中的问答或检索页面。

设置窗口采用 AppKit 原生侧栏与滚动表单，分类为取词与快捷键、取词释义、截图问答、联网检索、账号与同步。页面切换保留草稿，不自动保存；保存后留在页面，支持还原更改。关闭窗口丢弃未保存草稿。账号页只在需要时显示冲突和未归属词条操作，导出与恢复收进默认折叠的词库维护区。

截图取词原文随窗口高度伸展；截图问答采用紧凑标题和齿轮设置入口，输入区与次要操作分层，性能数据位于安静的底部区域。已有快捷问题、原图、联网、思考强度、缩放和自适应换行保留。

## 实现与行为边界

- `SettingsWindow.swift`：原生分类导航、页面缓存、滚动容器与共享表单组件。
- `DictionarySettingsView.swift`：释义服务配置、显式连接测试、保存与还原；验证先于 Keychain 写入，失败不覆盖原配置。
- `AccountSettingsView.swift`：登录同步摘要、条件操作、可折叠词库维护，复用原来的确认与恢复流程。
- `VocabCaptureApp.swift`：统一入口、删除重复菜单与旧设置弹窗，沿用原同步、账号、凭据和截图流程。
- 快捷键录制仅在设置窗口为 key window 且录制框有焦点时暂停全局取词快捷键；失焦、切换页面、关闭或切换应用会恢复。
- 模型、检索、快捷键编辑器提供嵌入模式，独立窗口行为继续受已有回归保护。
- 不新增依赖；不修改 OCR 算法、网络请求协议或词库格式。API Key 继续只存本机钥匙串；非秘密配置保留原 UserDefaults 键。
