# 截图问一问：联网检索

## 使用

1. 打开菜单栏「模型与服务 → 联网检索设置…」，或问答窗口的「检索设置…」。
2. 在 [Tavily 控制台](https://app.tavily.com) 获取自己的搜索 API Key，在应用内填写并保存。不要将 Key 发到聊天或提交到仓库。
3. 截图问一问，勾选「联网检索」，输入问题。关闭这个开关时保留原来的直接模型回答。
4. 根据检索阶段提示等待回答，点击「检索来源」下的网页链接核对。停止、关闭窗口或切换检索模式会取消当前请求。

搜索服务与问答模型独立。当前支持 Tavily，所有现有问答模型都走相同的搜索流程；参考图片仍需所选模型支持图片输入。搜索认证、额度、连接失败或无结果时明确报错，不会默默生成未检索的回答。

## 请求流程

采用固定检索流程，继续使用 LangChain 模型接口，不引入 Agent 工具循环：

1. 所选模型根据本次问题、截图内容与最近六轮上下文生成一个简短检索词。
2. 引擎通过 Tavily Search API 搜索一次，最多保留五条可用网页资料，提取搜索摘要或返回的页面文本。
3. 将有长度限制的检索资料交给所选模型，流式生成回答，并附上实际取得的网页标题和 URL。

检索词生成增加一次模型调用，搜索可能消耗 Tavily 额度，联网回答通常比直接回答更慢。固定请求上限、超时和取消控制用于避免无界工具循环。首字时间统计到第一段可见回答，包含前面的检索时间；平均 TPS 沿用最终回答的 token 用量除以整个请求耗时，不等同于纯解码速度，也不包括检索词生成的 token 数。

## 数据与来源

- 模型 Key 和搜索 Key 使用不同的 Keychain 条目，调用时只经匿名管道进入引擎内存；不进入命令行、偏好文件、日志或安装包。
- Tavily 收到整理后的检索词和搜索服务认证，不接收截图、完整对话或模型 Key。检索词可能包含截图里与问题相关的文字；勾选前请检查截图内容。
- 所选模型收到原有问题上下文和检索资料。只有勾选「参考原截图」或没有 OCR 文字时才发送图片。
- 网页内容与截图作为待分析资料，不是改变系统指令的命令；网页标题和内容设长度上限。
- 来源列表由实际搜索结果生成，只接受 HTTP/HTTPS 网页链接。检索结果不是答案正确性的保证，时效、来源差异及证据不足仍需明确说明。
- 不提供人脸身份识别或反向人脸搜索。缺少可检索文字线索时，补充具体名称、页面标题或来源链接。

搜索服务可独立选择直连或系统 HTTP 代理，不改变其他模型的网络设置，不启用 LangSmith 跟踪，也不自动重复付费请求。

## 验证范围

0.2.74 已完成以下验证：

- 207 项 Swift 测试通过，编译将警告视为错误；修改的 Swift 文件通过严格格式检查。
- 56 项 Python 测试通过；持久进程测试使用打包后的引擎。模拟 HTTP 验证真实 LangChain 的 Chat Completions、Responses、Anthropic 适配器、独立鉴权、来源、进度、失败与取消。
- 原生界面夹具使用虚假 Key 和隔离偏好，检查了 150% 缩放下的来源换行、链接和完整设置窗口。
- 安装包通过深度严格签名验证，347 个文件的凭据模式扫描未发现命中；本机应用与打包引擎均成功启动，原有四个模型配置和生词本仍在。
- 打包引擎使用本地模拟模型生成公共检索词，实际连接 Tavily，并以无效测试 Key 验证独立认证失败处理。未使用用户凭据、私人截图或付费有效 Key。

有效 Tavily Key 下的检索质量、完整联网回答和真实延迟尚未验证，不能用模拟结果或认证失败耗时宣称真实搜索性能。菜单栏应用没有可见窗口时，系统 UI 自动化读取会超时；界面验证使用隔离夹具和原生测试完成。

官方接口：[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
